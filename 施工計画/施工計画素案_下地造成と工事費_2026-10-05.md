# 施工計画（素案）：下地造成と工事費の予測（2026-10-05、Claude）
前提：斜面長1km×幅40m（4万m²）、20°と30°の2案。依頼者確定：4〜5時間に1回の保守、滑走集中ゾーンは全体の60〜70%が通る、上級者のカービングを考慮する。
入力：VT9〜VT12、[GPT-6 Astraの監査](../GPT往復/GPT回答_下地造成と全天候リスクの監査_20261005.md)、単価調査（下表のURL）。計算：[cost2.py](../バーチャル試験/cost2.py)、[vt12.py](../バーチャル試験/vt12.py)。

## 1. GPT監査の採否
| GPTの指摘 | Claudeの検証 | 採否 |
|---|---|---|
| 1:4（約15°）より急な地盤は段切りが原則 | 国交省・県の基準で確認（段切り高さ0.5m以上・幅1.0m以上） | **採用**。VT10の「20°なら段切り不要の可能性が高い」は誤りとして訂正 |
| 地山側にもフィルターが要る | 妥当（地山の泥が排水層を詰まらせる） | 採用 |
| 排水層は固めない | 妥当（透水・洗浄・交換性を失う） | 採用。焼結はHBG床だけに限る |
| R10（局所300mmの削れ代）と矛盾し、最小厚0.45m | 妥当（要件の整合） | 採用。その他の区域は0.3m→0.45m |
| 30°は排水しても摩擦だけでは安全率1.21で、1.5に届かない | VT12でも地震時0.93を確認 | 採用。30°は横断止め（地山に定着）を加える |
| 横断排水は20°で10m、30°で15m間隔（劣化後の透水0.01m/sの仮定） | VT12は劣化なし（0.1m/s）で164〜240mだった。目詰まりを考えると保守的なGPT案が妥当 | 採用 |
| 回収池は3,280〜4,000m³。10µmの微粉の沈殿に表面積約2,160m²が要る | 妥当 | 採用（沈殿池の拡張は単価未調査） |
| 4万m²規模では、石灰水が1回約155m³要る | VT6の2,000m²の値を拡大していなかった。妥当 | 採用（水の量・流れ方の設計が必要） |
| VT9〜11の模型の弱点（安息角なし、マスの重なり、埋め戻し率を仮定にしている、12通りの最大は最悪値ではない） | 妥当 | 次のVTで修正する |

## 2. 推奨断面（上から）

| 上部フィルター | 0.15m | 角ばった細かい砕石（D15≈2.6〜5.6mm。粒度曲線で照査） |
| 排水層 | 0.20m | 洗浄した角ばった砕石40〜20mm（固めない） |
| 段差の充塡 | 平均0.25m相当 | 構造用砕石C-40 |
| 下部フィルター（地山側） | 0.2〜0.3m（2〜3段） | 地山の粒度で選ぶ |
| 段切りした地山 | 高さ0.55〜0.58m×幅1.0〜1.5m | 表土・弱い層を除いたもの |

横断暗渠φ200：20°は10m間隔、30°は15m間隔。両側に幹線水路と落差工。30°は横断止めを追加。法尻には止め工・回収場所・調整池・沈殿池・中和設備を置く。

## 3. 施工の順番
1. 測量・地盤調査（ボーリング、土の強さ、地下水、凍上性）・設計
2. 工事用道路・仮設排水・濁水処理
3. 伐採・除根・表土はぎ
4. 段切り・法面整形（30°は横断止めも）
5. 下部フィルター → 横断暗渠・縦断集水管 → 排水層 → 段差の充塡 → 上部フィルター
6. HBG床を数cmずつ敷き、締め固め、石灰水で焼結する（施工方法は試験で決める）
7. 両側の水路・端部（ふとんかご）・回収池・沈殿池・中和設備
8. 細霧設備・センサー・電気と給水
9. 試験滑走 → pH・強度の確認 → 開業

## 4. 工事費の予測（直接工事費、税抜）

| 条件付き（凍上性の地山の置換） | 〜0.45億円 | 〜0.45億円 |
| **工事代金の予測**（諸経費×1.3〜1.6〔仮定〕、消費税10%込み） | **8.3〜34.9億円** | **8.9〜40.4億円** |

**金額の幅の最大の原因は、方解石粒の単価**（1.5〜10.8億円）。大口のトン単価が公開されていないため、下限は一般砕砂、上限は20kg袋の価格を使った。採石場への見積り依頼で、最も幅が縮む。
**計上していないもの**：急斜面の資材運搬（索道・ウインチ・モノレール。単価が見つからない）、敷均し・締固めの手間、地区・時点の補正、設計・許認可、電気・給水の引込み、石灰水の水量（1回約155m³）。

## 6. 全天候リスクの主な対策（GPT監査＋VT7・VT12）
| リスク | 対策 |
|---|---|
| 豪雨 | 上流からの清水を遮断水路で外す。横断暗渠10〜15m間隔。調整池4,000m³。雨の夜は石灰水を散布しない |
| 台風（80m/s） | 予報が出たら表面の緩い粒を回収する（3〜10mmで約200〜670t）。結合面の侵食は未検証 |
| 地震 | 30°は横断止めと段切りで抵抗させる（排水層だけでは、強震時の安全率0.93） |
| 凍結・凍上 | 凍結深さは1〜2.5m（積雪なしの場合）。冬の前に微粉を除き、出口を凍らせない。凍上性の地山は置き換える |
| 雷 | 閉鎖して避難（設備では滑走を続けられない） |
| 猛暑・乾燥 | 細霧（VT3）。乾燥時の発塵を管理する |
| アルカリ・微粉の流出 | 中和設備、沈殿池（表面積約2,160m²）、放流水のpH（一般排水基準5.8〜8.6）を管理する |

## 7. 結論
- **20°案が、費用・地震・施工のすべてで有利。** 30°は横断止めが必要で、費用が約0.6〜5.5億円増える。
- 工事代金は**約8〜40億円**（1km×40m）。幅を縮める順に、①方解石粒の大口見積り、②地盤調査、③急斜面の運搬方法の見積りが要る。
- HBG床の厚さはR10に合わせて最小0.45m。集中ゾーンは0.8m（U6の試験で締まりの強さを確かめてから見直す）。
