# VT第7弾：滑走で緩んだ後の状態と、雨の日（HBG-6案、2026-10-05、Claude）
スクリプト：[vt7.py](vt7.py)。斜面（40m×50m）を0.5mと0.25mのマスに分け、1日3,000本（100人×30本）の滑走を、乱数を変えて12通り計算した。物理実証ではない。

## A. 1日滑った後（17時）の斜面
| 項目 | 結果（マス0.25m〜0.5mの幅） |
|---|---|
| 緩んだ粒の層の厚さ | 平均2.8〜3.4mm、95%値7〜9mm、最大20〜25mm |
| 面積の割合 | 2mm以上が58〜67%、5mm以上が13〜21%、20mm以上はほぼ0 |
| 下地がむき出しの所（緩み0.5mm未満） | 5〜7% |
| 下地が削れた深さ | 平均2.7〜3.4mm、最大13〜15mm（ターンが集中する所） |
| 緩んだ粒の総量 | 8〜10t |
| 斜面の下端5mと場外に集まった量 | 1.7〜2.7t |

**状態のイメージ**：締まった下地の上に、数mmのサラサラの粒が乗る。ターンが集中する所には、ひと山1〜2cmの小さな粒の山ができる。削られて下地が出た所が、5〜7%まだらに残る。午後の圧雪バーンで「削れた硬い所」と「寄せられた雪の山」ができるのと同じ構図になる。
- 緩んだ層が数mmなら、エッジはその下の締まった下地に届く。止まれなくなることはない見込み。
- 安息角（緩い粒が止まれる最大の傾き）を、30°の斜面より急な場合（33°）と緩い場合（28°）の両方で計算したが、結果はほとんど変わらなかった。粒を運ぶのは主に滑走のずらしで、ずり落ちは従である。
- **夜の保守**：ピステンで、下端にたまった約2〜3tを斜面の上へ押し戻す。全面をならし、石灰水を散布して締め直す（緩んだ平均3mm、最大25mmの層を結合し直す）。雪の圧雪作業と同じ流れになる。
- マスの大きさで結果が15〜20%変わるため、数値は桁と傾向として扱う。

## B. 雨の日
| 項目 | 結果 |
|---|---|
| 表面を水が流れるか | 流れない。床は1時間あたり1,000〜10,000mmの雨まで吸い込める |
| 床の中の排水 | 砕石の排水層が薄い（透水0.01m/s・厚さ0.1m）と、50mm/h以上の豪雨で斜面の下部から水が湧き出す。**透水0.1m/s・厚さ0.2mの排水層なら、100mm/hでも余裕** |
| 雨がやんだ後 | 表層5mmは6〜19分で、深さ5cmは1〜3時間で、ほぼ通常の湿りに戻る。床の底は8〜28時間湿ったまま |
| 雨の最中の滑り心地 | 表層が水浸しに近くなり、しっとりからべしゃっとした感じ（春の雨の日の雪に近い）。雨がやめば数十分で戻る |
| 締まりへの影響 | 方解石の橋が雨に溶けるのは、30mmの雨で最大約3kg。毎晩の析出17kgの2割弱で、1日の雨で表層の締まりが1〜2割弱まるのが上限。酸性雨の影響は無視できる |
| 斜面の安定 | 締まり（c）が10kPa以上あれば、飽和しても安全率1.5以上（VT1） |

## 運用ルール（追加）
1. **雨の夜は石灰水を散布しない。** 床が水浸しだとCO2が届かず固まらない。散布した石灰水も、アルカリのまま流れて回収池のpHが上がる。雨がやんで表層が乾いてから（数時間後）散布する。
2. 雨の日の営業は可能。ただし、雨が強い間は質感がべしゃっとする。
3. 排水層は「透水0.1m/s・厚さ0.2m」以上で設計する。
