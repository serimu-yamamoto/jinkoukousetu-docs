# VT第5弾：ソールの傷と摩耗（1kmのコース×30本＝30km/日）（2026-10-05、Claude）
スクリプト：[vt5.py](vt5.py)。試行回数を1万→10万→100万→1,000万回と増やし、結果が変わらなくなる（収束する）ことを確認した。物理実証ではない。

## 結果
| 項目 | 結果（1,000万回） |
|---|---|
| 粒の接点のうち、ソールに傷（塑性変形）を残す割合 | 37% |
| 1本の溝の深さ | 中央5µm、95%値15µm、99.9%値30µm（溝の幅は数十µm） |
| 一様な摩耗 | 中央0.8µm/日（95%値18µm/日） |
| 個人で10日滑った累計 | 中央8µm（95%値180µm） |
| レンタル板で100日使った累計 | 中央78µm（95%値1.8mm） |
| 鋼エッジ | 丸い粒なら、方解石でも石英でも傷はつかない（接触圧は最大2.2GPa、塑性が始まるのは約2.7GPa）。方解石の粒のほうが先に砕ける |

## 保守で直せるか
| 傷・摩耗の大きさ | 見え方の目安（一般的な保守の常識。実測なし） | 保守 |
|---|---|---|
| 5µm前後（溝の中央値） | 白っぽいくもり程度 | ホットワックスで埋まり、目立たなくなる |
| 15〜30µm（95〜99.9%値） | 線傷として見える | ワックスだけでは埋まらない。定期的なストーン研磨（1回で約100µm削る）で消える |
| 100µm超のえぐれ | — | 今回の計算では出ない（角ばった破片が混じった場合は別） |

**結論：傷は「ワックス＋定期的なストーン研磨」で直せる範囲に収まる見込み。** 個人客が年10日滑る程度なら、ワックスの手入れだけでよい（中央値8µm）。レンタル板は、1シーズンに1〜2回の研磨が必要。

## 条件と注意
- **摩耗は、比摩耗量k（未測定）でほぼ決まる（順位相関0.99）。** 合格ラインは次のとおり。
  - レンタル板が1シーズン（100日）で研磨1回分を超えない：k≦4×10⁻⁶mm³/Nm
  - ソール厚のうち0.5mmまでを1シーズンで使ってよいとする：k≦2×10⁻⁵mm³/Nm
  - kは、ピンオンディスク試験（ソール片を床材でこする、安価な試験）1回で決まる。**物理試験の最優先候補に追加する。**
- **溝の深さは、荷重を受ける粒が少ないほど深くなる**（順位相関−0.81）。表面が平らにそろうほど浅くなる。溝の深さは粒の半径に比例するので、表層の粒を細かくするか、整地で平らにならすことで浅くできる。
- **方解石はエッジの下で砕ける。** その角ばった破片は、丸い粒の計算より深い傷をつける可能性がある。微粉・破片を回収池で取り除くこと（R28・R32）が、傷の対策を兼ねる。
- 細霧の運用（含水3%）では摩擦が下がるため、この計算（乾いた状態に近い条件）より傷は浅くなる方向。
