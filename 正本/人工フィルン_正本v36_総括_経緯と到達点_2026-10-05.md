## 1. 根本的な目的

### 1.1 目的

屋外・現地非冷却で、気温30℃級の夏でも、約30°の斜面で、**圧雪した新雪と同じ滑走性と爽快感**（沈み込み、エッジのかかりと抜け、横の支え、スピード、振動）が得られる滑走面をつくる。冬は天然雪の下地として、雪を余計に溶かさず定着させる。維持更新費を含めて採算が取れる、通年スキー場の素材・工法・運用を発明する（知財化を含む）。

### 1.2 依頼者の完成判断基準（3点）

1. 30℃の気温でも、圧雪と変わらない滑走感で滑れること。
2. 冬になれば、上に天然雪が降り積もって定着すること。
3. 経済的に合理性があること。

### 3.1 第29版まで（ChatGPT主導の研究記録）

### 3.2 2026-10-02：Claudeの監査とHBG-1

- **残した成果**：要件と概念を分ける体系。主要な式の算術は独立に再現できた（くさび模型、粘度上限8.172631mPa·s、六方向粒の体積、単価上限206.7145円/kgなど）。

  - PCLの価格は単価上限の3.3〜5.2倍。

  - 日射下で待機中に融ける。
- **HBG-1**：含水PVAゲルの破砕粒を、乾燥で結合させる案。後に撤回した。

### 3.3 2026-10-02：GPTとの往復（HBG-2〜HBG-3）

- **GPT「湿潤支持型」→HBG-2**：乾燥結合をやめ、湿ったまま粒の内部構造で支える方式へ。床厚0.45m。経済式Pmaxを導入。
- **GPTの検証→HBG-2 rev.1**：PVAゲルは37℃で摩擦が上がり傷がつく（Sasakiら2018）。毛管力（水の表面張力による粒の結合）を主な保持機構にしない。
- **GPT rev.2→HBG-3**：方解石の芯をPVAの殻で包む複合粒。
- **GPTの回答**：芯の露出は許容しない、方解石を優先、冬は自然雪の下地として扱う、殻密度の式を訂正。

### 3.4 2026-10-02：「30℃前後まで融けない雪状結晶」の再検討

- 融点30〜36℃の材料は、白くても日中に融け続ける（反射率0.8で8時間に10.9〜17.4kg/m²）。待機中に融けないためには、融点45℃以上かつ反射率0.8以上が必要。
- 融点30〜55℃で水のような液になる物質は、例外なく水に溶ける。水に溶けない結晶は、融けると油になる。
- 既知の候補（半クラスレート水和物、芒硝、炭酸エチレン、チオ硫酸Na、酢酸Na、パラフィン、脂肪アルコール、PEG、高圧氷）は、いずれも不成立だった。
- 超高圧の噴出では、水は温まり（約+22K）冷えない。結晶を作れても、屋外で保てるかは表面の熱収支で決まる。
- 帰結：屋外で成立するのは「水に溶けない固体＋水で潤滑と結合」の形で、PVA物理架橋が該当する。

### 3.5 2026-10-04：可溶材・屋根・造雪再生・雪定着

- 依頼者が、雨で溶けること、造雪のような再生、低コストの開閉屋根を許容した。これを受けて塩水和物（芒硝、硫酸Mg等）を再評価した。

- 冬の保冷：凍った含水床の効果を試算した。ただし過大な主張を含み、GPT v33で訂正された。

- **HBG-4**：カオリン微粉を分散させた、芯のないPVAゲル粒。湿潤冷却、閉鎖時の表層結合、冬の排水断熱で運転する案。

- GPT監査をほぼ全面採用した。
- **新しい発見**：圧雪の物差しで読み直すと、ゲル粒の床は雪より剛性が2〜3桁低い。「圧雪と同じ」に届かない主因は剛性だった。

## 4. 閉じた枝と理由

| 枝 | 閉じた理由 |
|---|---|
| 低融点PCLジオール（Capa 7201A等） | 粘度が潤滑模型の上限の38倍以上。価格が上限の3.3〜5.2倍。日射下で待機中に融ける |
| 融点30〜36℃の相変化材全般 | 白色でも日中に融け続ける。噴霧で補充すると毎日20〜90t（2,000m²）が必要 |
| 塩水和物（芒硝、硫酸Mg、リン酸塩、酢酸Na、チオ硫酸Na） | 凝固点降下で冬に雪を溶かす（判断4・5・6）。季節ごとに撤去しても残留塩が残る |
| 水に溶ける小分子の結晶（炭酸エチレン等） | 冬に雪を溶かす。分解生成物（エチレングリコール）も凍結を防ぐ |
| 水に溶けない有機結晶（パラフィン、脂肪アルコール） | 融けると油になる（R40）。価格も超過 |
| 超高圧噴出による急冷形成 | 結晶を作れても、屋外で保てるかは表面の熱収支で決まり、圧力では変えられない |
| 製雪機（本物の雪） | 固定条件により停止基準・比較上の勝者にしない。依頼者も固定の造雪機を望まない |
| 乾燥で結合させる案（HBG-1） | 乾燥は潤滑と相反する |
| PVAゲル単独・微粉分散のゲル粒床（HBG-2〜4） | 剛性が雪より2〜3桁低く、ベチャッと沈む。「柔らかい雪」の別商品としての比較枝に留める |
| 厚い殻の芯入り粒（HBG-3） | 芯が露出すると荷重が一粒に集中し、ソールの傷が増える。比較枝に留める |
| 6mm六方向粒 | 圧雪の粒の大きさ・形と合わない。比較用として残す場合は依頼者の明示が必要 |
| 側鎖結晶性ポリマー（G17、34℃） | 研究費を割かない記録枝 |

## 5. 現在の到達点

### 5.1 最終発明案 HBG-5

**定義**：丸い方解石粒の骨格を、薄い水和PVA膜で包み、粒の接点をPVAで結合した床を全深度に敷く。整地で結合を壊し、乾きで結合を戻し（湿度焼結）、噴霧でPVA膜と水分を更新して滑らせる。現地非冷却の人工フィルン滑走面である。

**雪との対応**

| 雪の要素 | 雪での役割 | HBG-5での担い手 |
|---|---|---|
| 氷の結晶粒 | 硬い骨格 | 丸い方解石粒（0.6〜1.5mm） |
| 焼結ネック | 粒の結合、硬さと粘着 | 接点に集まったPVA（乾くと強く、濡れると弱い） |
| 雪面の水 | 低い摩擦 | 水和したPVA膜と噴霧水 |
| 整地→夜の焼結 | 壊して締め、翌朝固まる | 整地で結合を壊す→夜に乾いて再結合 |
| 冷えるほど硬い | 温度で硬さが変わる | 乾くほど硬い（湿り具合で硬さを調整） |

**構成（第1案の提案値）**

| 要素 | 仕様 | 状態 |
|---|---|---|
