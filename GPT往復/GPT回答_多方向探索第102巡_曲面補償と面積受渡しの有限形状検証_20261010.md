# 多方向探索第102巡：曲面補償と面積受渡しの有限形状検証

2026-10-10 / Codex。**物理試験0件、成功確率は未算定（null）。** 設備・協力先は未確保。今回の成果は、2種類の局所接触構造を有限な移動範囲で反証・比較した計算である。

## 設計の更新

第101巡で求めた「縦の支持力を落とさず、横の拘束を外す」を、曲面で渡す案H102-Cと、同じ高さの受け面の接触面積で渡す案H102-Aへ分けた。**高さ一定、合計接触面積一定、支持力の連続性は、それぞれ別の条件だった。** どれか一つを満たすだけでは雪状の滑走を保証しない。

H102-Aは細い排水隙間を残した2面構成を次の候補とする。ただし入口の圧力集中が新たな課題になった。完成した粒の設計・製造・50℃性能を実証したものではない。

## 曲面で渡すH102-C：横抵抗を消すと持上げが残る

同じばね剛性kを持つ2接点に、一定法線力F0を渡す。δ0=F0/k、移動距離L、w=u/Lとする。2面の高さを、基準高さを省いて次で与える。

- hA=δ0[1−w+c w(1−w)]
- hB=δ0[w+c w(1−w)]

c=0なら設計荷重F0で上側の高さは一定だが、弾性エネルギーが変化し、可逆な横抵抗の最大値はF0δ0/Lとなる。**押上げがなくても横抵抗は残る。**

c=1でエネルギーを補償すると、同じ設計荷重ではこの横抵抗がゼロになる一方、上側は途中でδ0/4だけ持ち上がる。摩擦ゼロ・回転拘束・準静的な模型内の結果であり、実際の摩擦がゼロという意味ではない。

荷重を0.5F0にすると補償後も最大横抵抗はF×0.5δ0/Lとなり、2F0では出口で元の接点に全荷重の25%が残る。このまま接点を打ち切ると、第101巡で問題にした支持力急落を再導入する。**一つの荷重で補償できても、滑走中の荷重変動への適応は未解決。**

## 面積で渡すH102-A：排水隙間を残す局所構図

下側の一粒の枝に、同じ高さの受け面A/Bを設ける。別の一粒の受け面が横へ動き、A上の重なりを減らしながらB上を増やす。コースへ敷き詰めるマットや連続シートではない。

```text
移動方向 →      下側の受け面の配置（平面投影）
x=0             L   L+g             2L+g
  [------ A -----]   [------ B -------]
                    ↑ 開放隙間 g

上側の有限な受け面の投影：[ u, u+L+g ]、0 ≤ u ≤ L
Aとの重なり長さ=L−u、Bとの重なり長さ=u
共通幅=bなら、重なり面積の合計は Lb のまま
```

独立した圧縮ばねの集まりとして両受け面を近似すると、回転を固定した場合、支持剛性・沈み込み・弾性エネルギーは移動中一定になる。ただし、必要な拘束モーメントはFg(w−1/2)。**周囲からこのモーメントを受けない自由粒に、回転固定の良い結果を流用できない。**

そこで上側の回転を自由にし、圧力を引張りにしない条件で力とモーメントを解き直した。排水隙間の比γ=g/Lが大きいほど、傾き・部分接触・入口圧力が増える。

| γ=g/L | 出口／入口端での沈み込み δ/δ0 | Bに触れ始める直後の圧力／基準平均圧力 |
|---:|---:|---:|
| 0.10 | 1.030 | 1.360 |
| 0.25 | 1.1875 | 2.125 |
| 0.40 | 1.4815 | 3.2099 |
| 0.75 | 3.5556 | 16.000 |

ここでδ0=F/(k_a bL)、k_aは仮の面積当たり圧縮剛性。圧力の列は**新しい面への接触開始の極限値**で、実材料の応力ではない。接触開始時のBの合力は0へ近づいても、局所圧力は0へ近づかない。合力が連続だから摩耗しない、とは言えない。

γ≤1/3の全接触範囲では、端の沈み込みは1+3γ²倍。γ=0.10で移動中の高さ変化は0.03δ0、γ=0.25では0.1875δ0。回転自由の場合には可逆な横抵抗も戻り、その端の値Q/Fは、それぞれ0.0798δ0/L、0.7265625δ0/Lとなる。

201点の粗い移動刻みでは入口圧力を過小評価したため、接触開始直後を別に解析し、移動比10⁻²〜10⁻⁸で照合した。[入口極限の計算](曲面補償と面積受渡しの有限形状検証_20261010/boundary_limits.json)

## 次の形状条件

1. **幅のある丸い入口を設計する。** 鋭い前縁へ瞬間的に圧力を掛けない。ただし丸めると面積一定の条件が崩れるので、形状を入れて再計算する。丸めれば解決するとは未確認。
2. **排水と荷重を同じ形で確認する。** γを小さくすれば力学的変動は減るが、毛管付着・目詰まり・凍結閉塞が悪化し得る。本巡の隙間率は排水能力ではない。
3. **枝と受け面を一粒内に収める。** 個別の軸・組立ばねを足さず、開いた枝の一部に受け面を作る案。ただし全姿勢でこの受渡しが起きるとは仮定しない。
4. **横方向の切れを失わない。** 面を広げすぎると、砂状の硬さやマット状の支持へ近づく恐れがある。実スキーの侵入・せん断・解放・振動を別に比較する。
5. **除荷復帰を別に確認する。** 正のばね定数を仮定した計算は、50℃での長時間クリープ・摩耗後復帰を保証しない。

これらは粒同士の局所接触案であり、下側粒も動く3次元の床、全粒の力・モーメント釣合い、繰返しの接触ネットワークをまだ解いていない。準静的保存エネルギーの横抵抗には、前縁の押しのけ、衝撃、粘弾性損失、摩擦を含めていない。

## 材料・製造・費用への接続

成形する枝状高分子、弾性根元と接触表面の複合粒、結晶粒の首と受け面へ、この条件を共通に適用する。今回の成形形状は、雪の結晶成長を再現した証拠ではない。30℃以上での噴霧結晶化案も探索に残す。

受け面全体の外形長さW=2L+gを固定すると、γ=0.25で接触面積は隙間ゼロ案の88.9%へ減る。同じ面積へ戻すには幅を12.5%増やす必要がある。γ=0.75では面積72.7%、必要幅増加37.5%。**排水隙間は、寸法・必要剛性・材料量との交換条件になる。** これは幾何の比で、金型費、完成材料価格、歩留まりや採算の見積りではない。

整地設備2億円という従来の予算枠と素材費を分ける。雨後は回収重量だけでなく、受け面の摩耗・隙間の閉塞・圧力分布まで戻るかを確認する。60分内の復旧、冬の雪→粒→床→地盤の接続、人体・環境への無害性は未実証の独立条件として維持する。
