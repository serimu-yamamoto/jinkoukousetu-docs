# 第19巡の再計算
このフォルダは質量・熱・費用の条件比較を保存する。物理試験なし、成功確率未算定。

- inputs.json：全入力と仮定。第18巡の運用・予算を継承。
- calculate.py：Python標準ライブラリだけで計算する。
- results.json：60工程ケース、製粒収支、費用境界、Pe、脱水、交換在庫。
- validation.json：142項目の数値整合確認。物理の妥当性試験ではない。
- sources.json：一次資料の種類・読取範囲・転用の限界。
- 試験仕様.md：未実施の材料比較と評価段階。

Python 3で、このフォルダのcalculate.pyを実行すると結果と照合記録を再生成する。例：`python calculate.py`。作業環境でRTK指定がある場合はその方針に従う。追加ライブラリ不要。

費用は税抜の仮モデルで見積書ではない。2%補充は購入費の入力で、環境流出の許可値ではない。抵抗加熱の潜熱比較を、熱回収等を含む全方式の最低コストと呼ばない。bは処理粒中の接合相乾燥比、fは全床に対する処理量比、wは原料液の乾燥物比で、互いに異なる。
