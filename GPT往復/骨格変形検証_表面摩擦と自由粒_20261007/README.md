# 第14巡：自由粒の骨格変形と内部補強

[研究報告](../GPT回答_多方向探索第14巡_骨格変形と内部補強の費用条件_20261007.md)を先に読む。物理試験0、実物成功確率未算定。結果は指定した静的釣合い荷重への線形骨格応答で、実際の接触配分、粒群床、雪感、材料合格ではない。

## 再現

Python 3.12.14で実行。requirements.txtのNumPy/SciPy/Matplotlibを使用した。リポジトリ全体が必要で、第13巡の保存済み接触データと費用入力を読み込む。任意のPython環境へ依存関係を入れ、当フォルダで次を順に実行する。

~~~text
python -m pip install -r requirements.txt
python calculate.py
python brace_scan.py
python economics.py
python verify.py
python plots.py
~~~

元環境ではプロジェクト直下の一時 .deps をPythonパスへ追加して実行した。配布対象はソースと結果だけで、依存ライブラリ本体や作業用Git履歴は含めない。

- elastic_free.py：曲線・直線梁のコンプライアンス積分、自由粒の基準除去、表面力と局所偶力、応力と変位。
- calculate.py / elastic_results.json：第13巡の18荷重例。inputs.jsonはこの基準形状・材質・積分数の記録。開口150°と診断閾値はコードで固定されている。形状寸法の変更時は第13巡の接触データを再生成する必要がある。
- brace_scan.py / brace_results.json：Y3/T6・直径20/28/36/44µm。半径・E等はelastic_free.pyの既定値と一致させて比較。支持治具はC3・姿勢3・上面μ0・粒間μ0.6の一例。新部材の距離は解析被覆を使う数値上下限。変形後の接触、挿入経路は含まない。
- economics.py / economics_results.json：前巡の費用条件を引き継ぎ、11形状×密度2条件。体積の重複控除なし、見積りではない。
- verify.py / verification.json：47項目の解析・数値整合検査。試験件数や合格率の統計に転用しない。
- plots.py：構図・剛性と隙間・費用の図3点。図は計算モデルの説明用。
- C3_Y3_concept.scad / C3_T6_concept.scad：追加材28µmの概念形状。未コンパイル。製造用STLや金型設計ではない。

## モデルで解いていないもの

接点の法線/接線変位整合、摩擦のすべり履歴、変形による接触の追加・解放、幾何非線形、接合部応力集中、実材料の粘弾性と破壊、製造公差、熱、水、摩耗、飛散、排水、実物での費用と雪感。線形域を超える数値は感度と診断のために残している。

厚さ450mm、削れ代300mm、設備の税込2億円枠、閉鎖60分は変更していない。前二者を安くするため薄くする試算ではない。
