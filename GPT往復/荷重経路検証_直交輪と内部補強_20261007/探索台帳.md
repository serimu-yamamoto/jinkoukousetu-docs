# 第11巡 探索台帳

| 試した方向 | 計算・資料で分かったこと | 次の扱い |
|---|---|---|
| R2-Lをそのまま強い床とする | 指定背面固定の長い自由端は、片側荷重への初期変位感度が大きい | 接続経路の合格を荷重支持へ拡張しない |
| 材料を足すだけの直線筋交いR3 | 45条件のうち44で登録経路に衝突。残りも約1µm余裕。細い圧縮筋交いの座屈尺度も小さい | この経路の剛体補強候補から外し、補強経路を変更。全ての姿勢や柔軟な挿入を不可能としたわけではない |
| 中央の閉円R4 | 円へ迂回することで、調べた20条件で登録経路に正の中央寸法余裕 | 公差・自由姿勢・再接続を別に調べる。20/20を100%成功としない |
| R4-64 | 仮密度159.6kg/m³、4点圧縮の改善約1.15倍 | 単純な部材追加の不利を示す比較対照 |
| R4-120 / 150 | 自由端を短くすると4点圧縮の初期剛性が同開口補強なし比3.66 / 6.63倍。指定経路を維持 | 2形状STL/SCAD保存。保持・エッジ解放と自由姿勢を次の優先にする |
| Eを大きくする | 同一形・一様材料なら変位感度は1/E | 実際の50℃物性、摩耗、密度、費用が伴うまで採用しない |
| 発泡PEの粉砕分級 | 製造工程を簡単にする別方向は特許にある | 展示雪の記述をスキー床の実績にしない。量産の対照枝として残す |
| 凍結吸水粒 | 粒・接点・空隙の分布を参考にできる | 現地非冷却50℃の条件とは別の枝 |
| 固体潤滑材＋樹脂粒 | 支持と滑走を別に扱う先行記述 | パラフィン等を採用して冬の固着条件を置き去りにしない |

維持する条件：30℃以上の気温、約50℃表面、雪の圧雪感、300mmの深い削れ、60分程度の閉鎖、30°斜面、閉鎖時80m/s、冬の固着と界面排水、豪雨回収、人体・用具・環境、設備予算と材料費の区別。今回、各条件の実物合格は増えていない。

次は、実粒の姿勢と接触点が変わると4端均等荷重の利点がどれだけ残るかを検証する。そこで利点が消えるなら、自由度をさらに微細部品で埋める前に、別の骨格・接点・製造原理へ戻る。
