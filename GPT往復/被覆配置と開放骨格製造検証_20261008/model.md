# 第34巡 計算定義と限界

全入力は inputs.json、全出力は results.json、数式と収支の照合は validation.json。物理試験0件、物理成功確率null。実測摩擦、耐久、スキー雪感の推定器ではない。

## 密度・被覆・重量

D=母粒の包絡直径、d=子粒直径。母粒の包絡密度ρhは母粒内部の空隙を含み、床の粒間空隙は含まない。床の母粒かさ密度はρh×充填割合φ。本例は240×0.5=120 kg/m³。樹脂真密度でも重合粉末の実測かさ密度でもない。粒径450 µm、φ=0.5、外表面倍率α=1は仮定。

C=幾何学的な面積被覆予算。粒の荷重支持割合でも実被覆率でもない。αは対象外表面を球の表面積に対する倍率で表す仮の感度。内部BET表面積をそのまま使わない。枝粒の実面積はCT等で別測定する。

理想球の個数予算（S1式1/2へCαを付加）：

~~~text
N = 4 C α ((D+d)/d)^2
q = Mguest/Mhost = N (d/D)^3 ρg/ρh
  = 4 C α (ρg/ρh)(d/D)(1+d/D)^2
wguest = q/(1+q)
~~~

Nは連続値の数量予算。格子充填・曲率・多層・変形・付着効率を解いていないため、C=1で隙間なし実被覆を保証しない。S1の計数効率とも違う。

薄い局所膜の平面近似は q=6 C α ρg t/(ρh D)。孔を塞ぐ完全な球殻ではなく、接触候補面の膜体積を面積×厚さで概算する。膜厚t≪局部曲率半径・枝厚が必要であり、切断面、膜端、凹面、接合相は別途加算する。付着不良や必要厚さはモデルにない。

床母粒量M=A h ρh φ。追加材Mg=qMを加え、床の外形体積一定として密度増を一次評価。被覆で包絡径・充填率が変わる効果は未計算。したがって床厚を厳密に保証する充填モデルではない。

## 発泡前後の被覆

一様な等方膨張倍率B=Vafter/Vbeforeでは線寸法s=B^(1/3)、面積倍率s²。

- 子粒の個数・大きさ・投影面積が変わらず脱離しない場合：Cafter=Cbefore/B^(2/3)。
- 接合された部分膜が母材とともに一様に伸び、裂けず、膜体積一定の場合：Cafter=Cbefore、tafter=tbefore/B^(2/3)。

後者は二軸変形と界面追従が成立する場合だけ。再配列・開孔による新生面、非等方膨張、膜の収縮・破断・剥離は別問題。膨張倍率10で得た値を任意の製法へ一般化しない。

## 扁平子粒の曲率と有限の幅

半径rの球を体積一定の軸対称扁平楕円体へ変形し、投影面積倍率gを置く。

~~~text
a = r sqrt(g)       横半径
c = r/g             縦半径
a² c = r³
Rtop = a²/c = r g²
aspect = a/c = g^(3/2)
g = sqrt(Rtarget/r)
~~~

母材の曲率は加算せず平らな支持面を仮定する。半球状の母粒面上では実効曲率が変わる。実際の子粒は軸対称とも体積保存とも限らない（破砕等）。S2の平均aspectをgへ変換した値は、同じ形状クラスだと仮定した比較目安であり、文献粒の平均形状を再現した値ではない。

接触半径 aH=(3 F R/(4E*))^(1/3) を均質弾性体の幾何診断として計算。aHが子粒の幅aを超えるなら、同じ子粒を無限に広い接触部と扱えない。膜厚が接触半径よりはるかに小さい本例で、Hertz式を被膜の応力・摩耗予測に使わない。実際には層状接触・基材変形・界面剪断が必要。

余裕kでa≥k aHを要求すると、必要初期半径r≥((k aH)^4/R)^(1/3)。材料強度や製造可能性の条件は含まない。

## 費用と能力

~~~text
Ctotal = (M ch + Mg cg + (M+Mg) cp) / Y
Cincrement = Ctotal - M ch
Cannual = replacement_fraction * Ctotal
Q = Vchamber * fill_fraction * bulk_density * 60/(process_minutes+handling_minutes)
~~~

ch=未被覆骨格材の仮単価、cg=被覆材仮単価、cp=複合化処理の仮単価（投入合計質量基準）、Y=良品歩留まり。処理費は配合後投入粉体1kgあたりで、良品1kgの処理費とは区別する。損失材の売却・回収価値は0、歩留まり不良で骨格材も失うものとして計上。年交換費は同じ良品仕様の交換比率による。

単価は見積でなく感度仮定。税・輸送・施工・工場固定費・設備投資・除塵・検査・回収再生・洗浄処分・金利は未含有。別計上する費目を処理委託単価へ内包する場合は二重加算しない。試算は2億円以内を保証しない。100/1000 Lは仮装置で、同一回転数や同一時間の相似則を主張しない。

## 損耗と摩耗余裕

各サイクルで残存被覆のεが外れ、途中で補充しない場合、n回の剥離量は Mg[1-(1-ε)^n]。捕集割合ηで回収できれば未捕集量はその(1-η)。εとηは実測ではない。粒径・粉塵経路・排水への流出割合や有害性は別に測る。

膜の半分をn回後に残す仮仕様なら、均一減肉の平均許容量は 0.5 t/n。局所傷・膜の剥離にはこの平均式は使えない。摩耗速度を予測する式ではない。
