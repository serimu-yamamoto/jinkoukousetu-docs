## 方法と限界

軸ばね、初期応力0、微小変形、上下の剛体端面という境界条件を置く。各方向の単位変位は線形応答の係数計算であり、大変位試験ではない。Kの対角値と、xy部分の最小固有値を分ける。z変位を許したせん断はSchur補元で併記する。内部自由度を最小二乗法で緩和し、反力とエネルギーを照合する。

模型に摩擦・曲げ・回転・慣性・液橋・破壊進展・実粒接触生成はない。空間配置の反例を識別するための計算で、50℃床の滑走性能や全床剛性を予測しない。方向を対にする改良は二群分散より良い本例を持つが、中央寄り配置を上回らない結果も保存する。最適解とはしない。

座標ずれは接続関係を固定し、各ばねを新しい自然長で開始する。製造公差・初期応力・粒の接触消失のシミュレーションではない。サイズ3条件は有限模型の比較であり、山全体の収束証明ではない。仮費用は価格見積りでも補充削減の予測でもない。
