# モデルの再現と境界

## 実行

Python 3の標準ライブラリだけで calculate.py を実行すると、入力JSONから結果JSON、CSV、数値照合JSONを再生成する。図のみ draw.py と matplotlib が必要。任意の隔離環境に matplotlib を導入して利用できる。計算ディレクトリ外の一時的な .deps があれば優先するが、研究成果には同梱しない。

    python calculate.py
    python draw.py
    python audit.py

## 実装上の重要点

時間 s=t√(k0/m)、変位 u=x/x0、速度 w=du/ds、Maxwell枝力 z=q/(k0 x0) に無次元化する。

    u'=w
    w'=-u-z+f   （接触中の最初の負方向滑り）
    z'=αw-z/r
    d_visc'=z²/(αr)
    d_friction'=f|w|

無次元エネルギーは (u²+w²+z²/α)/2。α=0は枝を除去し、0除算しない。力 f=Fk/(k0 x0) は滑り方向に対応する定数であり、速度の符号を越えて永久に適用しない。

RK4、基本刻み0.005、計算窓s=200。初回の停止は速度の負→非負イベントを検出し、刻み内を45回二分して速度0を求める。その場の保持力と、枝の緩和後の保持力を別に照合。停止後の圧力変化・再滑りは計算していない。初期静止から滑り始める直前の条件は第60巡から与える。

自由復帰は f=0 とし、別の初期値 u=1,w=0,z=0（またはz=1）から計算する。接触中の残留状態をそのまま渡したものではない。最大1.897 ms（名目質量）の窓内で、変位だけでなく総エネルギーの条件を満たす時刻を求める。収束していない場合は null を返す。

収束条件：|u|≤0.1、U≤0.01 Uinitial、U≤0.005 k0 x0²。最後の条件は、枝に初期力がある場合も未来の変位を0.1 x0以内に抑えるため。Uには運動エネルギーとMaxwell枝の蓄積も含む。外部入力も再接触もないこのモデルでは U は単調減少するので、条件到達後に上限を破らない。

複素剛性：

    K'(ω)=k0+kd (ωτ)²/[1+(ωτ)²]
    K''(ω)=kd ωτ/[1+(ωτ)²]

単枝では tanδmax=α/[2√(1+α)]、ωτ=1/√(1+α)。損失係数と減衰比の弱減衰近似は使わない。物性の時間温度換算を実施した計算でもない。

## 数値検査が保証する範囲

29照合は、弾性極限の正弦解、摩擦の最初の停止位置と時刻、前巡の未処理エネルギーとの対応、運動／弾性／散逸エネルギーの帳尻、刻み幅半減、初期材料記憶、せん断体積式を確認する。実物の材料、可動域、製造公差を保証しない。

初回停止で摩擦比を変える表は解析式。仮定した質量は時間に効くが停止位置には効かない。付着を変えた比較では、最初の静摩擦限界になる法線反力も変える。H60のNを固定したままTaだけ変えた表ではない。

## 省略した物理と設計値の意味

- 法線方向の慣性、三次元連成、分布質量、片持ち梁の高次モード、接点法線の回転。
- 圧力履歴、液橋の形と時間依存、摩擦の速度・状態依存、衝突・硬いストッパー。
- 有限ひずみ・塑性・損傷・疲労・熱・吸水によるパラメータ変化。
- 粒群の支持網、全粒の反発、板の滑走・エッジ・転倒、冬季界面・雨後復旧。

有効質量2.5 µg、k0、kd、τ、摩擦と付着は未測定。α=1,r=1の収束が良好でも、その材料が存在・量産・安全適合する証明ではない。新しい樹脂を合成した結果も含まない。

材料体積は、パッド全体に一様なせん断を許す最も効率的な場合の線形モデル下限。許容ひずみやΔGは感度条件であり、既存銘柄の保証値ではない。20×20×5 µmパッドは寸法例にすぎず、118％を線形則で許容できるという結論にはしない。

第32巡は板接触の法線方向の低周波履歴、本巡は微小接点の局所質量を含む過渡。互いの周波数・荷重・散逸を無条件に流用しない。
