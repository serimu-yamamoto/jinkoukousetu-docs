# 第94巡：根元配置の模型と数値照合

[入力](inputs.json)／[再計算](reproduce.py)／[結果](results.json)。材料の50℃弾性率、復元率、接合強度は未測定。61件の照合は条件付き計算の検証で、雪状性能の実証ではない。

## 梁の比較

長さL=0.75mm、幅b=0.72mm、厚さh=0.12mm、先端力F=5.625mN。片持ち・一定断面・小変形を仮定。母材E_b=500MPa、根元E_r=100/200/500/1000MPaはすべて仮の50℃値で、特定グレードに割り当てない。

根元長をa=αL、I=bh³/12、p=1−(1−α)³とすると、曲げによる先端コンプライアンスは

~~~text
C / C_body = (1 − p) + p E_b/E_r
delta = F L³/(3 E_b I) × C/C_body
同じ変位での力比 = 1/(C/C_body)
根元の弾性エネルギー比 = [p E_b/E_r] / [C/C_body]
~~~

このエネルギー比は回復率でも、疲労寿命比でもない。実際の残留変形を戻すには、位置ごとの不可逆曲率・粘弾性回復・接触拘束を測る必要がある。

α=0.1、E_r=200の例：根元75µm、曲げ変位21.4615µm、同じ変位での力比0.710985。根元長／厚さ=0.625で、短い区間を独立した細い梁とみなす限界がある。界面の単純な曲げ応力尺度は2.197MPaだが、接合部の最大応力・剥離強度・必要接着強さではない。力を10倍にした線形変位はLの0.286倍となり、小変形近似による実性能予測には使えない。

## 二次元有限要素による別照合

Q4四辺形要素、2×2 Gauss積分、平面応力、等方線形弾性、ν=0.45。左端を固定、右端へ一様せん断荷重。厚さ方向を解析平面、幅bを面外厚さとする。完全接合・同一断面を仮定し、接合層の厚さは0。幅が有限の実粒を三次元再現したものではない。

30×6、60×12、120×24の3メッシュで、均一母材／根元10％／根元40％／全長柔材の4条件を計算。最細2,880要素・6,050自由度。最細化前後の平均先端変位差は0.506〜0.609％。この収束は当該境界条件の全体変位についてで、界面端の最大応力の収束や実材の妥当性を証明しない。

要素の対称性・剛体並進・非負エネルギー・一定ひずみパッチ、全体の力とモーメント釣合い、外力仕事とひずみエネルギー、均一Eの比例則を照合。単純梁とは分布荷重・固定端拘束・せん断が異なるため、完全一致を要求しない。節点の局所応力や復元の過渡計算は実施していない。

## 重量と原料差額

基準135,000kgを仮密度930kg/m³の固体として同じ固体体積を比較。新材は比重1.25に対応する計算用密度1,250kg/m³。実床の充填率や必要厚さが同じになる保証はない。

粒の固体体積のうち枝がβ=0.8という仮定なら、根元長10％は体積置換率f=βα=0.08。実際の中心部・先端の体積をCAD等から求めるまでこのβは未確定。

~~~text
M_body = M0 (1 − f)
M_root = M0 f rho_root/rho_body
原料差額 = M_body p_body + M_root p_root − M0 p_body
追加加工費 = (M_body + M_root) q
~~~

f=0.08、仮単価PE500円/kg・新材1,500円/kgでは重量138,716.1kg、増加2.7527％、原料差額16,374,194円。加工が完成材全重量に100円/kg加わるなら、別に13,871,613円。全固体置換f=1では重量181,451.6kg、原料差額204,677,419円。税・接合材・製造設備・歩留まり・検査・施工・補充・廃棄は未算定。見積りや材料の実売価格ではない。

24梁条件・12有限要素条件・27費用条件の計算割合を成功率へ換算しない。
