圧力上限12条件、逆算条件16件、接点48条件、接触相費用12条件、荷重分担3条件。高さ分割の追加計算や数値照合を実物の試行数へ数えない。接点の小変形スクリーニングも材料の成功判定ではない。新たな温度別係数や価格を入力する場合は、出典と実測範囲を追記して再計算する。
