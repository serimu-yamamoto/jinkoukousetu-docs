# H33の計算式・定義・限界

## 1. 圧力上限から接触面積を制約する

接触面積A_real、局部圧力p(x)、全荷重Nを用いる。すべての接触点でp(x)≤p_capなら、N=∫p dA≤p_cap A_realなのでA_real≥N/p_cap。p_capは仮の上限で、実材料の耐摩耗値・降伏値・人体安全値ではない。

局部の凝着せん断応力をτ(x)=τ0+βp(x)と仮定すると、F_adh=τ0 A_real+βN、μ_adh=τ0/p_area_mean+β。面積平均圧力p_area_mean=N/A_realは、板の公称圧、Hertz接触の最大圧、S1の比較図にあるp_max,planeと同じではない。

したがって、その他の抵抗をμ_oと仮置きすれば、μ_total≥μ_o+β+τ0/p_cap。目標μ_Bに対しβ≥μ_B−μ_oなら、τ0>0では有限の圧力増加だけで達成できない。β<μ_B−μ_oなら必要条件p_cap≥τ0/(μ_B−μ_o−β)、同値にτ0≤(μ_B−μ_o−β)p_capとなる。

これは仮定した線形せん断則と圧力上限の下での必要条件。S1のフィットを大きく外挿して得る70〜200MPaを設備・接点の設計推奨値にしない。速度・温度・材料対・移着膜状態でτ0、βは変わり得る。降伏・摩耗・発熱・エッジ支持・人体環境の条件は別に残る。

## 2. 高さが異なる接点と弾性根元

板の幅b、長さL、仮想配置間隔d、配置割合fから、接点候補数n_site=bL f/d²を置く。高さは−hから+hの一様区間を中点則で分割する。積分の重みは接点数であり、確率や試験成功率ではない。

各点は曲率半径Rの球面冠と、剛性k [N/m]の線形根元を直列に置く。Rは局所曲率で、粒全体の半径ではない。500µmの曲率半径も、直径450µmの粒にある浅い球面冠として幾何を比較できるが、その製造を確認したわけではない。

板の接近量z、高さh_i、u_i=z+h_iに対して、u_i≤0は非接触。接触時は、

~~~text
F_i = (4/3) E* sqrt(R) δ_i^(3/2) = C δ_i^(3/2)
u_i = δ_i + F_i/k
a_i = sqrt(R δ_i)
A_i = π a_i²
p_mean,i = F_i/A_i
p_peak,i = 3F_i/(2A_i)
~~~

剛な根元は1/k=0。zは全接点の加重和Σw_iF_i=Nを満たすよう二分法で求める。実接触面積Σw_iA_i、接触点数、最大局部圧力、根元の最大変位を保存する。反対側のスキーを含む弾性はE*という仮の合成値で表す。

模型は摩擦のないHertz法線接触を荷重分配へ使い、その後に凝着則を当てる分離近似。摩擦が接触形状へ与える影響、塑性・粘弾性、温度、根元の座屈、大変形、粒の転動、相互干渉、側壁、H32の横解放は解いていない。無拘束の粒床や曲がった板の実状態と同一視しない。

a/R≤0.1は小接触を点検するための仮のスクリーニング。通過しても弾性・無摩耗は証明されない。超えた点はHertz近似を点検する警告として表示し、予測として採用しない。本計算では16/48条件がこの幾何チェックを通るが、16/48を材料合格率にしてはならない。鋭い接点の枝で警告が多かったため、R=500µmの浅い冠を追加した。

## 3. 力の観測だけではτ0を一意に決められない

F_adh=τ0 A_real+βNにおいて、全A_realをs倍し、τ0を1/s倍してもF_adhは変わらない。接触面積が不明なまま摩擦力をよく再現しても、τ0の一意な同定にはならない。独立した面積情報、妥当な接触モデル、複数の荷重・形状・履歴が必要。S1の研究を否定する意味ではなく、別の粒床へ転用する際に追加確認すべき条件である。

## 4. 少量の接触相と荷重分担

二種類の接触相が受ける荷重割合をwと1−wとする。μ_L、μ_Hを仮定すると、μ_interface=w μ_L+(1−w)μ_H。μ_total=μ_interface+μ_o≤μ_Bにはw≥(μ_H−μ_B+μ_o)/(μ_H−μ_L)。係数一定・成分加算の模型であり、実粒では荷重・速度に依存する。

このwは質量割合ではない。低抵抗相の局部圧力にも同じ上限を置けば、その実接触面積はA_L≥wN/p_cap。接触材5wt%を混ぜたことは、荷重の70%を受け持つ証拠にならない。混ぜた材料が接点に出るか、雨・整地・摩耗後にも残るかを確かめる。

## 5. 費用

床質量M=面積×深さ×仮床密度。接触相への仮の質量割合f_mと単価差Δcから追加材料費ΔC=M f_m Δc。Δcは見積価格ではない。製造歩留まり・接合・造粒・分別・洗浄・輸送・年間交換・下地・整地設備は含まない。

## 6. 数値照合

全荷重の釣合い、面積積分による凝着力、圧力下限、不変な単位換算、等しい高さの解析解、変位変数と力変数を別々にした接触解、101→202→404高さ分割の面積収束を照合。ソフトな根元による圧力低下と面積増加、τ0と面積の同定不能性、質量と荷重分担の区別も確認する。25項目の詳細はvalidation.json。すべて数値確認で、物理試験数は0。
