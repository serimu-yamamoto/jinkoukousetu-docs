# 第26巡・接点再接合検証

[本文](../GPT回答_多方向探索第26巡_自己修復接点の保持時間と雪らしい解放_20261008.md)。H26は、支持骨格・一時的な接触保持・少量の再接合相・短い界面解放を組み合わせる候補。製造や物理試験の達成を意味しない。

物理試験0件、実物成功確率null。文献の強度回復率、本模型の接点化率、研究全体の成功率を分ける。入力は未校正の仮定。元の材料比較面積2000m²と、機械の運用面積20,000m²を混用しない。

## 内容

- [inputs.json](inputs.json)：機械・接点反応／離脱・時間尺度・凝集力・費用の仮定、Claude資料の読取コミットと照合ハッシュ。
- [calculate.py](calculate.py)：標準Pythonのみで計算。接点48、機械圧力12、面積率と接触数60、凝集力36、費用27条件。時間尺度比較も保存。
- [results.json](results.json)：全計算結果、独立RK4と数値積分の照合、面積別初期費用、Claude表の件数・採点式監査。
- [validation.json](validation.json)：28項目の数値整合確認。全項目通過。実物検証とは異なる。
- [plot.py](plot.py)：図2点の再生成。使用版Matplotlib 3.11.2、NumPy 2.5.3。
- [接点保持とローラー](01_retention_and_roller.png)、[解放距離と費用](02_release_and_cost.png)。図中のt90は接点数の仮時間であり、特定材料の引張強度回復時間ではない。
- [sources.md](sources.md)：一次論文11件の出典・読んだ範囲・適用しないこと。
- [publication-manifest.json](publication-manifest.json)：公開する13ファイルのバイト数・SHA256。manifest自身は循環を避けて表から除外し、公開後照合の対象に含める。

## 再計算

リポジトリ全体を取得し、このフォルダを作業ディレクトリとして実行する。

~~~text
python calculate.py
python plot.py
~~~

calculate.pyはリポジトリ内の「バーチャル試験/自律ループv2_噴霧結晶化素材_第1〜4ラウンド_20261008.md」を読む。参照した原文のコミットはa061c984c343a199b81cfef98b4d2fd660343180。改行をLFに正規化してSHA256を検査する。後日に原文が更新された場合は、本パッケージ公開時のコミットを取得して再現する。原文に記載された開発サーバーのスクリプトは実行していない。

描画ライブラリは通常のPython環境から利用できる。plot.pyは補助的にリポジトリの.depsも探索するが、ローカル依存ライブラリは成果物として保存しない。数値計算は外部ライブラリ不要。

kineticsのseparation_time_s=nullは「離脱なし」という明示した比較条件であり、未知値の補間ではない。evidenceのphysical_success_probability=nullは未算定を意味する。両者を区別する。
