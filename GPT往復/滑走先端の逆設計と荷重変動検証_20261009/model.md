# 第72巡：模型・導出・境界

## 1. 単位と問題の限定

剛な軸対称先端と、均質・線形弾性の半無限体との、摩擦なし法線接触を解く。実際の滑走抵抗は求まった面積から別に診断する。局所ピーク基準p0=5MPa、設計接触半径a0=50µm、合成弾性率E0*=0.5GPaはいずれも仮入力。長さ尺度H=p0 a0/E0*=0.5µm、半径座標x=r/a0、接触半径比c=a/a0。力の尺度はp0 a0²。設計力W0=0.8πp0a0²=0.031416N。

板全体の荷重を一接点へ掛けていない。実粒の向き、薄い皮と芯の変形、ソールの有限厚さ、接点間干渉、粘弾性・凝着・摩擦による法線変形は未解決。入力E*を特定銘柄の50℃測定値と解釈しない。

## 2. 前巡の圧力分布R8からの逆算

目標p/p0=1−x^8は平均/最大圧力比β=0.8。一般の偶数mについて、等価一次元変位w1と形状gを

~~~text
w1(x) = 2 ∫[0, sqrt(1−x²)] {1 − (x²+t²)^(m/2)} dt
δ = w1(0) = 2m/(m+1)
g(x) = δ − w1(x)
f(x) = (2/π) ∫[0,π/2] g(x sinθ) dθ
~~~

とする。fは無次元の物理形状。これは一次資料S1のAbel変換を使った計算。mが偶数なのでw1は有限個の多項式積分として評価できる。m=8のg'(1)=0であり、設計点を越えた荷重にどう応答するかは外側形状で決まる。

R8比較案ではx>1へg(x)=δ+k(x−1)²を延長し、k=0.5/2/8を比較する。これは本巡で加えた一つの連続延長であり、すべてのR8延長を最適化した結果ではない。外側の物理形状にも上のAbel変換を適用する。

任意cの無次元力Fと圧力は

~~~text
F(c) = 2 ∫[0,c] x g'(x) dx
p(r,c)/p0 = (1/π) ∫[r,c] g'(x)/sqrt(x²−r²) dx
~~~

材料係数がE/E0=e倍へ変わる場合、同じ物理形状で力・圧力にeを掛け、指定荷重からcを逆算する。eを温度変化量へ換算していない。

## 3. H72-Q：二次・四次の組合せ

同じβ=0.8を、別の圧力分布で実現する。

~~~text
設計点のp/p0 = sqrt(1−x²)(1+x²/2)
g(x) = (3π/8)x² + (3π/16)x⁴
f(x) = (3π/16)x² + (9π/128)x⁴
F(c) = π(c³/2 + 3c⁵/10)
p(r,c)/p0 = sqrt(c²−r²)(3/4+c²/4+r²/2)
~~~

物理高さはH f(x)。このfを設計接触域の外側へ滑らかに継続する。接触半径の余裕を1.25/1.5/2倍として比較する。半径cが用意した範囲を越えれば、同じ解の継続を実先端へ適用しない。

c>1では最大圧力が中心からずれる。最大点はr²=max[0,(c²−1)/2]であり、r=0の圧力だけを最大値にしていない。閉形式と積分で圧力・力・形を照合した。四次形状やAbel法そのものの新規性は主張しない。

摩擦診断は前巡の仮則μ=b+τ0/p_meanを使う。b=0.03、τ0=0.04MPaなら設計点μ=0.04になるが、この材料を発見した値ではない。既存の仮のτ0=0.2333MPaの列も保存した。粒の押しのけ等の抵抗を加えれば全μは変わる。

## 4. 接触半径を固定して押す反例

硬い縁で半径aを固定したまま荷重ΔWを加える理想解は

~~~text
Δp(r)=ΔW/[2π a sqrt(a²−r²)]
~~~

となり、縁で発散する。現実の圧力が無限大になる予測ではなく、鋭い固定縁・線形弾性という模型が局所丸みや塑性を欠くことを示す。全体荷重だけの判断を避ける反例。

## 5. 摩擦トルクと片当たり

法線荷重Wを支える反力点が接触面からh下、接線力がμW、ほかの支持モーメントをゼロとする静的模型では、圧力重心の偏心e=μhが必要。

H72-Qの設計圧力へ横偏りを付けた試行分布 p(r,θ)=pQ(r)[1+C(r/a)cosθ]を置くと、円板の積分からe/a=(3/14)C。したがってC=14μh/(3a)。C≤1はこの試行分布が負圧を生まない条件。C>1を、すべての圧力分布で接触不能という定理にはしない。C≤1も変位適合を満たす接触解ではなく、モーメント釣合いの診断である。

支持点を浅くすれば偏りを抑えられるが、薄いヒンジの疲労・濡れ固着・ソールによる曲げを別途解く必要がある。傾き診断の角度atan[η f(a)/(2a)]も、幾何差の尺度であって加工公差・破損基準ではない。

## 6. 数値・費用

R8の力積分はx=sinθ、圧力積分はt=sqrt(1−r²)sinθで端点の平方根を除去。32/64/128点のGauss積分を照合する。R8の最大圧力は1001点の半径探索。Q72は最大位置の閉形式を使用する。R8の細かな極値・非軸対称接触の保証にはしない。

費用は第71巡の全深度仮粒数3.117691兆、6先端/粒、皮10µm、密度950kg/m³を継承。外半径をs倍にすると皮面積・質量はs²倍。材料500/2000円kg、機能面加工10/100円m²は税抜の仮単価。支持部・工具・立体加工・余白・歩留まり・回収費は含めない。
