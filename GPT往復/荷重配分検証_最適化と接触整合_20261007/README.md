# 第15巡：荷重配分と接触整合

[報告書](../GPT回答_多方向探索第15巡_荷重最適化と接触整合および短い受け_20261007.md)を先に読む。物理試験0、実物成功確率未算定。静的な力の最適化、接触の運動条件、短い受けの寸法予算を別に扱う。

## 再現

Python 3.12.14、requirements.txtのNumPy/SciPy/CVXPY/Clarabel/Matplotlibを使用。リポジトリ全体が必要。第13巡の接点と第14巡の骨格コード・費用結果、第8巡のクリップ尺度を参照する。当フォルダで次を実行する。

~~~text
python -m pip install -r requirements.txt
python allocation.py
python minimax.py
python contact_audit.py
python seat_requirements.py
python verify.py
python plots.py
~~~

実行時はリポジトリ内の一時 .deps を読み込み先へ加えた。依存ライブラリ本体は保存対象にしない。inputs.jsonは入力条件の記録であり、各スクリプトの定数を自動上書きする設定ファイルではない。形状・寸法を変える際は、接点生成から再実行する必要がある。

## ファイルと範囲

- allocation.py：81条件の円形摩擦円錐内エネルギー最小化、117固着試行。接点ばねは独立仮定。接点を動かさない初期解と、すべる解を混同しない。
- minimax.py：21条件で、33点/部材の最大線形診断を直接最小化。得た力を257点で再評価。これは固定接点の静的な緩和問題。
- contact_audit.py：上面摩擦0の8荷重例について、9µNでの固着・すべり方向整合を計算。さらに24条件の機械保持力尺度。滑りを許す境界判定幅は摩擦比1e-6。
- seat_requirements.py：20µm角×20µm長さ、6短材/粒の理想的な公称圧縮面積・材料費。相手形状、骨格接続、入口・解放・保護を備えた部品設計ではない。
- verify.py：力法とは別の変位法、摩擦円錐射影、KKT、接点精度、再最適化の細分化など。329項目の許容内確認。成功確率へ使わない。
- plots.py：3枚の図。完成品や実験を表す画像ではない。

各スクリプトと同名または関連名のJSONに条件、力、残差、スコープを保存。結果の内部にもphysical_tests=0とsuccess_probability=nullを保持する。新規CAD/STLは作成していない。

## 読み間違えてはいけない点

最適化の最小値は実物の力配分ではない。大変形になる線形値は感度であり、破壊後の実変位ではない。固定点で固着できないことは、接点が変わった粒群でも支えられないという証明ではない。小さな接点残差は幾何・接触則の誤差と区別できない。

受けの面積を確保しても、引張成分を圧縮へ変換する相手部や荷重経路がなければ保持できない。面積・材量だけを成立した発明や価格としない。
