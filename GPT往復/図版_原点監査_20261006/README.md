# 原点監査の図版

- `01_摩擦模型の仮定感度.png`／`.svg`：計算模型の仮定感度。観測データや実験結果ではない。数値は `バーチャル試験/snow_origin_audit_results_20261006.json`。
- `build_plot.py`：Matplotlibで上記グラフを再生成する。Matplotlibが通常のPython環境にない場合、第一引数でインストール先を指定できる。Windowsの日本語フォントを探索するため、他OSでは日本語フォント設定を追加する。
- `02_構造と検証.svg`／`.png`：手作成の編集可能な模式図。実物の顕微鏡・CT像ではない。粒径比・接点数・空隙率は縮尺通りの描写ではない。SVGを正として、PNGはSharpで同寸法に変換した。

どの図も雪らしい新材料の完成を示すものではない。未製作の構造案と現行案を区別するための図である。
