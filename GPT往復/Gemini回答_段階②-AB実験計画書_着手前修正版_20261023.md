## 3. 無害性・環境安全性の3領域判定体系（試験開始条件と屋外使用承認の分離）

[回覧板・第3章](https://github.com/serimu-yamamoto/jinkoukousetu-docs/blob/fd85f22a7083e850a4892fd3cd2225e421a84546/回覧板.md) の必須要件である「人・環境への非有害性」について、公的基準の流用（数値のすり替え）を排し、**①雨水溶出・水質、②吸入性粉じん、③水生生物毒性**の判定体系を以下の通り定める。

### 3.1 雨水溶出・水質の判定表（法定排水基準・受水域環境基準と材料選別値の分離）
* **公的基準の位置づけ【公的基準】**:
  - 水質汚濁防止法の一般排水基準（[環境省・一般排水基準](https://www.env.go.jp/water/impure/haisui.html)）は特定事業場から公共用水域への排出基準（pH $5.8 \sim 8.6$［海域以外］、BOD・COD最大 $160\text{ mg/L}$・日平均 $120\text{ mg/L}$、排水量 $50\text{ m}^3/\text{日}$ 以上等の適用条件あり）であり、材料無害性の合格値ではない。
  - 河川AA類型（pH $6.5 \sim 8.5$、BOD $\le 1\text{ mg/L}$： [環境省・河川](https://www.env.go.jp/kijun/wt2-1-1.html)）および湖沼AA類型（pH $6.5 \sim 8.5$、COD $\le 1\text{ mg/L}$： [環境省・湖沼](https://www.env.go.jp/kijun/wt2-1-2.html)、[埼玉県・環境基準一覧](https://www.pref.saitama.lg.jp/a0505/suisitukankyoukijun.html)）は**受水域の環境基準**であり、材料抽出液の法定認証値ではない。
* **本計画の溶出試験・暫定選別表**:
  段階②-Aでは閉鎖系で試験液・洗浄液を全量回収（放流ゼロ）し、新品配合の比較溶出データを取得する。屋外使用判断の前には摩耗後・経時劣化後・凍結融解後・初期流出水と反復降雨の累積溶出を測定する。

| 測定項目 | 段階②選別値・判定方法 | 区分と根拠・限界 |
| :--- | :--- | :--- |
| **pH** | 標準化した未処理（無ろ過・無中和）溶出原液で **$6.5 \sim 8.5$**（測定値 $\pm U$ が範囲内） | **【暫定提案・未確認】** AA類型環境基準からの借用（法定抽出値ではない）。水ブランク自体が範囲外の場合は原因を切り分け単純合否を保留する。 |
| **$\text{BOD}_5$** | 未処理溶出原液換算で **$\text{BOD}_5 + U \le 1.0\text{ mg/L}$** | **【暫定提案・未確認】** 河川AA類型値からの借用。希釈して合格させず、原液換算値と単位乾燥材料あたり負荷量（$\text{mg/kg-dry}$）を併記する。 |
| **$\text{COD}_{\text{Mn}}$** | 未処理溶出原液換算で **$\text{COD}_{\text{Mn}} + U \le 1.0\text{ mg/L}$** | **【暫定提案・未確認】** 湖沼AA類型値からの借用（$\text{COD}_{\text{Cr}}$ と混同せず、河川のBOD判定をCODで代用しない）。 |
| **$\text{Na}$・クエン酸・$\text{Ca}$** | 溶存態および全回収可能濃度（$\text{mg/L}$）と累積溶出量（$\text{mg/kg-dry}$）を実測。<br>**本材料用の単独合格濃度は【未確認】** | **【暫定提案・未確認】** 根拠なき $\text{mg/L}$ 値を捏造しない。公的PNECが確認できる物質は現地背景込みの $\text{PEC/PNEC} < 0.1$（[環境省・環境リスク初期評価ガイドライン](https://www.env.go.jp/content/900501350.pdf) の低優先度区分）を選別目安とし、PNECまたは現地条件が未確定の間は**判定保留**とする。 |

### 3.3 水生生物への毒性の判定表（WET手法の段階的適用）
化学分析（pH・BOD・COD）だけでは混合物・懸濁粒子の生物影響を判定できないため、[環境省「生物応答を用いた排水試験法（検討案）」](https://www.env.go.jp/content/900541513.pdf)（藻類生長阻害・ミジンコ繁殖阻害・魚類胚／仔魚短期毒性の3試験系、希釈系列 $5, 10, 20, 40, 80\%$ 等）を参照し、以下の段階的選別基準【暫定提案・未確認】を設定する。
1. **暫定選別基準**: 試験成立条件（対照区の生存・繁殖・増殖基準）を満たした上で、未処理（無ろ過・無pH調整）の流出原液に対する3試験系すべてで最高試験濃度 $80\%$ に統計的有意な悪影響が認められず、**$\text{NOEC} \ge 80\%$** であること（検出力・効果量・信頼区間を併記し、ばらつき過大時は**判定保留**とする。また「$80\%$ 試験液で影響なし」を「原液 $100\%$ で無影響」や「普遍的無害」と書き換えない）。
2. **実施順序**: 段階②-A（1.2kg少量選別）では溶出液の化学分析（pH, EC, BOD, COD, Na, Ca, クエン酸, $\Delta T_f$）を実施し、段階②-B通過候補に対して **藻類・ミジンコ試験 $\rightarrow$ 屋外放出判断前に魚類胚・仔魚試験を含む全3試験系＋PEC/PNEC評価** を完了させる必須ゲートとする。
