# 第35巡 数量・成長・費用の計算定義

inputs.jsonの値をcalculate.pyで計算し、results.jsonとvalidation.jsonへ保存する。物理試験0件、実物成功確率null。28件の照合は代数・幾何・収支だけで、材料の性能試験ではない。

## 1. 理想の法線力予算と接点量

粒の包絡直径D、包絡体積の床内割合φ、平均近接数z、床体積Vとする。np=6φ/(πD³)が単位床体積あたりの粒数、nc=z np/2が共有接触の個数密度。母粒の内部空隙を含む包絡密度ρenvと床かさ密度φρenvを分ける。

ランダム接触位置の両側に種が必要で、それぞれの設置割合fが独立なら接合可能割合p=f²。位置に相関がある場合はこの式を使わず、実接触の測定値で置き換える。

全接点が円柱状の同じ結晶橋（半径r、長さL）を持ち、力F=σbπr²を同時に負担すると仮定する。方向が等方的なら、接触力のvirial平均の一方向成分は

~~~text
Tideal = (nc p) F D / 3 = z φ p σb (r/D)²
r = D sqrt(Ttarget/(z φ p σb))
Mbridge = V (nc p) π r² L ρcrystal
        = 3 Ttarget V L ρcrystal /(σb D)
~~~

Tidealは指定された全接点の法線力を等方平均した診断値であり、剪断強度、Mohr-Coulomb粘着力、雪の硬さ、実際の破壊荷重ではない。荷重釣合い・ネットワーク連結・亀裂進展・応力集中を解いていない。少数の接点だけ大きくして同じTidealとなっても、床は連結しない可能性がある。

σb=10 MPa、ρcrystal=1,450 kg/m³、Ttarget=3 kPa、L=2 µm、φ=0.5、z=6、D=450 µmは全て比較仮定。チロシン／シスチンの実測接合強度や密度セットではない。AFMで測定された弾性率をσbへ代入しない。床2,000 m²×0.45 m、母粒包絡密度240 kg/m³から母粒108 tを置く。

このモデルでは固定Ttargetでpを下げても橋の総質量は同じだが、必要半径と1接点荷重が増える。p=0では有限半径の解がなく、今回は正のpのみ計算する。有限の受け座半径20 µmを超える場合は幾何条件だけでも満たさない。20 µm以下でも採用可能とは判定しない。

## 2. 析出量と回復対象を区別する

床内結晶橋のうち補修対象割合fr、その橋体積のうち新しく結晶化する割合fg、析出した固体のうち有効な接点になる割合ηと置く。

~~~text
Mnew = Mbridge fr fg
Δc = cfeed - ceq > 0
Vsolution = Mnew /(η Δc)
Mfeed = cfeed Vsolution
Mmother = ceq Vsolution
Munhelpful = Δc Vsolution - Mnew
Mfeed = Mnew + Mmother + Munhelpful
~~~

濃度kg/m³はmg/mLと数値が同じ。S1の供給5・室温平衡0.5、S2の供給0.7・25℃平衡0.16821を使う。S2の換算は0.7 mmol/L×240.3 g/mol=0.16821 g/L。これらは30/50℃の平衡値ではない。

fgを0.1にする案は、元の結晶の多くが受け座に残る場合に限る。新しい位置で繋がる場合、相手の種が脱落した場合、汚れて接合しない場合は適用できない。種・保持部・固定工程の費用は別。熱い溶液を噴霧すれば現地でこの析出量が得られると仮定していない。

## 3. 段差速度から面の成長を区別

平行な段差が横へ速度vstepで移動し、高さhstep・間隔λで等間隔に並ぶ定常モデルなら、面に垂直な速度はvn=vstep hstep/λ。両側の面が同条件で向かい合えば時間tで埋まる幅は2 vn t。

S2の2 mM・AFMの横速度11.4 nm/s、高さ5.6 nmに、未測定のλ=50/100/500/1000 nmを組み合わせる。λは観測値ではない。20/40/60分と0.2/2/20 µmの隙間を比較する。2 µmは第1節の橋長さに対応する例だが、fg=0.1の体積を足せば2 µmの隙間が必ず閉じるという対応は付けていない。

供給濃度一定、核生成待ち時間0、両面の配向適合、濡れと輸送維持を仮定する。段差束間隔の変化、母液の枯渇、曲面、毛管力、接触時の結晶方位、異材との界面強度は未計算。幾何学的に閉じた後に機械的に接合するまでの時間も未知。

## 4. 雨の溶解容量

雨量R、接点へ達する水の割合eに対し、接点に利用できる溶解容量をMcap=A R e ceqで比較する。初期水濃度0、完全な接触・平衡という容量上限。実溶解量や速度ではない。Mcapが橋全量より大きければ、難溶性だけを根拠に保持を保証できない。小さくても、弱い接点が優先して溶ければ破壊し得る。温度・pH・他の溶質・流路・拡散境膜は別測定。

## 5. 水・熱・可変費

加熱の電力量 Eheat=Vρw cpΔT(1−熱回収割合)/(3600×加熱効率) [kWh]。ΔT=70 K、cp=4.18 kJ/(kg K)、ρw=1000 kg/m³は水の概算。熱回収0/80/95％・加熱効率80％は仮定。濃度を維持した昇温・冷却循環の予算で、現地に熱い液を撒く指示ではない。30/50℃へ冷却した後の過飽和保持時間は未測定。

仮単価：電力30円/kWh、水＋処理500円/m³、溶質1,000/5,000円/kg。1年200回は運用感度。可変費は加熱＋水処理＋新規供給溶質。母液・余剰結晶は再利用価値0として全供給量を買う。溶解熱、熱損失、ポンプ、攪拌、回収分級、労務、装置、種の製造、母粒の交換、税、造成、資金費は含まない。

析出後に水の95％を排出できると仮置きし、残水の蒸発熱を2,400 kJ/kgで別計算する。析出前に液を抜けば溶質も失うため、この95％を析出量と独立に実現できたとはしない。乾燥20分の必要熱出力と、能動加熱なら追加される費用を出す。日射や50℃表面で自然乾燥できるとの予測ではない。加熱と乾燥を順次20分ずつ行えば、さらに機械移動・検査時間が必要となる。
