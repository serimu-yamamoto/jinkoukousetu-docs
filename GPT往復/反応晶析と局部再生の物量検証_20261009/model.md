# 第68巡 計算の定義

全式は保存則・仮定感度。物理試験・反応速度予測・雪の滑りの予測ではない。標準ライブラリの [calculate.py](calculate.py) を実行すると、[results.json](results.json)、6表、[checks.json](checks.json) を再生成する。

## 1. 反応による結晶供給

システインをRSH、シスチンをRSSRと記す。総括反応の理想量論は 2 RSH + 1/2 O₂ → RSSR + H₂O。過酸化物など中間体・副生成物が残る場合はこの最終生成物収支まで到達していない。量論は無副反応を証明しない。

丸めた分子量：システイン121.16 g/mol、シスチン240.30 g/mol。シスチン1 kgに必要なシステイン1.00841 kg、O₂ 0.0665834 kg。1 mM=1 mol/m³より、前駆体c mMの理論供給量は c×240.30/2000 kg/m³。溶けたままの生成物・副反応・回収損を引く前の上限である。

初期溶存酸素Cs mg/L、水量V m³ならO₂在庫は Cs×0.001×V kg。気液移動の上限は、液内酸素濃度を常にゼロに保てると仮定し、Cs×0.001×V×(1+kLa×t) kgとする。反応が遅ければ酸素が蓄積し実移動量は下がる。この式は速度定数kLaを測定した式ではなく、必要曝気能力の下限を逆算する式。

[supply.csv](supply.csv)の100 mM、kLa、DO感度は仮定であり、S2の実測速度から導いたものではない。6 mM・7.5 mg/Lでは原料0.7209 kg/m³に対し初期酸素だけの上限0.112641 kg/m³。15.625％は原料転換の酸素上限であり、旧成功率15％とは無関係。濃度を100 mMに増しても酸素を追加しなければ同じ0.112641 kg/m³。

液量は完全反応しても6 mMで1387.15 L/kg。蒸発潜熱0.65 kWh/kg水を仮置きすると901.65 kWh/kg結晶。これは全液を蒸発させる極端な経路だけの熱量。濾過・母液再使用では全液を乾燥させない。循環液量を新規取水量にしてはいけない。100 mMなら83.23 L/kg・54.10 kWh/kgだが、晶癖・閉塞・反応時間・収率のデータはない。

## 2. 電荷と電力

酸化も逆向き還元もシスチン1 mol当たり2 mol電子。F=96485.33212 C/molより Q=2F/(0.24030×3600)=223.06684 Ah/kg。電流I A、電流効率ηFなら生産上限 IηF/Q kg/h。[charge.csv](charge.csv)の効率は感度仮定で、S3の実測ではない。

還元後のシステインには1 molにつき1電子相当。100 cm²×400 mA/cm²=40 Aでの上限は180.826 g/h。200 g/hなら少なくとも44.2415 A。S4の最大値が同時の定常値か、面積・質量基準・丸め等が異なるかはSI未確認。論文全体を否定せず、200 g/hを40 A装置の保証仕様として使わない。2.4 F/molの全転換も純度・分離収率・機能回復率ではない。

S4の別条件の約1 kWh/kgシステインをシスチン基準へ換算すると1.0084 kWh/kg。酸化側を未測定の3 V・電流効率90％と置けば0.74356 kWh/kg。合計1.75196 kWh/kg、35円/kWhなら61.32円/kg。ただし両研究を接続した実測ではなく、洗浄・液移送・乾燥・損失・冷却補機・固定費を含まない。価格61円の材料が製造できるという意味ではない。

## 3. 形と機能まで戻る経済条件

退役結晶相1 kgを基準とし、各段階へ入った量に対する条件付き質量歩留まりを y回収、y還元、y酸化、y形状、y機能検査とする。η=積。独立な成功確率を掛けているのではない。各ロットの実測が必要。

新品の同じ機能を満たす結晶相の価格P、全回収工程の変動費C（退役相1 kg当たり）、年間追加固定費Ffix、年間退役相量Mなら、再生による節減 S=M(ηP−C)−Ffix。新品補充量(1−η)Mも収支に含む。ηP≤Cなら規模を増してもこの単純模型では逆転しない。

例は全て仮置き：歩留まり0.90×0.98×0.95×0.80×0.90=0.603288、P=6000円/kg、C=2000円/kg、Ffix=200万円/年。変動節減1619.728円/退役kg、固定費を回収する退役相量1234.78 kg/年。年200 kgでは節減ではなく167.6万円/年の追加費となる。少量接点用なら委託・共用設備を先に比較する。Cは濾過・形状制御・母材分離・検査・廃液まで含む仮予算であり、単価見積なし。

同じηが繰り返されれば元の材料残存分は2巡で半分未満になる。再生可能という語で補充ゼロを約束できない。[recovery.csv](recovery.csv)と[fixed_cost.csv](fixed_cost.csv)はその感度表。

## 4. 昼60分と工場在庫

床の仮基準2000 m²×0.45 m×120 kg/m³=108000 kg。1日に0.5％の粒を交換する仮定なら540 kg。結晶相が粒の1％なら相は5.4 kgだが、選別機が扱うのは粒540 kg。実効作業40分、合格歩留まり95％とすれば投入処理能力852.63 kg/hが必要。汚れの洗浄時間・搬送距離・機械台数は未実測。整地面全体を同時にこの流量で処理できるという主張ではない。

再生リードタイム5日＋余裕1日なら交換粒在庫3240 kg。5日は製造計画の感度値であり、S1の5日をシスチンへ転用したものではない。冬・雨後の突発交換分は別途。在庫・交換量の関係は[exchange.csv](exchange.csv)。全108 tを40分で処理すると162 t/hとなり、少量交換とは別装置になる。

## 5. 洗浄負荷

電解液1 M KClを、結晶相1 kgに対し0.1 L持ち越す仮定なら7.455 g KCl/kg。各回1 Lの清水を完全混合し、毎回0.1 Lだけ残す理想洗浄では残存比(0.1/1.1)^n。3回で5.601 mg/kg、洗浄水3 L/kg。[wash.csv](wash.csv)。吸着・閉じた空隙・再使用水・結晶溶出を無視しており、安全・融雪・排水の合格値ではない。溶出液中の塩化物等の測定が必要。

チロシンの酵素経路は前駆体1 molからリン酸1 molが出るため、チロシン1 kg当たりP 0.17095 kg相当。50 mM供給の上限9.0595 kg/m³と対応する。リンをコースへ散布する案にはしない。緩衝剤・酵素・未反応物の除去も別負荷。

## 6. 本計算で扱わないもの

結晶誘導時間、乾燥50℃強度、粒間接点の破断変位、UHMWPEソールとの摩擦、雪の定着、雨水排水能力、毒性、化学プロセス設計圧力、実機価格。いずれも未知を0や合格に置かない。2億円の整地設備枠は化学工場・全材料・全土木の予算へ拡張しない。
