# 摩耗形状と接触相配置の模型

全ての候補物性・運用値は inputs.json にある仮定。これは**与えた摩耗後形状の接触感度**であり、局所摩耗則を時間積分して将来の形を予測した計算ではない。物理試験0件。成功確率未算定。

## 1. 同じ体積を失う二つの形

元の軸対称先端を f0(r)=r²/(2R) とする。rは先端中心からの距離、fは中心から下方への深さ。fは荷重による弾性変形の前の形。

### 平らな切頭形

中心から w_f だけ削り、半径 b=√(2Rw_f) 内を平らにする。中心を原点に取り直すと：

~~~text
f_flat(r) = max(0, r²/(2R) - w_f)
V_flat = π R w_f²
g_flat(x) = x/R × sqrt(x²-b²)  (x>b), それ以外0
d = a/R × sqrt(a²-b²)
F = 2 E*/(3R) × (2a²+b²) sqrt(a²-b²)
~~~

最後の接触式はS1式2.78と独立のMDR積分で照合。r=bに理想的な鋭い接続があり、接触圧力は特異になる。平均圧力を局所最大圧力へ置き換えない。

### 滑らかな除去形（今回定義した比較形）

元形状からの除去深さを h(r)=w_s exp[-r²/(2Rw_s)] と仮定する。中心の高さを引き直すと：

~~~text
f_smooth(r) = r²/(2R) + w_s exp[-r²/(2Rw_s)] - w_s
f'_smooth(r) = (r/R){1-exp[-r²/(2Rw_s)]}
V_smooth = 2π R w_s²
~~~

同じ除去体積なら w_s=w_f/√2。平らな面と鋭い肩を避ける比較であり、この形が自然に摩耗して生じるとの主張ではない。無限に続く減衰尾部を含む模型なので、有限な先端の幅・厚さに対する補正も必要。

## 2. 軸対称弾性接触の再計算

S1のMDRを使用する。

~~~text
g(x)=x ∫[0,x] f'(r)/sqrt(x²-r²) dr
d=g(a)
F=2E* ∫[0,a] {d-g(x)} dx
p(r)=E*/π ∫[r,a] g'(x)/sqrt(x²-r²) dx
~~~

基準a0とRから d0=a0²/R、F0=4E*a0³/(3R)。x,aはa0、w,dはd0で無次元化する。滑らかな形では、z=x²/(2w)、J(z)=Dawson(√z)/√zとして：

~~~text
g(x)=x²{1-J(z)}
g'(x)/x=1+(2z-1)J(z)
F/F0=(3/2) ∫[0,a] {g(a)-g(x)} dx
~~~

小さいzには展開を用い、角度変換した原積分と独立照合する。圧力積分は x=√(r²+t²) で下端の特異核を除去。64点と128点Gauss積分を比較し、圧力を面積積分した荷重も照合する。圧力最大値は501点の半径標本による近似値である。

線形弾性・小傾斜・非凝着の法線接触・半無限体を仮定する。先端の有限厚み、50℃クリープ、塑性、粗さ、隣接接点、粒の回転・移動を解いていない。法線接触の凝着を無視し、接線抵抗へ凝着項を用いることの妥当性も実材で検証が必要。

接触剛性 K=2E*a は接点単体の微小増分剛性である。粒床の剛性・エッジ支持・解放距離ではない。摩耗前後で基準高さが変わるため、弾性押込みdの差を表面の全沈下として扱わない。

## 3. 摩耗体積と摩擦の接続

~~~text
V = k_w F ℓ × 10^-9  [m³]
k_w : mm³/(N m)
ℓ = 100回 × 1.6m = 160m（固定された接点の仮定）
μ_interface = β + τ0 πa²/F
Q_ski = μ_interface × 400N × 10m/s
~~~

k_wは硬さで割った**比摩耗量**なので、さらに硬さで割らない。値0、10^-9、10^-8、10^-7、10^-6は感度用で、発見した材料の範囲ではない。Archardの総体積だけを与え、除去形は上記の別仮定。局所のdh/dℓ=k_wpを満たす形状発展とは区別する。

第41巡の面積一定分割を継承：F_i=F0/m、a_i=a0/√m、R_i=R0/√m。このため、同じk_wとℓで総摩耗体積はmに依存しない。各中心摩耗深さはm^-1/4、初期押込みはm^-1/2、両者の比はm^1/4になる。一定の摩擦増分に達するk_wの診断境界はm^-1/2。

τ0=0.2MPa、β=0.03は仮の低せん断条件で、S4の実測値ではない。温度、速度、方向、濡れ、圧力で一定との前提も未校正。0.01/0.02/0.05の摩擦増分は診断用で、雪感の合格線ではない。局所発熱は今回は再計算せず、前巡のHertz熱源を削れた非Hertz接触に流用しない。

## 4. 混合相の偏摩耗

接触面に二つの材料相が常に接触し、同じ速度で滑り、形状が定常になった場合だけを扱う。S2の条件 k1 p1=k2 p2 と荷重釣合いを使う。接触面積の割合をφ、比摩耗量の比をr=k2/k1≥1とする。

~~~text
p1/pbar = r/(φr+1-φ)
p2/pbar = 1/(φr+1-φ)
材料1の荷重割合 = φr/(φr+1-φ)
k_eff = 1/{φ/k1+(1-φ)/k2}
~~~

φは面積割合であり、重量配合率ではない。定常形でも全体は摩耗し続ける。実混合材は相の剥落、露出面積変化、弾性率差、局所未接触を持ち得る。この式で低摩耗相の採用や安全を決めない。

S2プレプリントp.8の式22では半径因子r、式25では角度積分前の係数に不整合がある。ここでは独立に F=2π∫p(r)r dr を使った。正式出版版まで同じ誤記が残るとは確認していない。

## 5. 再配置と運用費

理想的にM個の別表面へ等しく接触を振り分け、方向変更で比摩耗量がχ倍になるなら、1表面当たりの量は元のχ/M。χ=Mなら分散効果は消える。全表面の総摩耗量はχ倍で、材料が復元するわけではない。S3の摩擦倍率をχへ代入していない。

年床在庫108t、完成粒500円/kg、新品補充率20→10%という未実証仮定なら、材料購入の粗節約は540万円/年。200回/年、処理厚d、床厚0.45mの場合：

~~~text
処理量/年 = 108000 kg × d/0.45 × 200
追加処理費上限 = 5400000円 / 処理量
~~~

ここから追加設備償却、人件費、洗浄乾燥、微粉回収、休業損失を払う。深い溝の修復を浅層処理で済ませる許可ではなく、全深度同一性能を維持する。費用の節約率も追加処理単価も実見積りではない。

同じ10年・割引率8%で初期材料の年額換算も含めると、500円/kgの材料年額は補充20%で約1885万円、10%でも約1345万円。前巡の仮の材料枠1000万円/年はなお超える。540万円の粗節約を事業採算の達成としない。

## 6. 検証

reproduce.pyの24項目はHertz極限、独立積分、導関数、除去体積、荷重積分、剛性、相の釣合い、単位、費用の保存を確かめる。出典の摩擦観測4点は校正入力へ入れていない。30接触条件・25混合相条件・9再配置条件を、合格率や成功確率として数えない。
