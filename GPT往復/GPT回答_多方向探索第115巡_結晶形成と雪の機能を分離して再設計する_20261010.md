# 多方向探索 第115巡：結晶形成と雪の機能を分離して再設計する
2026-10-10 / Codex。開始時main: eeeae63ce64e0a5c6d82911dda3201b919bd16a1。

**中性pHで実際に結晶を作る酵素法の原著全文を確認し、前巡の発明案を修正した。この経路で報告された主な形はジグザグ結晶・球状集合体であり、前巡の42nm厚の薄板をそのまま作れる経路ではない。さらに水中で結晶相が部分的に変わる報告がある。H115は「結晶を作る工程」「滑る接触面」「粒床の崩れ方」を分け、雨後に変わらない機能を比較して選ぶ設計である。**

## 1. 原著から確かめたこと
主資料はTah Royら「Guanine Crystal Formation at Physiological pH」。前巡で抽出できなかった大学公開PDFの全9ページをテキストで読んだ。図像そのものの寸法再測定は行っていない。本文・図説明に基づく確認である。[原著公開PDF](https://eprints.whiterose.ac.uk/id/eprint/227661/1/tah-roy-et-al-2025-guanine-crystal-formation-at-physiological-ph.pdf)

| 原著本文の条件・結果 | 本計画での意味 |
|---|---|
| グアノシン1.6mM、リン酸緩衝液50mM、pH7.2、PNP酵素1U | 中性pHでの形成は確認できる。塩を屋外潤滑剤に使う処方ではない |
| 静置で基質消費まで約2日、撹拌した20mL・1Uの比較では約1日 | 60分閉鎖中に現地で完成する証拠ではない。工場工程として比較する |
| 静置の生成物は5–10µmの球状集合体を含み、構成結晶はジグザグ形状。時系列記述には10–20µmもある | 単一の粒径規格・分布とは扱わない。枝状の雪粒や42nm薄板の代用と断定しない |
| 撹拌で独立したジグザグ状β型結晶 | 撹拌で薄い生体型板が得られた、とは書かれていない |
| PNP量・基質濃度・緩衝液・撹拌によってα/β相が変わる | 速く作ればよいだけではなく、形と相も管理する |
| β型は空気中・母液中では少なくとも20日変化なし。一方、DI水・HEPES緩衝液では18時間後にα型への部分転換 | 雨後に質量が残っていても同じ材料状態とは限らない |

出典箇所はPDF pp.2–7。最後の水中結果は室内文献条件であり、屋外の雨・50℃・保持粒での寿命ではない。18時間を「それまでは安全」という保証時間にも使わない。[原著DOI](https://doi.org/10.1021/acs.cgd.5c00205)

実験の詳細補足PDFは公開リンクを本文から確認したが、取得はHTTP403で未了。正確な反応温度、酵素の活性単位の測定条件、洗浄・乾燥の全手順は未確認。中性pHを30℃以上の噴霧形成、50℃での摩擦性能へ読み替えない。前巡の材料一覧にあったアジ化ナトリウム等も、この製造液へ投入したと推測しない。

## 2. 薄板・固溶体・低摩擦をひと続きにしない
前巡の約2µm・全厚42nmは別の2023年研究の結晶であり、今回の酵素法へ寸法を移せない。したがって以下の20.21kgは前巡の**質量予算だけ**を比較用に引き継ぐ。酵素法でもその量で同じ機能面積を被覆できるという計算ではない。

本原著ではヒポキサンチン等の添加による形態変化は概して小さく、PVP等は相も変えた。生体結晶に含まれる分子を混ぜるだけで薄板・滑走・耐水性が同時に改善する、という近道は採らない。原著が示唆する局所環境・足場の重要性は、局所で結晶を保持する設計の検討理由にはなるが、その設計の実証ではない。

雪の滑走感は結晶格子だけでは決まらない。上面の摩擦・摩耗、荷重に対する沈み、エッジの横支持と解放、整地後の再接続を別々に測り、同じ粒床で同時に成立させる。板状の光学結晶を砂に混ぜるだけで雪になるとは扱わない。

## 3. 製造物量：希薄な反応液の規模を隠さない
丸めた計算入力はグアニン151.13g/mol、グアノシン283.24g/mol。1.6mMは1.6mol/m³なので、完全変換時のグアニン換算は0.241808kg/m³。結晶の分離回収率と粒への配置歩留まりを別に置いた。

| 仮定した保持目標 | 分離・配置歩留まり | 累積仕込み換算液量 |
|---|---|---:|
| 20.20788kg（質量予算のみ） | 各100％ | 83.57m³ |
| 同じ目標 | 各50％ | 334.28m³ |
| 1,350kg（旧仮予算の比較） | 各100％ | 約5,582.94m³ |

20.20788kg・各100％の場合、グアノシン投入約37.87kg、リン酸成分の初期投入約4,178.50mol。反応でリボース1リン酸側へ移るリンは約133.71molで、残り無機リン酸は約4,044.79molという完全変換の収支となる。生成物へ全リン酸が残る意味ではない。洗浄・母液再利用・副生成物の行先を工程に含める。

20mL当たり1Uという文献の投入比を単純に維持すると、83.57m³には約418万Uの酵素投入相当となる。**Uは酵素質量でも処理能力の保証でもない。活性測定条件・失活・回収再利用・量産時の反応速度が未確認なので、kg/時の能力には変換しない。**

液量は累積仕込み相当であり、新水消費・排水量・同時タンク容量とは異なる。仮に30日・有効稼働75％で処理し、1日反応を維持できるなら、反応槽の有効液量の算術値は約3.71m³。2日なら約7.43m³。充填率、混合、洗浄、分離、滞留時間分布、スケール効果の設計を含まず、購入仕様・成立した設備容量ではない。

## 4. 経済判断をできる形にする
見積価格は未取得。低歩留まりを安価な仮定で埋めない。理想歩留まりで保持結晶1kg当たりの投入係数は以下となる。

- グアノシン約1.87415kg。
- 工程液約4.13551m³。
- 緩衝液中のリン酸成分約206.7756mol（塩の配合質量・価格は未確認）。
- 実験投入比を保つ酵素約206,775.6U。

グアノシン単価を円/kg、酵素単価を同じ定義の円/U、リン酸成分の調達・調製費を円/mol、工程液処理費を円/m³とすれば、各係数を掛けた和に、分離・洗浄・固定・乾燥・品質検査・設備償却を加える。分離と配置が各50％なら上流投入係数は4倍。ただし下流の作業費まで全て一律4倍とはしない。

酵素の固定化・再利用と母液再使用は改善候補だが、回収率と活性維持を測る前に費用削減を計上しない。単に1.6mMより濃くしても、同じ相・形・収率が出るとは限らない。設備2億円枠を、この製造原価試算で達成したとは扱わない。

## 5. H115：工場で状態を確かめた接触相を、開放粒の局所へ保持する
提案する構成は、丸い枝を持つ開放粒の「ソールが触れる少数の座」と「エッジで離れる粒同士の接点」を分けるもの。局所のくぼみ・保持縁に結晶を固定し、粒全体の空隙や水の通路を被膜で塞がない。滑走面の連続マット・ネットは使用しない。

```mermaid
flowchart LR
 A[工場で結晶形成] --> B[分離・洗浄]
 B --> C[水履歴と結晶相を確認]
 C --> D[開放粒の接触座へ局所保持]
 D --> E[50℃の実ソール摩擦・摩耗]
 E --> F[粒床の沈み・横支持・解放]
 F --> G[散布補充と60分整地の試験]
 G --> H[雨後と冬の接続を再確認]
```

現地補充の候補は、検査済み完成粒を空気搬送・最小限の水で散布する方式。ただしこれは現地の噴霧から結晶を新生させる理想とは異なる工程であり、散布性・粉じん・保持性も未実証。理想の温暖噴霧経路は別候補として残す。酵素反応液を山へ直接撒く提案はしない。

比較は最大4条件：保持構造のみ、既存LL比較材、洗浄したβグアニン、α相を含む水履歴後の同系結晶。α型は比較対照であり安定性・摩擦の合格を前提にしない。同じ母粒・保持構造・接触量で比べ、形を合わせられない場合は差を記録して結晶相だけの効果と断定しない。β型維持が必要かどうかも摩擦と摩耗から決める。

**発明上の修正は、結晶を「全ての性能を解く物質」にせず、交換可能な小量接触相へ限定し、雨後に変化した相を先に比較してから採ること。** 結晶相が変わっても必要な滑走特性が維持されるなら採用余地がある。逆に相が同じでも摩擦・粉化・移着が悪ければ棄却する。

## 6. 次の反証試験と切替条件
1. 完成粒を水に0/1/18/24/72時間さらす比較。18時間は原著との対応点で、屋外寿命ではない。30/50℃、乾燥復帰後も相・粒径・保持量・溶出を測る。回収率と摩擦の回復率を混同しない。
2. 同じ実スキー底面で乾燥・濡れ・再乾燥の摩擦、摩耗、移着、ざらつきに関係する変動を測る。天然の圧雪を対照にして許容差を先に定める。現時点では許容差や成功率を捏造しない。
3. 同じ母粒床で沈み、エッジの入り・横支持・離れを比較。接触相で滑っても砂状の破壊なら、粒の形と接点へ戻る。化学添加だけを増やさない。
4. 豪雨後は上への回収・均しに加え、流出した微小相の量、組成、排水、摩擦を再確認。局所保持が剥がれているなら60分のローラー整地だけで元に戻るとは判定しない。
5. 冬は天然雪→完成粒→埋設下地の接続と界面排水を独立確認。結晶板が水・雪の弱層にならないことが条件。
6. 完成粒、摩耗物、飛散・排水・残留成分の人体・環境評価は未実施。生体由来という説明で代替しない。

本巡は形態の誤移植を防ぎ、耐水相変化を実験設計へ取り込み、製造量と費用係数まで進めた。完成材料、無害性、50℃滑走、90％超の成功を示す実証結果はまだない。Claudeには原著照合と上記の反証を依頼する。
