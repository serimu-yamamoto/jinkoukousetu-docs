# 第88巡：一度の解放から、接点の再形成を含む群模型へ

第49巡の一方向・一回解放の限界を補う診断。原著の粒床DEMや分子模型の再現ではない。入力値は全て仮定で、50℃の実測パラメータはない。

## 1. 最小の更新模型

潜在接点面密度n、一接点の剛性k、解放までの相対変位δc、一定の局所相対速度v>0を置く。接続中はF=kxで、x=δcに達すると外れる。外れた接点は平均τの指数分布に従って待ち、無荷重x=0で別の接続を作る。解放は必ずしも材料の破断を意味しない。

nは独立な潜在接点の数で、物理的な粒数・接触網の連結性を解いた値ではない。粒全体の配向、相手の共有、法線荷重、隣接接点への力移行を省略する。vは接点の相対滑り速度であり、スキーの前進速度ではない。

一つの接続が存続する時間t_b=δc/v。更新周期の平均はt_b+τ。定常接続割合と、初期全点同時ピークS0=nkδcで規格化した定常抵抗は：

`q∞ = t_b/(t_b+τ) = 1/(1+r)`
`S∞/S0 = q∞/2 = 1/[2(1+r)]`
`r = vτ/δc`

接続中の年齢・伸びが定常状態で一様に分布するため平均力はピークの半分。一回の接点解放時に放出する弾性エネルギーはkδc²/2。この仕事を周期中の移動距離δc+vτで割っても同じ定常力になる。

この抵抗は再接続接点の寄与だけ。スキー底面との界面摩擦、粒の押しのけ、濡れ吸着、他の粒のせん断抵抗を含む総μではない。v=0の静止保持はこの定常滑り式では扱わない。放出エネルギーの熱・振動・破損への分配も解いていない。

## 2. 短い解放と速い復帰の逆算

仮の残留比上限β<0.5を満たすには：

`τ_slide ≥ (δc/v)[1/(2β)−1]`

全接点が外れ、再接続相手を全て利用でき、休止中に再び外れないという楽観条件では、時間T後の再形成割合はq(T)=1−exp(−T/τ_reset)。仮目標q*へ届くために：

`τ_reset ≤ T/[−ln(1−q*)]`

一つの待ち時間τを両場面に使う場合、この下限と上限が重ならなければ二条件は両立しない。今回β=0.05とq*=0.95は設計診断用の仮値。雪の合格帯・開発成功率ではない。

相手を利用できる割合ηを固定してq(T)=η[1−exp(−T/τ_reset)]とする感度比較も行う。η≤q*なら有限時間には目標へ届かない。η=q*かつ非常に長いTで浮動小数点が等号へ丸まっても、合格フラグはfalseに保つ。

再形成割合は接点数の割合にすぎず、床強度や滑り心地が95％回復した証拠ではない。残存する接点に荷重が残る場合や、休止中にも外れる場合は別式が必要。

## 3. 通過中と通過後を分ける場合

再接続速度の比をα=k_on,slide/k_on,reset（0<α≤1）と置くと、τ_slide=τ_reset/α。

`α ≤ min{1, vτ_reset/[δc(1/(2β)−1)]}`

これは必要な機構の仕様を逆算しただけで、αを持つ粒が既に実在するわけではない。平均の再捕捉なし移動距離へ換算するとvτ_slide≥δc[1/(2β)−1]。一粒の幾何学的な長さと同一ではなく、相手を何度も変える運動を含む有効量。

## 4. 過渡計算と検算

全接点が無荷重で同時に接続した状態から開始する。接続の伸びをδcの200／400分割で追跡。各増分では伸びを進め、δcへ達した群を除き、未接続群を確率1−exp(−Δt/τ)で再接続する。再接続は増分末に集約する一次精度の離散化。

入力仕事=現在の弾性蓄積＋解放エネルギーを各増分で照合。離散模型の定常抵抗も独立に導く。h=1−exp[−1/(Mr)]として：

`S_discrete/S0 = h(M−1)/{2[1+(M−1)h]}`

r=0.1／1／10／100で定常式・分割収束・数値非負性・接点数とエネルギー保存を検査。400分割の連続式に対する誤差は全条件0.3％未満。端数で約10⁻¹³の負値が残る場合は計算丸めで、物理的な負の抵抗とは解釈しない。

同じδc・初期状態を全点に与えると同期した波形になる。実粒の振動、体感のザラつき、実験のギザギザを再現したとはしない。δcや姿勢の分布と、装置剛性を加える必要がある。
