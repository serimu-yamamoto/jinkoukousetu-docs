# 第88巡：通過中の再捕捉と通過後の復帰を分ける未実施仕様

設備・協力先未確保。照会・発注・物理試験は行っていない。[第82巡の実証入口](../初回実証の設備照合と試験費用_20261009/protocol.md)、[第87巡の高さ・接点観測](../実雪接触の根拠と荷重分担の逆算_20261009/measurement_protocol.md)へ接続する。

## 一回の破断試験に追加する観測

| 段階 | 観測する量 | 誤認しないための対照 |
|---|---|---|
| 単接点の初回解放 | 局所変位、力、除荷、δcの分布 | 治具・センサーのたわみと材料変形を分離 |
| そのまま滑らせ続ける | 再捕捉イベント、力、積算仕事、相手の入れ替わり | 一度外した接点を再接触させない対照 |
| 止めて荷重を保つ | 時間と残留力、再接続、クリープ | 除荷後の復帰と混同しない |
| 除荷して休止する | 待ち時間と再接続割合、再載荷時の支持 | 相手を保った固定配置と、失った自由粒配置 |
| 濡れ・乾燥・再整地 | 上記の繰返しと微粉・水橋・閉塞 | 同じ質量・高さでも性能が戻ったと扱わない |
| 雪との対応 | 同一底面処理の滑走・横支持・短い解放・残留仕事 | 接点模型だけで雪感を判定しない |

速度vは画像等から得る接点の相対移動速度。装置の牽引速度、板の前進速度、粒の回転速度を区別する。δc=100µm、τ=0.1sを測定値として計画に固定しない。

模型の指数待ち時間が正しいか、待ち時間分布を観測する。同じ相手への再接続と別の相手への接続を可能な範囲で識別。接点総数が一定でも構成接点が入れ替わっていないかを見る。高速度撮影で見えない接点を、イベントなしと記録しない。

## H88の比較対象

1. 同じ短い受け面を持つ開放粒で、滑り中も開口が露出する対照。
2. 横変形・粒の回転中だけ開口が内側へ退く、または捕捉方向から外れる一体形状。
3. 同じ形で、除荷時にも開口が戻らない対照（低残留だけの見掛けの改善を検出）。

いずれも未製造。第56〜61巡の後退・復帰機構と第87巡の法線支持を候補に使うが、別体ラッチやタイマーが完成したとはしない。法線荷重だけで捕捉を完全停止すると、通常の静的支持や冬の雪保持を損なう可能性がある。冬に荷重が掛かり続ける条件も比較する。

試料数・独立調製・許容誤差は協力先と測定可能量が決まってから事前に設定する。本巡の[test_plan.json](test_plan.json)は観測項目で、実施回数ではない。

## 切替条件

通過中の再捕捉を抑えると静的保持まで消える場合は、根元の受けによる支持と横方向の捕捉を別経路へ分ける。静止時は戻るが次の通過まで間に合わなければ、相手との出会い・配向・復帰を分けて測る。どの機構でも残留抵抗が雪対照から外れる場合は、長い絡み合いを主案から外し、結晶接点・短い機械接点・粒内修復へ比較を戻す。

雨後は回収量と機能回復、通常の約60分整地と台風後処理を区別。450mm機能層・300mm掘削・R39保持を継承。材料の安全・粉塵・溶出、雪界面の水溜まりとせん断固着は別途実証する。
