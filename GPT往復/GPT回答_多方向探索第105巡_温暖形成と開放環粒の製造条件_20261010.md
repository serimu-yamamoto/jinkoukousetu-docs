# 多方向探索第105巡：温暖形成と開放環粒の製造条件
2026-10-10 / Codex。物理試験0件、成功確率null。設備・協力先未確保。

**第104巡の外周支持を、二つの環を6本の支柱でつなぐ開放粒H105-Cとして具体化した。** 中央の貫通孔に加えて側面にも窓を置き、外周同士をつなぐ部分を残す。製造計算では、材料回収率を上げても加工量は消えないことが明確になった。このため、後から一粒ずつ穴を開ける方式を量産の前提にせず、多数個同時成形を比較する。

**これは雪状結晶の完成ではない。** 工場で作る比較試片であり、雪の沈み込み・エッジの切れ・濡れた滑走・50℃の性能は未実証。噴霧して雪状結晶を作る最優先経路も残し、形を作る工程と結晶化を混同しない。

## 1. 既存研究を踏まえた4経路
第68巡の温暖反応晶析、第53巡の異形材形成、第85〜86巡の一括加工を台帳から再利用した。Claudeの物性台帳は前巡と同じ本文ハッシュで、新たな返答は確認できていない。

| 経路 | 今回の確認 | 次の判断 |
|---|---|---|
| A：温暖反応晶析 | 第68巡の液中晶析と希薄液の負担を継承 | 現地で乾いた枝状結晶になる条件を独立に追う |
| B：液滴の渦輪を固定 | 輪状の粒を作る実験例がある | ゲル化・析出による形状固定。乾燥後の構造が課題 |
| C：溶融噴霧固化 | 水分をほぼ含まない樹脂から球状粒を作る工業工程がある | 水の乾燥負担は減るが、球を雪状構造と扱わない |
| D：連続中空材から開放粒 | 中空PP繊維の溶融紡糸が実在 | H105-Cの比較製法。微小側面窓と加工量を別に評価 |

Bの原著では2％ w/vのナノクレイ液を0.06mL/minで100mM CaCl₂液中へ送る条件が記載される。「freezing」は渦輪の形をゲル化・析出で固定する意味で、雪の凍結ではない。室外30℃で乾燥した雪状結晶を作った証拠ではない。[S1：An et al., 2016、Methods／Discussion](https://www.nature.com/articles/ncomms12401)。

Dの原著はPP3155を210℃で紡糸し、4分割円弧の口金を使用。1繊維0.25〜0.83g/min、69繊維という実験条件を確認した。これは今回の2mm粒の生産実績ではない。[S2：Ruckdashel & Shim, 2020](https://journals.sagepub.com/doi/10.1177/1558925019899680)。

Cはメーカーの工程説明であり、独立したスキー試験ではない。冷却ガスの条件を持つため、真夏の現地空気だけで十分かは別途確認が必要。[S3：PRECI公式](https://www.preci.co.jp/en/applications/0017/)。

## 2. 温暖形成で必要になる水処理
原著Bの供給条件から得られる乾燥固形分の供給上限は、1ノズルあたり**0.072g/h**。歩留まりを100％と仮定しても、135kg/hへの単純換算は187.5万ノズル相当になる。これは実設備の必要台数の見積ではなく、原著条件のまま直線拡大できないことを示す尺度である。

液密度1kg/L、潜熱2,400kJ/kgという仮定で、供給水を全て蒸発させる場合は、固体1kgあたり水49kg、潜熱約32.7kWh。浴・洗浄水、熱損失は含まない。逆に、機械脱水できる分まで蒸発必須と決めつけない。

| 脱水後の固体質量割合（仮定） | 残る水kg/kg固体 | 蒸発潜熱kWh/kg固体 |
|---:|---:|---:|
| 2％ | 49 | 32.67 |
| 10％ | 9 | 6.00 |
| 30％ | 2.333 | 1.56 |
| 60％ | 0.667 | 0.444 |

この脱水率で輪状粒を壊さず処理できることは未確認。含水ゲルを乾燥させれば、収縮・孔閉鎖・粉化が別の制約になる。湿ったまま残す方式を、乾いた雪の滑走感を満たす代替としない。

既往と同じ仮の2,000㎡×450mm×乾燥かさ密度150kg/m³では135t。Bの供給水を全蒸発する計算は初期分だけで4.41GWh。1％の補充でも供給液67.5m³、供給水66.15tで、1時間蒸発なら潜熱44.1MW相当となる。発熱源や実設備の見積ではない。液中形成Bは現地60分補充へ直結させず、閉鎖系の工場形成・脱水・洗浄と、現地への合格粒供給を分けて比較する。

塩を含む形成浴をコースに散布する案にはしない。工場で使う場合も、残留物・排水・摩耗粉を含む人体／環境評価が必要。元論文の用途から無害性を推定しない。

## 3. H105-Cの形状
[パラメトリック形状](温暖形成と開放環粒の製造監査_20261010/open_rim_grain.scad)を保存した。OpenSCAD用ソースで、レンダリング・製造は未実施。円弧は多角形近似。

| 寸法 | 比較試片の仮値 |
|---|---:|
| 外径／中央孔径 | 2.0／1.4mm |
| 全高さ | 0.6mm |
| 上下の環の厚さ | 各0.1mm |
| 中間の支柱 | 6本、各20° |
| 側面窓 | 6個、各40°、高さ0.4mm |
| 材料体積 | 0.5341mm³ |
| 質量 | 0.4807mg（固体密度900kg/m³という仮定） |

二つの連続環は支柱同士をつなぎ、中央孔と側面窓は幾何学的につながる。**第104巡で不足していた「外側の支え同士の接続」を形として指定した**点が前進。ただし一体作用の剛性、環の変形、粒の向き、座屈、窓端の破壊、接点の荷重受渡しは未計算であり、第104巡のIの有利さをそのまま移していない。

中央孔だけの短い筒も対照に残す。側面窓が雨後の性能を改善しないなら、加工負担を増やしてまで採用しない。横倒し・粒同士の接触で水が閉じ込められる可能性もあり、「開口がある」だけでは排水や凍結後の安全を保証しない。

体積から逆算した外形包絡体積の充填率は約0.588。実際の充填密度ではなく、仮のかさ密度150kg/m³と整合するために必要な値である。粒が重なり合う場合の定義や実充填は別に調べる。

この形が砂より雪に近いかは、乾湿50℃で摩擦・摩耗・沈み込み・横反力・エッジ解放を測るまで未確認。輪状・6本支柱という外観を、六方晶の氷や雪の結晶成長と呼ばない。

## 4. 加工量と費用の逆算
連続した中空材を短く切り、側面を除去して作る仮工程では、環状ブランクからの幾何歩留まりは**5/9＝55.56％**。さらに品質歩留まり80％を仮定すると、良品135tに対して延べ加工量は303.75tになる。

| 回収率の仮定※ | 新規原料 | 延べ加工量 |
|---:|---:|---:|
| 0％ | 303.75t | 303.75t |
| 50％ | 219.38t | 303.75t |
| 90％ | 151.88t | 303.75t |

※良品以外の材料のうち、工程へ再投入できる割合。再生による劣化や選別・乾燥費は未確認。閉じた定常収支の仮定であり、回収率を達成した実績ではない。

S2の0.5g/min×69本＝2.07kg/hを処理量の尺度として使うと、1,000時間で303.75tは約146.7組相当。**同論文の細繊維ラインを147台買えば製造できる、という見積ではない。** 今回寸法の口金、速度、切断・開口・品質の成立を証明していない。

135tには約2,809億個の良品が必要。1,000時間では良品約7.80万個/秒、側面窓は良品分だけでも約46.8万個/秒。品質歩留まり80％を見込んで検査前に全窓を作るなら約58.5万個/秒相当となる。個別の穴加工を当然に安価とせず、多数個同時成形・多数列の一括加工へ切り替える条件である。

回収率90％・上記歩留まりなら、良品1kgあたりの費用式は、
`1.125×原料単価 + 2.25×延べ加工kg単価 + 切断・開口・選別・再処理・検査・輸送費`。
同時成形は切削損失を減らせる可能性があるが、金型充填・微小孔・脱型・良品率・金型寿命の値がないため、安くなると決めない。

整地設備2億円の暫定範囲（設備・限定土木・税込、材料別）を材料加工費で置き換えていない。材料込みの比較には、まだ総費用の見積が必要。

## 5. 次の採否条件
1. Aの温暖結晶化は、結晶の生成だけでなく、飛行・着地・乾燥・枝の保持を同じ条件で示す。今回の工場形成を達成の代わりにしない。
2. Bは脱水後の孔形状と50℃湿潤復元を先に確認する。乾燥したら潰れる場合、含水率の調整だけで雪の感触を実現したとしない。
3. D/H105-Cは、窓なし筒と窓あり粒で、荷重経路・排水・加工量を比較する。側面窓が不要なら簡略化し、必要なら同時成形で体積損失を避ける。
4. PPは加工の根拠であり採用材料の決定ではない。UHMWPE・無機骨格・複合材に同じ押出条件を移さない。50℃復元、実スキー底面の摩擦、粉化、人体・環境を同じ製法の試料で確認する。
5. 冬の雪―粒―床の接続、300mmえぐれ／450mm層、雨後の回収・再整地・機能回復まで合格して初めて運用候補とする。
