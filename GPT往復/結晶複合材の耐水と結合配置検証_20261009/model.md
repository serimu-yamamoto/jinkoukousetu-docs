# 配合、露出、保持を分離する診断模型

[入力](inputs.json)・[再計算](reproduce.py)・[計算結果](results.json)。標準Pythonで再現可能。描画のみmatplotlibを使う。すべて必要条件の診断で、実測成功率や完成床の予測ではない。

## 1. 少量の結合材による全面被覆

結合材ECの重量割合をw、LLとECの密度をρc、ρbとする。空隙なし・体積加算の近似：

- ρmix=1/[(1−w)/ρc+w/ρb]
- φb=(w/ρb)/[(1−w)/ρc+w/ρb]

無作為に切った代表断面では平均面積率を体積率と対応させられるが、磨耗・表面偏析・圧力差がある実際の荷重割合とは同じではない。

別の極端な配置として半径r・厚さhの円板結晶をすべて均一膜δで包む。角を丸めず、円柱外径と厚さを広げる体積近似：

(r+δ)²(h+2δ)/(r²h) = 1 + (w/ρb)/[(1−w)/ρc]

二分法で解く。薄膜近似は δ≈q/(2/r+2/h)。この「包める量」は濡れ性・成膜性を証明しない。ナノ膜の実際の摩擦は下地や破膜にも依存するので、バルクECの係数をそのまま膜へ代入しない。計算した結晶厚は仮定であり、実LL厚さの測定値ではない。

## 2. 摩擦と接着の連成

結晶・結合材の摩擦係数をμc、μb、結合材の法線荷重割合をfsとする。変形・掘り起こし等をμoへまとめた診断式：

μtotal = μo + μc + (μb−μc)fs

本巡の仮値：μc=0.025、μb=0.20、μo=0.01、μtarget=0.04。したがってfs≤1/35=2.857%。どの値もLL/ECの実測値や天然雪の確定基準ではない。μc+μoが目標以上なら配置の改善だけでは達成しない。

保持部の投影面積割合をfa、荷重座全体の平均圧をp、せん断設計係数をSとする。滑走面で生じた接線力をすべて保持部が伝えると仮定：

τrequired = S p [μc+(μb−μc)fs] / fa

μoは粒の形状等で発生し、その力は別経路で骨格へ伝わる仮定。実際に同じ接着部へ追加荷重が流れるなら加算する。剥離、引張り、偏心、疲労、衝撃、クリープ、エッジ荷重はこの平均せん断式に含まない。引張強度を接着許容せん断強度として代入しない。

### 同じ結合部が上面と保持面を兼ねる特別な場合

均一圧力で面積率=荷重率、fs=fa=fと置くと：

f ≥ S p μc / [τallow − S p (μb−μc)]

分母≤0または必要f>1は、この模型では成立域なし。数値表は空欄を0と扱わない。p=4MPa、S=2のとき、摩擦条件も同時に満たすにはτallow≥8.4MPa。これは新材料の性能でも工学的安全保証でもない。

### 上面と裏面を分ける場合

fs=1%、fa=5%、p=4MPa、S=2なら診断μtotal=0.03675、必要τ=4.28MPa。両割合を独立に実現できれば、平均せん断の必要値を下げられる。材料選択だけでは実現せず、表面分析・局部荷重・濡れた後の接着測定が必要。無作為に混ぜた95/5配合から自動的には得られない。

## 3. 水量・乾燥エネルギー

S1製法の代表入力：固形分130mg、水20mL。水密度1kg/Lとして153.846kg水/kg乾燥固形分。

蒸発潜熱を仮に2.4MJ/kg、熱利用効率η、電熱購入単価30円/kWhとした単純模型：

E = 水量×2.4/(3.6η) [kWh/kg固形分]

η=0.35/0.70で293.04/146.52kWh/kg。加熱立上げ、換気、攪拌、乾燥速度、熱回収、残留水は別。天日・排熱・ヒートポンプでは購入エネルギー費が変わるため、普遍的な最低費用ではない。濃度10/50倍の行は仮想感度であり、溶解性・成長構造・加工性は未成立。

## 4. 全深度への機能層量と部分費用

基準床：2,000m²×0.45m×120kg/m³=108t。ただし粒数N=3.117691×10¹²、6座/粒、座径150µmは前巡の数量仮定。実粒の質量・形状と整合させ直す必要がある。

A = N×6×π(d/2)² = 330,564.886m²
M = A t ρmix

tは機能層の等価体積厚で、結晶一枚の厚さでも座全体の厚さでもない。材料歩留まり0.8、LL単価1,000/5,000/10,000円/kg、EC2,000円/kg、面積加工10/100円/m²は未見積りの感度入力。

Cpartial = M[(1−w)CLL+wCEC]/0.8 + A Cprocess

骨格、別途必要な裏面接着材、設備、溶剤回収、検査、輸送、排水、造成、税を含まない。再加工率10%の行は単純比例の年費感度で、寿命予測・年額化・実補修費ではない。

S2の投入比によるエタノール量は0.25M。仮に95%回収なら補給0.0125Mだが、初期充填、洗浄、運転損失、残留溶剤は別。工場工程の数量比較であり、現地散布は採用しない。

100日×16時間で、1m幅ウェブ上の有効配置率をφwebとすると、ウェブ長=A/φweb、必要速度=A/(φweb×96,000) m/min。乾燥炉長・裏面塗布位置精度・分割後の粒組立・良品歩留まりは未評価。微細な接点を一個ずつ組み立てる費用を、この面積単価で済ませたことにはしない。
