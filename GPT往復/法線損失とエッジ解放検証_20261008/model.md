# 計算の定義・導出・適用範囲

このモデルは材料の合格判定器ではない。法線変形の仕事、接点が横へ解放する仕事、繰り返し負荷の履歴を混同しないための計算器。係数はすべて仮定で、50℃のUHMWPE、PP、POM、発泡体等から同定したものではない。

## 1. 新しい面を通過するときの仕事と抵抗

一つの面要素について、法線圧力pと沈みδの一周期の仕事をU_A=∮p dδ [J/m²]と置く。幅b、速度vで、同じ負荷履歴の新しい面を毎秒bvだけ通過する場合、P_def=bvU_A、F_def=bU_A、Δμ=bU_A/N。

Nはその一枚のスキーの法線荷重。二枚の幅だけを使い、一枚の荷重と組み合わせない。これはエネルギー収支の等価抵抗で、スキーと粒の接触を解いた結果ではない。粒の押しのけ・破壊・界面の摩擦を含めた測定U_Aや全抵抗へ、同じ成分を再加算しない。旋回、速度変化、重なる走路、接触域の移動、動的圧力の変化は別途必要。

## 2. 指定した法線圧力パルス

T=L/v、ω=π/T、p(t)=p0 sin(ωt)、0≤t≤T。p0=Nπ/(2bL)とするので、b v ∫p(t)dt=N。圧力分布を与えた感度解析であり、たわむ板と変形する粒床の接触領域を連成して求めてはいない。

瞬時ばねK0とKelvin要素(K1,η)を直列に置き、δ=p/K0+x、dx/dt=(p−K1x)/η、τ=η/K1。K0とK1は面圧/変位 [Pa/m]、ηは[Pa·s/m]。バルクの弾性率E、雪のHV、粒一個のばね係数とは別の量。

未負荷の初期状態x(0)=0で、a=ωτと置くと、

~~~text
x(t) = (p0/K1) [sin(ωt) − a cos(ωt) + a exp(−t/τ)] / (1+a²)
W = ∫ p dx
  = (p0²/K1) {πa/[2(1+a²)] − a²[1+exp(−T/τ)]/(1+a²)²}
~~~

瞬時ばねの往復仕事はゼロ。Kelvin要素の仕事は接触中の粘性損失∫η(dx/dt)²dtと、除荷直後に残る蓄積エネルギーK1x(T)²/2の和。通過後はp=0でxが緩和し、残りも散逸する。後から形が戻ることを、すでに去った板へのエネルギー返却と扱わない。

この線形体は永久破壊・塑性圧密・側方流出・粉砕・水流・温度上昇・板振動を持たない。損失が小さくても、それらが小さいとの推定はしない。パラメーターの最適値は実測なしでは選べない。

## 3. 反復の定常値

周期P>T、除荷区間P−T。初回のパルス終了変位g=x(T)として、各通過直前のxは、

~~~text
x_(n+1) = exp(−P/τ) x_n + g exp[−(P−T)/τ]
x_* = g exp[−(P−T)/τ] / [1−exp(−P/τ)]
~~~

初期x0があるパルスでは上式x(t)へx0 exp(−t/τ)を加える。仕事は初回Wからp0 x0 a[1+exp(−T/τ)]/(1+a²)を引く。モデルの周期平均変位は2p0T/(πPK1)。コードは2,000回の漸化式計算と定常解を照合する。2,000回は試験回数ではない。斜面の自重、長時間クリープや整地の回復は含めない。

## 4. 横方向のピーク以降の解放

代表面積A=eL_edgeに対して、ピークτ_pから距離d_cで残留τ_rへ線形低下し、その後d_postだけτ_rで移動すると仮定する。

~~~text
F_peak = τ_p A
G_post = (τ_p+τ_r)d_c/2 + τ_r d_post
W_post = A G_post
G_above_residual = (τ_p−τ_r)d_c/2
~~~

ゼロ変位はピーク時点。ピークまでの蓄積・散逸を含まない。破断後の残留抵抗はゼロとは限らない。G_postは指定した移動距離までの仕事で、材料固有の破壊靱性ではない。面積eLの用法は説明用であり、S2の雪のSfから本模型の凝集則を同定したものではない。亀裂経路、摩擦、押しのけ、接点数、粒度・密度・向きによって実際の曲線は変わる。

## 5. 数値確認

48の法線入力条件で閉形式の仕事を台形積分と照合し、接触中の散逸と残存蓄積エネルギーの収支を確認。さらに別実装の常微分方程式RK4で3条件を4,000・8,000刻みに分けて比較する。せん断は9条件、反復は12条件。詳細はvalidation.json。これらを独立した材料実験数・成功割合として数えない。
