## 再計算

リポジトリルートを作業ディレクトリとする。依存ライブラリはこの巡ではNumPy 2.5.3、Matplotlib 3.11.2。Python 3環境で次を実行する。RTK環境では各開発コマンドを適切なRTKラッパー経由にする。

```text
python -m pip install --target .deps numpy==2.5.3 matplotlib==3.11.2
python -X utf8 "GPT往復/粒内補強検証_配向と荷重移行_20261008/calculate.py"
python -X utf8 "GPT往復/粒内補強検証_配向と荷重移行_20261008/plot.py"
```

計算は乱数を使わない。JSONはUTF-8・LF、有限要素の微小丸めは数値ライブラリで変わり得る。計算は異常なら非ゼロ終了する。図は結果を読み込み、表示確認済み。再計算・文章変更後は公開用ハッシュ一覧を作り直す。

## モデルの読み方

母材両端を変位拘束、繊維両端を自由端とする一次元線形モデル。せん断ばね、弾性率、配向は未校正。外層の体積整合は、製造時の繊維配置・端部閉鎖を保証しない。方向別の軸剛性指標を、曲がった実粒の曲げ剛性や50℃クリープへ直接使わない。末端応力による剥離判定はしない。

費用は占有樹脂体積を固定する比較と、仮に円形梁の曲げ剛性が同じなら細径化できる診断を区別する。後者の `ideal_resize_diagnostics` は原料費のみ、成形費込みの必要剛性倍率は `same_shape_cost_cases` にある。参考論文の8→3GPaは候補H25の実測ではない。
