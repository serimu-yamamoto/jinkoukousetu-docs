# 未実施の判別試験

設備・協力先は未確保、見積り・依頼送信・試作・実証は0件。これは[24個の割付案](test_plan.json)であり結果表ではない。試験前に具体材料、50℃保持設備、荷重・変位の分解能と安全な試料固定を確定する。

| 因子 | 水準 |
|---|---|
| 幾何 | 制限なし／復帰側の余裕＋柔らかい移行部を持つ内側ストローク制限 |
| 保持時間 | 1秒／4時間 |
| 水条件 | 乾燥／濡らした後に自由排水（含水量を実測） |
| 独立個体 | 各3個。独立製造ロットではない |

2×2×2×3=24個。比較の目的は、長時間保持後の折れ残り・濡れ閉鎖・復帰時の跳ねを識別すること。1秒も4時間も無次元Tではなく実試験の割付秒数。仮のDe・β・τから試験結果を埋めない。

1. 各個体の実寸と枝の初期角、50℃平衡温度、表面状態を記録。寸法±5％を合格仕様とする前に、実寸とλの対応を3次元解析または荷重測定で較正する。
2. 荷重―押込み―時間の全履歴を収録し、保持力の緩和を測る。原点通過と、その後の変位帯への滞在、残留応力・揺り戻しを分ける。
3. ストローク制限に接触したまま止まらないか、復帰時に周囲の粒を跳ね上げないか、再荷重で硬化しないかを観察。局所3D形状、接点摩擦が主要な未知量。
4. 部品段階を通過した場合のみ、粒群の法線押込みと横せん断を対で測り、実雪参照の力―変位・仕事・振動・残留深さを比較する。単粒の10％帯への復帰を雪質再現としない。
5. 4時間保持、濡れ、再整地の後に同じ応答を再測定。雨後に高さ・質量だけが戻る状態は復旧としない。冬の雪／粒／地盤の排水と残留せん断は別試験。

本24個ではロット差、疲労寿命、UV、微粉・溶出、スキー摩擦、人体・環境影響、台風流出、冬の界面・内部弱層は証明しない。完成材の選定にはこれらと製造費を含める。24個を全部通過しても目的全体の90％成功率とはならない。設備照会の未送信文と候補機関は[第82巡](../初回実証の設備照合と試験費用_20261009/inquiry_draft.md)を引き継ぐ。
