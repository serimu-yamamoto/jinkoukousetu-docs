## 剛性配置

曲面を付けず、同じ高さでk_a(r)=k0κ(r)を変える。p=k0κ(r)max(δ+θr,0)。力Fとモーメント0の釣合いからδ・θを解く。κは実物の物性測定値ではない。

q=θ/δとすると∫rκ(r)max(1+qr,0)dr=0は単調。区間内のκは一次式。負圧部分を切り取り、積分を区間中心へ移した多項式の厳密積分で求める。圧力の区間内最大は端点と二次式の頂点から計算する。移動方向については有限標本の最大で、全連続経路の最大を証明していない。

入口だけ：変化区間0.05/0.15/0.30、端剛性0/0.05/0.20、隙間比0.1/0.25。基準を含め20条件。κ=0は製造できる厚さゼロの枝という意味ではなく、数学的な端の参照条件。

両端：入口変化区間0.15/0.30/0.45、外側0.15/0.30、入口端0.05/0.20、外側端0.05/0.20/1。2隙間比で72条件。各隙間比について圧力比と沈み込み変動比の大きい方を最小化し、選出例を移動1,001点と境界近傍で再計算。条件通過割合を確率と呼ばない。

全体剛性倍率s=δ_end/δ_uniform_endで入口端の沈み込みを一致させる。この倍率で全κを変えても、固定法線力での圧力分布は変わらず、変位は1/s倍になる。根元厚さ代理は(sκ)^(1/3)、単純圧縮層厚さは1/(sκ)。根元体積代理は独立な同長・同幅片持ち枝が並ぶ仮定の積分で、全粒重量・量産費ではない。

同じ局所毛管力での変位増加は1/(sκ)。clearanceに対する力の無次元比をλとすれば閉鎖量/clearance=λ/(sκ)。ここでclearanceは局所の変形方向の隙間であり、排水用gと同一視しない。接触角・液橋・50℃クリープは入力されていない。

## 排水切れ目の分散

L=1、窓長W=1+γ、移動u∈[0,1]、下側有限長2+γ。周期W/nで支持区間長1/n・開口長γ/nを配置。窓内の支持長は常に1、開口長はγ。n=1は第102巡の幾何と一致することを照合した。

同じ独立ばね剛性で回転自由の力・モーメントを解く。n=1/2/4/8、γ=0.1/0.25の8条件、4,134平衡状態。移動501点に接触境界とその前後10⁻⁸を追加。下側粒の変形・自由運動、速度、摩擦、3次元姿勢や詰まりは未計算。

理想細隙流れはQ=b a³ΔP/(12ηℓ)。n本でa=g/nとしたとき、同じ深さのコンダクタンス比は1/n²。細口深さt、その後の幅gの出口深さℓ−tを直列、n本を並列とする抵抗比は1/n+(n²−1/n)t/ℓ。別々の出口が重なる配置では適用不可と記録する。入口損失を含まない平行平板・十分発達した層流の仮定であり、短い実孔へ適用できるかは未確認。
