# H69の支持モデルと製造収支

[calculate.py](calculate.py)はPython標準ライブラリのみ。結果は[results.json](results.json)と8個のCSVへ出す。[draw.py](draw.py)にはMatplotlibが必要。既定ではリポジトリの一時的な.depsを探索するが、通常のPython環境にインストールしても実行できる。物理試験0件、成功確率null。353行は曲線の標本点と仮定の感度行であり353件の実験ではない。

## 1. 部材を引っ張る幾何

固定した左右の支持点を±a、中央の下向き変位をxとする。半分の引張帯の現在長l=√(a²+x²)、自然長l₀、未変形断面A₀、軸方向係数E。引張時だけ働く線形の材料則を有限変形の幾何へ組み合わせる。

T=EA₀ max(l/l₀−1,0)

F=2T x/l = 2EA₀ x max(1/l₀−1/l,0)

U=EA₀ max(l−l₀,0)²/l₀

左右二本分を合計したUを微分するとFになることを独立差分で照合。大ひずみで線形材料則が正しい保証はない。帯の横収縮、曲げ、支持点移動、ロッドの座屈、接合、粒の三次元回転、せん断、接点摩擦を解いていない。このFをそのまま実物のスキー板の力にしない。

初めから張られている条件l₀≤aでは、F/x³はxとともに減少する。理由は

F/(2EA₀x³) = (1/l₀−1/a)/x² + 1/[a l(l+a)]

で、右辺の2項が非増加だからである。したがってF(x₂)/F(x₁)≤(x₂/x₁)³。今回の48.15→86.6025µmでは上限5.818。5→100 kPaの比20に足りない。材料のひずみ硬化・接触・支持点移動等を含めれば別の応答も可能だが、『初期張力を増すだけ』というこの模型の案は棄却できる。

## 2. 遅れて張る支持の逆算

第57巡の比較点x₁=48.15µm、x₂=86.6025µm、p₁=5 kPa、p₂=100 kPaを使い、セル投影面積500×500µm²でF=pAcellへ換算。両圧力は設計仮定であり雪の実測合格帯ではない。a=100µmを仮定する。

K=(p₂/p₁)(x₁/x₂)と置くと、l₀=(K−1)/(K/l₁−1/l₂)。必要なEA₀はp₂Acell/[2x₂(1/l₀−1/l₂)]。

逆算値はl₀=109.250µm、張り始める変位44.00µm、EA₀=0.09055 N。最大帯ひずみ21.09％。両端点は合わせるために解いたので実験への一致ではない。44µmより小さい変位ではこの帯の支持が0になり、別の柔らかい支持・形状保持が要る。第57巡の既存部材を足せば合計力は変わるため、統合時には再配分する。

同じ100 kPa端点に断面を合わせても、初めから張った帯は48.15µmで22.55 kPa、1.5倍の予伸長を置く線形外挿例では44.76 kPaとなる。後者の帯ひずみは最大98.4％で、S3の膜の破断ひずみ約89.9％とも整合せず、実材案としては採らない。S4の収縮差50％がそのまま全ての帯の予伸長1.5倍を生むという推定も行わない。

## 3. 雨による寸法・50℃の緩和

同じ断面のまま自然長だけが−1％、+1％変わる仮定では、低荷重点の圧力は8.22、1.84 kPaへ変わる。+2％ではその点で未接触になり0。この寸法変化は実測吸水率ではなく許容差を調べる反証条件。

形状や端点位置を固定しても、同じひずみで係数または緩和応力が20％へ下がれば力も20％へ下がる。幾何をロックしたことだけで50℃の応力保持を保証しない。線形粘弾性の一般式ならFの時間応答に緩和関数が入る。本巡は時間定数を測っておらず、1時間・1年の耐久予測を出さない。

## 4. 必要断面と材料量

S3の係数1.35 MPaは試験温度が確認できない参考値で、50℃値ではない。この値なら各半帯の断面67074µm²、幅500µmに換算した厚さ134.15µm、左右合計体積がセル外形体積の10.15％。薄い膜なら少材料で済む、とはまだ言えない。

2000m²×0.45mの床、外形セル500×500×577.35µm、包絡体の充填率0.5、実体密度1200kg/m³を仮定。N=V床φ/Vセル。帯だけの材料量は54.83t。係数5/20 MPaを仮置きすれば14.80/3.70tだが、その係数・回復・50℃湿潤・疲労を満たす材料は特定していない。枠、結合、外面、保持・排水部の量は別。

参考骨格108tとの比較では、54.83tは追加量と確定したものではなく、全体に許容する材料量の大きな部分をこの支持が占めることを示す。既存の支持芯を置換できるかは未設計。

## 5. 平面から作る場合の面積費

1粒の平面製造面積=セル投影面積×q、面付け歩留まりηlayoutと置く。必要面積A=N×Acell×q/ηlayout。q=2、ηlayout=0.8では1948557m²。100日・16h/日の生産期間なら1218m²/hが必要。12hの膨潤滞留を持つ工程なら処理中の面積は14614m²相当になる。巻物や積層で保持できるが、床占有面積そのものではない。

加工単価1/10/100円/m²の単純感度なら195万円/1949万円/1億9486万円。材料、設備、化学液、廃液、光学マスク、打抜き、外面処理、QA、歩留まり損、工場固定費は別。これは市場価格や見積りではない。整地設備・限定土木の2億円枠を、材料製造枠へ移していない。

51µm画素で50µmの部位は1画素未満。『少なくとも3画素を置く』という仮の設計規則なら画素≤16.67µmが要る。光学的な解像度、硬化広がり、厚さ方向の反応を保証する条件ではない。S4の成形工程をそのまま500µm粒へ縮小して量産済みとしない。

## 6. 結晶と熱の注意

S1/S2の伸長比20を幅200µmの部位に実現する幾何なら自然長10µm。非圧縮の一軸伸長では断面比1/20、横寸法比1/√20。この幾何だけから必要引張力や寿命を推定しない。大きな伸長で結晶を保つ案では、固定部・破壊・雨の膨潤が別の課題になる。

S2の温暖時の高い熱伝導は冬の粒床係数ではない。本巡はその値を0℃の雪床へ移して融雪量を計算しない。材料の熱伝導向上や弾性熱量効果を、受動的に冷たい雪を維持する仕組みと混同しない。
