# H100-Gの検証仕様（未実施）

設備・協力先は未確保。実施件数0、対外照会・発注0。本書は合格記録ではない。

1. **対照と候補を区別する**：C3元形状、一体粒内で枝の向き／根元断面を変える候補、局所変形を許す候補を比較。外観の分岐数を雪相当性としない。元形状の近似接点を修復し、候補には実体形状・製造公差・50℃物性を与える。
2. **単粒の荷重受渡し**：上板の法線／接線力を指定し、どの接点が先に除荷され、代わりにどこが受け持つかを観測する。力と変位と接触画像を同期。固定接点のLPだけで経路を合格にしない。有限接触面が偶力を担う場合は有効面積と転がり抵抗を測る。
3. **同時開離の空間分布**：粒床に多数接触する同じ試験板で、開離数、最大連続距離、接点力の最大／分布、板の変形、局所沈み込みを比較する。平均密度・接点数が同じ床でも、分散配置と集中配置を作り分ける。人工的な配置の比較は現実の発生頻度とは区別する。
4. **実スキーへ接続**：板のEI・ねじり・キャンバー、床の法線反力と横せん断を実測。実雪対照で、前後摩擦・エッジ保持と解放・沈み込み・振動・制動の許容帯を事前登録する。剛体板で通った結果を全スキーに一般化しない。
5. **50℃・保持・繰返し**：夏の4～5時間の履歴を含め、開離が集中するまでの変化と復帰を調べる。即時の弾性復元だけで一日を保証しない。油・常時散水で成立させる試験条件へ変えない。
6. **雨後の回収と再整地**：降雨・流出・回収・再圧密後に、同じ荷重分布と沈み込みの位置分布へ戻るか比較。質量や表面高さだけの一致を復旧としない。材料分級・微粉・汚れも記録。約60分のコース閉鎖条件は搬送・全幅施工・測定まで含めて検証する。
7. **冬の固着**：人工粒表面の固着と、粒床内部・基盤への残留保持を分離。排水後と残留水・凍結融解の状態を比較し、開離しやすい部分が連続弱面を作らないか調べる。
