## 入出力と確認範囲

- inputs.json：幾何・仮の材料物性・価格・寿命。すべて実測値と区別。
- calculate.py：有限厚さの線形接点、二直線の凝集力則、並列支持、直列治具、部分原料費。
- results.json／numerical_checks.json：計算値と24照合。独立した数値積分で指定経路の仕事を確認。
- bridge_screen.csv：96仮定組。正の軟化区間と仮のひずみ診断を同時に満たす55組を成功数へ変換しない。
- thickness_screen.csv：厚さ3条件。Gc一定の界面破壊仮説に限定。
- force_paths.csv：0〜25µmの801点。支持が残る反例と、支持を指定通りに解放する要求曲線。
- fixture_screen.csv：治具剛性3条件。材料の短い解放と装置の不安定な跳びを区別。
- draw.py／PNG・SVG：上記のオリジナル図2組。指定曲線は実現した機構の動的計算ではない。
- sources.json：一次資料の確認箇所・取得状況・限界。補足PDFのHTML応答を材料データとして使用しない。
- audit.py／document-audit.json：リンク・数値・出典状態・保護事項の文書検査。
- publication-manifest.json：公開対象のSHA-256とバイト数。自己参照を避け、このマニフェスト自身のハッシュは含めない。

## 適用限界

接点の面積・質量比と実荷重比は異なる。線形近似・同じ開口の並列接続・単一方向の分離を置いており、50℃の実物物性、混合モード、粘弾性、粒群の連結、寿命、製造公差、安全性は未検証。H65-Pの機械支持の解放曲線は要求であり、製作図やエネルギー散逸の解決ではない。H65-Mの粒内修復量へ粒間Rumpf式を流用しない。

部分材料費は仮単価・仮歩留まりで、工場・支持材・装置・税を含む見積ではない。雨後60分、冬の固着、450mm全深度、実ソール摩擦は今後の同一試料比較を必要とする。Claudeの受領・稼働は確認していない。
