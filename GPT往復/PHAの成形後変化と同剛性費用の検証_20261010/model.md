# 数式と境界

## 1. 成形後の硬化

[S1](sources.md)の E(t)=E₀tᵇ の比だけを使う。b=0.095±0.004（PHBHHx）、0.186±0.008（P3HB4HB）。E₀や正確な測定温度は補完しない。一定の材料・熱履歴でのみ時間tの意味を保つ。

成形後t₀からH時間の剛性変化率は D=(1+H/t₀)ᵇ−1。仮の許容変化δに対して t₀≥H/[(1+δ)^(1/b)−1]。時間の単位をそろえる限り結果は不変。t₀>0、b>0が必要。

5分〜10日の範囲内で比較し、50℃の促進倍率、昼夜・季節、吸水・UV・繰返し荷重を導入しない。2/5/10％という許容変化は診断用の仮値であり、雪質の感覚閾値ではない。硬度の見かけの安定をEや疲労寿命の安定と同じにしない。

表のGと降伏係数は別の構成則のフィット量。10日/5分の比を計算するが、GをEへ換算せず、復元率・50℃保持力にも使わない。傷からの変位回復や結晶化度も成功率ではない。

## 2. 同じ曲げ剛性での材料量

同じ長さ・幅・本数の矩形枝の線形曲げEIを比べる。厚さ比t₁/t₀=(E₀/E₁)^(1/3)、重量比M₁/M₀=(ρ₁/ρ₀)(E₀/E₁)^(1/3)。したがって原料費を同等以下にするには

E₁/E₀ ≥ [(ρ₁p₁)/(ρ₀p₀)]³、または p₁≤p₀(ρ₀/ρ₁)(E₁/E₀)^(1/3)。

PE基準M₀=135t、ρ₀=930kg/m³、E₀(50℃)=200MPa、p₀=500円/kgは比較用仮定。PHAのρはS1の1210/1230kg/m³。E₁(50℃)=200/400/800/1600MPaと単価500/1000/1500円/kgは必要条件を調べる仮値であり、既知の物性範囲や販売価格ではない。特に柔らかなA1000Pがこの剛性範囲を持つという意味ではない。

この重量比は枝以外も同じ比で薄くできるという仮定を含む。実粒で厚さを変えると毛管閉鎖、根元の応力・疲労、接触面積、摩擦、嵩密度、粒の絡み方が変わる。450mm層の充填率を同じにできることも未証明。EI一致を雪質一致としない。

## 3. 安定化工程の一部費用

流量Q[kg/day]、保持日数d、嵩密度ρbulkなら工程在庫=Qd、保管容積=Qd/ρbulk。単位容積・日あたり費用uなら保管費/kg=ud/ρbulk。原料単価p、年利率rなら単純な資金拘束費/kg=prd/365。定常生産を前提とするリトルの法則と単純積算である。

本巡はQ=5000kg/day、d=3日、ρbulk=150/600kg/m³、u=50/200円/(m³ day)、p=1500円/kg、r=10％という仮定。600kg/m³は密な半製品などの比較条件であり、開放枝粒をその密度で無損傷保管できる主張ではない。最終熱・圧力加工の前に保持しても同じ安定化にならない可能性がある。

倉庫・資金拘束の一部費用に限り、設備、乾燥・加熱電力、金型、労務、計測、保管歩留まり、寿命、輸送、施工、営業損失を含まない。税込2億円の整地設備・限定土木枠と、材料・工場・研究費を混ぜない。

## 4. 反証可能性

実品の50℃乾湿でE(t)と緩和・損傷を測定して、仮入力を置き換える。実スキー対向材で摩擦を測り、ダイヤモンド傷試験の係数を除く。査定には粒群の支持・解放と雨後再整地の再測定が必要。コードの85照合は逆算・単位・物量の照合であり、実材の検証は0件。
