# Claude監査（短報）：Gemini 理論再設計（固定感度＋3候補）2026-10-24
感度表の算術（毛管0.39kPa、f_w臨界32.5%、ThOD換算など）は一致する。逆算をやめたことも妥当。ただし、3候補はいずれも次の理由で現状のままでは棄却相当。

**共通の致命点**：3候補とも、粒そのもの、または外皮が合成高分子・化学修飾高分子（セルロースエステル、ポリウレタン、グラフト共重合、UPy）である。その摩耗粉が年数t〜百t規模で出るので、マイクロプラスチック（EU 2023/2055）と、依頼者の必須要件「無害」に正面から衝突する。生分解性を実証しない限り不可。

1. **候補1（圧力でガラス化する外皮）**
   - (a) 圧雪車が床に高い圧力をかけるのは約10秒だけである。通過後の床の荷重は自重の数kPaしかなく、接点圧は約0.2MPa以下になる。「2〜5MPaで30分保ってガラス化する」という前提が成り立たない。
   - (b) 高分子のTgが圧力で上がる量は、一般に0.2〜0.4K/MPa程度とされる（要出典確認）。5MPaでも約1〜2Kしか上がらず、常温の含水ゲルはガラス化しない。
   - (c) 立ち止まったスキーヤーも、20kPaを数分間かけ続ける（α＝0.01なら接点で2MPa）。圧雪車の圧力よりも長く続く荷重なので、スイッチは板の側で働いてしまい、貼り付く。
   - → 机上で棄却できる。
2. **候補2（UPy・ホスト-ゲスト）**：UPyの4重水素結合は、水中では水と競合して大きく弱まる。ホスト-ゲストのゲルで報告されている界面強度は、一般にkPa〜数百kPa級である。τ_int 1〜2MPaは根拠がない（未確認）。汚れによる失活もある。
3. **候補3（形で噛み合う粒）**
   - Lever et al. の「融けない状態での低摩擦」は、氷の粒（融点の近くで柔らかく削れる）に固有の結果である。硬い非融解粒子とPEの組み合わせには移せない。表層では垂直応力がゼロなので、強度も出ない。
   - この領域は、Codexの多方向探索（第1〜135巡）が、50℃クリープや乾湿摩擦まで計算済みである。重複を避け、その結果を参照すること。
4. **検討から抜けている道**：Claudeの理論批判検証で唯一筋が通るとした「融点40〜70℃の分子結晶（脂肪酸・ワックス系）。相同温度が高いので自己焼結し、摩擦熱で融けて自己潤滑し、潜熱で温度を一定に保つ」が、比較の対象に入っていない。依頼者のR40判断待ち。
5. **次の一手**：試作の前に机上で棄却を確定する。
   - ①候補1：Tgの圧力依存の一次資料と、荷重がかかる時間の算術。
   - ②候補2：水中での界面強度の一次資料。
   - ③全候補：EU 2023/2055への該当と、生分解性の確認。
   - ④脂肪酸・ワックス系との比較表。
   - 生き残ったものだけを、1g級の二片接合試験（水中、50kPa・30分圧着）に回す。
