# 第39巡 計算モデルと適用限界

物理試験0件、実物成功確率null。96条件の枝モデル、27条件の整地面積・滞在時間、4条件の寸法相似、5条件の数値表面形状を診断した。35項目は数式・数値解の整合確認で、材料の合格数ではない。

## 1. 同じ材料量で比較する枝

全枝長L=300 µm、参照rmin=10 µm。第38巡の半枝と同じ体積V=πL rmin²(28/15)を使う。節点核、枝同士の重複体積、端部の丸いキャップは含めない。半径は材料座標s∈[0,1]、s=0が根元、s=1が自由端。

- Uniform：r=rmin sqrt(28/15)。
- Quadratic a1/a5：r=rmin sqrt[(28/15)/(1+2a/3+a²/5)] [1+a(1−s)²]。
- Clipped taper：r=rmin max[1,{B(1−s)}^(1/3)]、B=5.1484809744。半径一定の先端区間は全長の1/B=0.194232。

最後の形は、先端の横荷重について、小変形のコンプライアンスC∝∫(1−s)²/r⁴ dsを、∫r² ds一定、r≧rminで最小化した一次元解。変分条件はr⁶∝(1−s)²で、最小半径制約を満たす所で一定半径へ切り替える。体積条件は(3/5)B^(2/3)+(2/5)/B=28/15。節点・端丸み・製造公差・摩耗・接点形状を含む全粒の最適解ではない。a5は半径下限10 µmを満たさない別対照であり、同じ下限制約内の候補として最適性比較していない。

## 2. 分離後の枝の大回転

一端を固定した平面・不伸長の弾性棒を診断する。粒床中の節点が固定されることを意味しない。力Fは世界座標の横向きに一定で、接触座標qLに作用。q=0.5又は1。載荷点より先は無荷重・同じ接線方向の直線として扱う。

載荷長ℓ=qL、t=x_material/ℓ、θが接線角、m=M/(Fℓ)、X,Yがℓで無次元化した座標。Iref=πrmin⁴/4、j(t)=[r(qt)/rmin]⁴、λ=Fℓ²/(E Iref)。

~~~text
θ′ = λ m/j(t)
m′ = −cosθ
X′ = cosθ
Y′ = sinθ
θ(0)=0, X(0)=Y(0)=0, m(1)=0
~~~

solve_bvpの荷重継続で、無載荷の直線からつながる解を求める。θ<π/2の枝を確認。実際の材料の座屈・枝同士の接触・三次元回転・節点支持を求めた計算ではない。E=100/300/1000 MPa、F=1/10/30/100 µNは感度用仮入力で、50℃の測定値でも実際の接触力分布でもない。

表面法線応力の大きい側を、4|M|/(πr³)+|F sinθ|/(πr²)で診断する。後者は変形後の軸方向力。棒の軸伸びとせん断変形は幾何解では省いている。円断面表面と断面中心の最大応力を足して架空の破壊指数にしない。

σ/Eも保存し、仮の2%を超える行を診断表示する。2%は材料の降伏・疲労・安全基準ではない。回転が大きい場合を解いたことと、材料の線形弾性・不伸長近似が十分なことは別。5時間クリープ、塑性、破損、接触圧、濡れ・摩耗、粒全体の運動、板の滑走・解放曲線は未計算。

小変形対照はδ=Fℓ³/(E Iref)∫(1−t)²/j(t)dt。大回転では荷重の腕の長さが変わるため、これを外挿しない。

## 3. 寸法相似と粒数

粒形・接触配置・密度・材料が相似で、外部応力が一定なら、寸法倍率aについてF∝a²、L∝a、I∝a⁴なのでλとσが変わらない。δ/Lも一定。一定の**一粒荷重**と一定の**床の応力**を混同しない。摩擦係数、粘弾性の時間尺度、接触数が変わればこの相似から外れる。

同じ総質量なら粒数∝a⁻³。重力荷重は∝a³、単純な毛管橋の力の尺度は∝aなので、応力由来の力との比はそれぞれa、a⁻¹。後者は相似な橋形・接触角・表面張力を仮定した寸法則で、本材料の濡れや泥化の予測ではない。

粒数の参考では四枝の体積和と仮密度1250kg/m³、固定比較量108tを用いる。核・重複・端キャップの補正がなく、床の充填状態も解いていない。この108tを新形状の床に必要な在庫と認定しない。計数単位の加工費1円/百万粒、加工費枠100円/kg、1000時間の製造は全て比較仮定。実見積りではない。材料のkg単価と粒数依存工程を分けるために保存する。

## 4. 整地の接触時間

比較コース50m×40m。閉鎖3600秒のうち展開・格納・確認へ計1200秒を仮配分し、移動・作業2400秒。幅wのヘッドが全域を覆う理想走行距離は50×40/w、速度v=距離/2400。旋回・横移動・加減速・重複・停止・終端の余走を無視した楽観的な時間帳簿で、実機能力ではない。

進行方向の振動作用長をl、周波数fとすると、地点の名目作用時間t=l/v、サイクルN=f l/v。閉鎖時間×fを各地点の入力にしていない。27行は幅10/20/40m、長さ0.4/1/2m、周波数20/30/50Hz。

論文の10,000回は鉄製ステープルの参考履歴で、本素材の必要回数ではない。名目Γ=A(2πf)²/gの一致も、粒が受ける変位・衝撃・絡み方・深さ450mmへの伝達の一致ではない。振幅2.5mmを片振幅と解釈した30Hzの算術は約9.06g。斜面での採用設定を推奨した値ではない。

## 5. 球列モデルによる架空の凹凸

半径Rの円がピッチpで重なる二次元外包絡線を、点プローブでなぞる幾何診断。η=p/(2R)、谷高さh/R=1−sqrt(1−η²)、最大傾き=η/sqrt(1−η²)。これらは摩擦係数でも、実粒同士の三次元の引掛かり量でもない。表面を球列へ離散化したとき、入力摩擦ゼロでも幾何の抵抗が生じる可能性を見つける指標。

実粒床DEMでは、同じ質量・外形・接触則を維持し、ピッチを半減する収束と、滑らかなカプセル等による対照が必要。今回その粒床DEMを実行したとはしない。

## 6. 検証内容
