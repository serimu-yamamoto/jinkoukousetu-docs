# 次の検証仕様（全て未実施）

設備・協力先は未確保。発注・対外照会はしていない。以下は合格の実績ではなく、順番と停止条件を定める。

1. **初期配置の修復**：元のC3隣接粒位置を、誤差より大きい正の隙間を持つ配置から接触へ近付けて再構成する。元入力・補正量・力の釣合いを残す。今回の−0.00201µmを消しただけで接点法線が維持されると仮定しない。
2. **経路の検証**：全移動区間で円弧距離の下界を求める適応分割と、必要な丸め誤差処理を追加する。下界≤0の区間は未決定／接触として保存し、点の合格割合で代用しない。有限変形と新しい接点を追う。
3. **力で動く条件**：C3、閉環対照、H99-S、H99-Fを、同じ外力・同じ密度・同じ初期履歴で比較する。実測摩擦・50℃粘弾性がない段階の力モデルは感度解析と表示する。横逃げ量・回転・局所たわみ・ピークと残留力・散逸仕事を観測する。
4. **枝の実片**：50℃で10～20µm級の接点相対変位要求を再現するが、この範囲を普遍合格値にはしない。保持後の戻り、損傷、乾燥／湿潤、繰返しを測る。第96巡の有限範囲への復帰を使い、一度原点を横切ることを復元と判定しない。
5. **床と実スキー**：実雪対照、同じスキー底面・エッジ・荷重・速度で、前後摩擦、横支持、沈み込み、振動、制動を同時評価。整地前後、散水・流出回収後、冬季界面を別条件で確認。単一小片の低摩擦をバーン合格としない。

治具は上板の法線力と高さ、横力と横変位を独立に測れ、粒の回転と枝たわみを撮影できる構成が必要。微小隙間1～2µm級を主張するなら、それより十分小さい位置・形状の不確かさを確保するか、形状を拡大した幾何対照を先に使う。拡大試片は実寸での毛管力・剛性・熱・摩耗の代わりにはならない。

雪相当の許容帯は実雪の分布とユーザーの体感比較に基づき事前登録する。未測定のまま任意の90％合格値を設定しない。非破壊で戻るだけでなく、夏は切れて支え、冬は荷重経路が保持されることを両立判定する。
