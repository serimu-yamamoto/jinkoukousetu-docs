# 第20巡：濡れた局部接合と樹脂内補強
物理試験0件、成功確率未算定。局部支持・仮材料・質量費用の診断を保存する。

- inputs.json：規定荷重、枝、パッド、腕、親粒、運用予算。物性は仮定。
- calculate.py：Python標準ライブラリで全計算と照合を実行。
- results.json：162局部条件、18重複除外、324質量費用条件。
- validation.json：454項目の数値整合。物理性能の試験ではない。
- plot.py：結果JSONから独自の2図を生成。matplotlib 3.11.2で確認。
- sources.json：一次資料の種類、読取範囲、転用不可事項。
- joint_topology.png／support_comparison.png：局部構成と変位比較。

実行順は `python calculate.py`、`python plot.py`。計算は追加依存なし。図はmatplotlibを実行環境へ用意する。plot.pyは作業用.depsがあればそこも参照する。RTK指定環境ではRTK方針に従う。依存ライブラリ自体は成果物に含めない。

梁はTimoshenkoの曲げ・せん断、接合面は法線ばねで並進と回転を与える。外側の受けを剛い粒内枠とする局部問題で、自由粒全体の剛性ではない。接着破壊、粘弾性、界面特異性、接触、3D粒同士の干渉は未計算。短く太い腕の3D妥当性は別確認が必要。

幾何小変形フラグは物理合格率ではない。剛性比は規定荷重下での理想固定枝を基準にした相対変位。材料の実測E、許容応力、安全率は今回取得していない。材料500円/kg等は税抜の仮比較で、接合機・加工・在庫等を含む完成費用ではない。
