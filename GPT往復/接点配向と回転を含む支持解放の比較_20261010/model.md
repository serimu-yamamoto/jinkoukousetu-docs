# 第109巡の模型・単位・境界条件
## 1. 接点のエネルギー
斜面座標zを法線、xを山/谷方向、yを横断方向とする。単位枝ベクトルnに対し、接点剛性行列Kc=kt I+(ka−kt)nnᵀ。接点密度×枝長²×ka=1へ正規化する。ka=1、kt=κは仮値。実粒のPa、荷重や温度へ換算しない。

均質な対称微小ひずみEを与えると、固定中心の相対変位はd=E n、エネルギーはU=1/2 <dᵀKc d>。これは載荷で既に接触している両方向線形接点の増分模型。引張接点の開離、摩擦すべり、接点追加・破砕、事前応力に由来する幾何剛性は含まない。滑走開始からの現物を直接計算したものではない。

6成分ひずみは[εxx,εyy,εzz,γyz,γxz,γxy]で、せん断テンソル成分はγ/2。エネルギーU=1/2 eᵀ C eから全6×6行列を積分する。法線/せん断の比較はC[2,2]/C[4,4]。Czzは他の法線ひずみ0の拘束係数で、ヤング率でない。

## 2. 向きの分布
円錐半角α、c=cosαに対しcosθを[c,1]で一様、方位角を[0,2π]で一様とする。θを一様にはしない。逆方向−nも同重みで含める。半角90°では偶数モーメントが全方向一様の球と一致する。円錐軸をy軸まわりにβだけ傾ける。

m2=<nz²>=(1+c+c²)/3、m4=<nz⁴>=(1+c+c²+c³+c⁴)/5。軸がzなら、
Czz=κm2+(1−κ)m4、
Gxz=κ(1+m2)/8+(1−κ)(m2−m4)/2。
球ではCzz/Gxz=(6+4κ)/(2+3κ)。この閉形式は数値積分と別に照合した。

円錐分布は人工的な比較入力で、粒形から予測した接点分布でも、整地によって達成された分布でもない。

## 3. 中心粒の並進と回転を解放
外側の全端点はE nに従う。中心粒だけに変位uと回転ωを許し、中心粒の接点位置r=n/2とする。相対変位d=E n−u−ω×r=E n+Dq、D=[−I,skew(r)]、q=[u,ω]。

全接点の二次エネルギーを最小化し、q*=−H⁺Bᵀe、C_relaxed=C_affine−B H⁺Bᵀ。H⁺は閾値1e−12の対称擬似逆。BとHは接点エネルギーの交差項・内部変位項から直接組み立てる。力とトルクの残差、接点ごとの直接エネルギーを別に検算した。

この緩和は指定した同じ外側端点に対してエネルギーを増やさない。実床全体の厳密上限とは称さない。外側の隣粒も動く自由粒群、環粒の非球形接点位置、内部枝の曲げ、接点数や密度は解いていない。下端固定粒の第106巡からka/ktを取り出して使っていない。

## 4. 連成と退化
xzせん断だけ自由にする2×2部分行列[A B;B G]で、G>0ならτxz=0のときγxz=−B εzz/G、法線係数A−B²/G。他の4ひずみは0で固定した比較である。G≈0ではこの逆算をnullにし、無限大の性能としない。

完全一方向で中心回転を許すとGxz=0になり、正常に退化を検出する。せん断を拘束したA自体は有限でも、全変形に対する支持ではない。Mandel変数へ変換して6方向の固有値を算出し、回転不変性・支持されない変形方向を確認する。工学せん断表現の固有値をそのまま回転不変としていない。

## 5. 計算範囲
κ=0.01/0.02/0.1/0.5/1、半角0/15/30/45/60/90°、傾き0/15/30/45°で120条件。Gauss–Legendre×方位角積分を4×16、8×32、16×64で照合。滑走成功率・破壊確率・安全率は計算しない。

91確認は解析/数値整合。外部端点の拘束、線形性、粒密度や接点数の未較正が残る。50℃、湿潤、エッジの継続切削や大変位の解放を検証するには、別の非線形・接触更新模型と物理測定が必要。

## 6. 有限接点の追加比較
6方向は±x/±y/±z、8方向は(±1,±1,±1)/√3、12方向は(0,±1,±φ)、(±1,±φ,0)、(±φ,0,±1)を単位長に正規化し、φ=(1+√5)/2。各配置の総重みを1とする。個々の接点の実剛性や実接点密度が同じ比較ではない。

各配置×傾き0/15/30/45°で12ケース。3配置の二次方向指標はI/3、四次指標は異なる。6方向の無傾斜比は2/κ、8方向は2(1+2κ)/(2+κ)、12方向は球分布と同じ四次応答。中心自由化による変化が0なのはこれら対称配置のこの境界条件での結果で、一般の粒には外挿しない。

6方向の姿勢平均はSO(3)のEuler角2つを8点ずつ、cos傾斜を4点Gauss積分して256姿勢を使う。各姿勢で中心変位/回転を最小化し、その後に同じひずみ下でCを平均する。この試行は自由粒群のネットワーク均質化や離散要素計算ではない。
