# 第78巡：模型・寸法・限界

第77巡の仮定W0=0.8πp0a0²=31.4159mN、p0=5MPa、a0=50µm、接触E*=0.5GPa、支持合成K=20,000N/mを継承。N分割後の各荷重F=W0/N、ばねk=K/N、支持変位δ=F/k=1.570796µm。これらは実物50℃特性ではない。

## 1. 軸圧縮柱と曲げ梁

円柱の軸剛性k=EA/LからA=kL/E、r=√(A/π)、I=πr⁴/4を逆算。横力Ft=μF、仮μ=0.1。基部固定・先端自由として

~~~text
εax=F/(EA)
εbend=4FtL/(πr³E)
y=FtL³/(3EI)+FtL/(0.9GA), G=E/[2(1+ν)]
Pcr=π²EI/(2L)² ; slenderness=4L/r
Pcr/F=πk²/(16EF)   # k固定ならLに依存しない
~~~

Euler座屈は細長い柱の微小変形モデル。短柱、ゴム状大ひずみ、座屈後へそのまま適用しない。細長比20、変位/L=0.1は粗いスクリーニング境界で精度や安全を保証しない。軸力による横たわみ増幅・塑性・クリープは未計算。表のlinear_model_stableはEuler比が1を上回るという意味だけで、candidate_validatedは全件false。

4本の固定‐案内梁は、両端回転を拘束し相対変位のみを許す。

~~~text
k=4 E w t³/L³
εmax=3tδ/L²
w=kL³/(4Et³)
~~~

2.5µmは高さ差等を考えた仮の設計ストローク。固定‐自由梁の係数を混用しない。図の白抜きは細長比L/t≥5、ストローク/L≤0.1のどちらかを外れる。円周方向の幅枠は必要な配置目安で、実際の梁配置・金型充填・干渉を証明しない。元接点の外半径b=1.5aN、梁を外側へL伸ばす径2(b+L)を元ピッチ3aN+10µmと比べる。

## 2. 一軸弾性エネルギー容量の下限

一軸線形材料、ヤング率E、各点の弾性ひずみ上限εlimという限定で、蓄えるエネルギーFδ/2に対し、密度は最大Eεlim²/2。したがって

~~~text
Vsupport ≥ Fδ/(E εlim²)
ΣVper_original_head ≥ W0δ/(E εlim²)
~~~

Nを増やしてもこの合計は下がらない。これは多軸応力・非線形材・幾何学的な剛体運動を含む普遍的な下限ではない。揺動支点は同じ鉛直ストロークの弾性エネルギーを全支持部へ蓄える方式ではないため、この数値をそのまま当てない。

材料量換算は2,000m²の仮粒数3.117691兆、6先端/粒が**独立した支持部を持つ設計**、密度950kg/m³。既存骨格を利用できれば全量が追加材料になるわけではない。複数先端が支持体積を共有する設計にはこの6倍の集計を適用し直す必要がある。ただし共有した剛体土台を上下へ動かすだけでは、同じ接点群内の相対高さ誤差は消えない。

0.5/2/5％のひずみ枠は50℃の実材料限度でも測定済み疲労寿命でもない。

## 3. H78-R：2先端の局所揺動分配

N=4/16の末端1組にWpair=2W0/Nを割り当て、剛な腕の先端を±l、l=(3aN+10µm)/2に置く。これは上位の分配機構がその組へ荷重を渡した条件。16接点全体の平衡を解いていない。

第72巡Q接点を再使用する。

~~~text
g(c)=3πc²/8+3πc⁴/16
F(c)=p0 aN² π(c³/2+3c⁵/10)
δcontact(c)=(p0aN/E*) g(c)
q=(Fhigh−Flow)/Wpair
δcontact(Fhigh)−δcontact(Flow)=Δh−2lθ  # 両接触があるとき
Fhigh+Flow=Wpair
lWpair q=κθ+MR  # 単調に動く場合
MR=Wpair bR + z(2πrw γ) lcap
~~~

bRは**測って同定すべき抵抗モーメント/Wpairという長さ**で、摩擦係数・物理的な支点半径ではない。bR=0/0.1/1/5/20µmは感度。κ=0/2×10⁻⁹/10⁻⁸Nm/radも仮の保持ヒンジ特性。保持ヒンジへ全法線荷重を通す設計ではなく、法線荷重は別の受け面へ渡す構想。

γ=0.0679N/m、rw=10µm、lcap=25µm、z=0/5は水橋の仮診断。汚れ、粘土、濡れによるbR変化、凝着・粘性・凍結は含めない。滑走中は小さい水橋でも無荷重時の自重に対しては無視できない。

θ=0で駆動トルクがMR以下なら動かず、上回れば0≤θ≤Δh/(2l)で非線形接触とトルクを解く。接触が失われる場合は低い側の力を0とする。準静的・単調な開始条件だけ。回転慣性・ヒステリシス・方向反転・滑走横力をここに含めていない。

## 4. 横力も含めたモーメント予算

接線力μWpairとその反力の間の有効高さhがあれば、追加モーメントの絶対値はμWpair h。回転角が2°以下と仮定する場合の保守的な合計上界は

~~~text
|q| ≤ [bR + Mcap/Wpair + κθbound/Wpair + μh]/l
~~~

右辺が0.1以下ならこの限定のトルク予算に収まる。超えたことだけで実際に必ず10％以上偏るとは言えない。符号が相殺する場合もあり、機構の位置・接触維持・角度枠を別に確かめる。lateral_moment_budget.csvは回転運動の解ではない。

N=16、bR=1µm、κ=2×10⁻⁹Nm/rad、上記水橋5個、μ=0.1ではh≤12.214µmがこの条件。hは粒全体の高さではなく、力と反力の間の有効距離。横力の経路を浅くする設計が必要になる。

## 5. 受け面と物量

受け面の独立診断は円筒対平面のHertz線接触。曲率R=250µm、軸長B=100µm、E*=0.5GPa。

~~~text
aH=√[4Wpair R/(πE*B)]
pH=2Wpair/(πaH B)
margin=10µm − aH − R|θ|
~~~

N=16ならaH=5µm、pH=5MPa。圧力は実材料の許容値ではない。回転に伴う接触域の移動をRθで概算。幅余裕が正でも有限厚さ・端効果・粒内の全配置・転がり純度は未検証。軸長100µmの受け面が隣接する全組と干渉せず配置できることも未証明。

コスト表の末端バーは長さ2l、幅20µm、厚さ10µmの体積例だけ。腕自身のたわみ・ひずみ、支点・抜け止め・捕捉構造・支持ヒンジは未設計であり、この断面を必要十分な腕断面としない。完全二分木ならN−1の分配節点が必要という件数は計上するが、二分木全体の構造・荷重分布を計算したことにはならない。仮単価500/2000円/kg、歩留まり80％、税抜。完成品、整地設備税込2億円、全造成を区別する。
