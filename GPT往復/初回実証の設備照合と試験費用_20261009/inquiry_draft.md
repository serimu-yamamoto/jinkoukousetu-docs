# 試験機関への照会文案（未送信）

送信先候補：KISTEC 機械・材料技術部 材料物性グループ。代替照会先：JTLの摩擦摩耗試験窓口。正式な宛先・依頼者情報は送信時に入力する。本文の機関名・当て先を替えて一通ずつ使う。外部送信・見積取得・発注は行っていない。

件名：50℃・UHMWPE対向面の乾湿摩擦摩耗試験について、設備適合性と分割見積の相談

夏季屋外用の人工雪状粒の研究で、粒の局所接触材とスキー底面相当UHMWPEの摩擦・摩耗を比較したいと考えています。既存の試験設備や協力先はまだありません。公開研究資料は https://github.com/serimu-yamamoto/jinkoukousetu-docs にあります。

候補は無充填UHMWPE、無充填PEEK、耐加水分解性を確認する無充填エラストマーの3系統です。グレード・試料・対向材は未確保で、入手可能な材と加工寸法を相談したい段階です。50℃、名目0.3MPa、定速1m/s、200m、乾燥と一度純水で濡らし排水した状態を初期案としています。油・塩・フッ素・シリコーン潤滑、連続給水は使用しない条件です。

最初に3材×固定／移動の配置2方向の乾燥各1走行（計6走行）で治具・温度・微小摩耗測定を確認し、その後に3材×乾湿×独立3試片（計18走行）を考えています。前段の6走行が不要、又は他の予備確認が適切な場合は根拠と代案をご提案ください。

4mm径平面ピン・半径20mmの回転軌道なら法線力約3.77N、約477.5rpmとなりますが、これは寸法例です。相手材の実接触面積、速度の内外周差、芯ずれ、摩擦発熱、板側への移着を考慮し、適切な形式・寸法を提案いただけますか。往復式を使う場合は速度波形と反転条件、同一場所の再接触時間を明示してください。

回答いただきたい点は以下です。

1. 実UHMWPE対向面・50℃・低荷重・1m/s・一度湿潤を同時に扱える機器と治具、及び制限。装置ごとの最高仕様の組合せではなく、今回可能な実施条件をご提示ください。
2. 力・温度の連続記録と、前後同一位置の3D形状、移着・摩耗粉の評価方法。0.6µm前後又はそれ以下の摩耗を想定した検出限界と、軟質材の変形回復・ブランクの扱い。
3. 6走行と18走行を別々に、試料／加工／治具／対向材／温調乾湿準備／試験／形状測定／粉回収／元データ／報告／運送／税を分けた見積り。独立試片へ追加条件料金を適用できるかも明示してください。
4. 必要な試料寸法・枚数・予備数、グレード選定支援の可否、材料データと添加剤情報、納期・実施場所・依頼者の利用資格。
5. CSV等の力温度履歴と元形状データ、校正・検出限界・逸脱記録を公開GitHubへ保存できる範囲。必要な帰属表示や公開条件。

この照会は実施可否と費用確認のための案です。試験の申込み・発注・支払いや契約の確約ではありません。
