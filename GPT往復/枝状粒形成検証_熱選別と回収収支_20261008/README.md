## 再現

Python 3で、このフォルダを作業ディレクトリにして実行する。

    python calculate.py
    python plot.py

calculate.pyには外部ライブラリ不要。作図にはmatplotlibとnumpyが必要。今回の作図はmatplotlib 3.11.2、numpy 2.5.3を使用した。リポジトリ直下の一時的な.depsが存在すれば作図コードが参照し、それ以外は通常のPython環境を使う。実行結果と図はUTF-8の公開ソースとともに保存する。RTK利用環境では上記コマンドをrtk summary経由で実行する。

## モデルの読み方

- 枝半径と直径を区別する。熱伝達は円柱の集中容量。枝同士の熱伝導、気流の遮蔽、結晶相の分布を解いていない。
- 粘性毛管時間ηr/γは次元的な時間尺度。実際の丸まり完了、分裂、溶着の予測式ではない。
- 支持枝を融点未満に保つことは、支持剛性を保つ保証ではない。
- 湿潤曲げは、L/r≥10かつδ/L≤0.1だけを今回の診断範囲とする。範囲外の数値は反証用の指標で、実変位ではない。
- 工場収支は非ハロゲンの閉鎖フラッシュ工程の仮計算。液中析出・洗浄の費用には流用しない。
- 新しい分離・熱仕上げ・品質保証費は未確定。500円/kgは比較単価であり見積りや購入価格ではない。
- 回収不足分は環境への許容排出ではない。累積溶剤循環量は槽の同時保管容量ではない。
- リサイクル可能な樹脂でも、再溶融だけで枝形状が戻るとはしない。

独立エンタルピー積分との最大相対差は約1.1×10⁻⁹（最細分割）。20項目が通ることは実装の整合であり、雪のような滑走や人体への影響の検証ではない。
