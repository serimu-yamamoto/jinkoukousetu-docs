# 実測値の適用範囲と同定可能性

## 1. 転記と計算の区別
TA328表1から23/30/40/50/60℃の値をmeasured_inputs.jsonへ転記した。PDFテキストを確認し、画像ピクセルは未照合。表の温度・列名・単位を保つ。本文での計算は30/50℃の中心値。±は原記載の幅としてのみ扱い、信頼水準・相関・母集団分布を仮定しない。外部試料の測定と本プロジェクトの実物試験0件を区別する。

E′は保存弾性率（MPa）で、前巡の等価支持剛性k（N/m）ではない。前巡部品の標準線形固体の数学式を再利用しているが、Eをkへ幾何換算したことにはならない。

## 2. 同じ材料の幾何補償
円形梁I∝r^4、k′∝E′r^4/L^3。E30′/E50′=qなら、半径比q^(1/4)、同じ長さの体積比q^(1/2)。有効長さだけならL50/L30=q^(−1/3)、並列の有効本数だけならn50/n30=q。全粒の質量や開離経路は別に必要。

均一な線形材料ならk″/k′=E″/E′で、幾何係数を変えても比は不変。同じ変位振幅の周期損失はπk″A²なので、保存剛性を同じにすると損失比はtanδ50/tanδ30。この比較を力一定・実滑走の総摩擦へ拡張しない。

## 3. 単一複素データに一致するSLSの族
測定角周波数ω0、E′0>0、E″0>0に対し、自由パラメータx=ω0τを選ぶ。
E0=E′0−E″0x、ΔE=E″0(1+x²)/x、τ=x/ω0。
0<x<E′0/E″0なら全係数が正で、E*(ω)=E0+ΔE iωτ/(1+iωτ)は測定点へ一致する。

今回はx=.1/1/5の3反例。すべて1Hzで同じ748+i93MPaに一致する。1/10/100/666.666…/1000/5000/40000Hzを評価した。5kHzの損失比約97.1は選んだ3例間の比であり、物理的上下限・確率区間ではない。実在する3材料と認定しない。

独立検算はMaxwell枝の直列コンプライアンス [1/ΔE+1/(iωη)]^(−1) と並列E0を計算し、共有部品の保存/損失式と比較した。温度換算、結晶緩和の全スペクトル、非線形、自由粒の接触は同定していない。

## 4. 物量・費用
母粒質量M、補償対象部分の質量比b、該当枝の体積比aなら追加質量M b(a−1)。価格Pとの積が追加材料費のみ。密度同一、該当部分以外不変の条件付き算術。bは10/30/100％、Pは500/2000円kgの感度。実成形、荷重参加、開口の維持、年間交換率は未測定。

53確認は代数、複素インピーダンス、正の係数、端点・物量・入力の確認。測定値の外挿が正しいという実証ではない。
