# 第93巡の模型と適用範囲

これは方向変更を見落とす集約指標の反例であり、摩耗・寿命・成功率の予測ではない。[入力](inputs.json)と[再計算](reproduce.py)を公開する。

## 1. 第54巡から継承する方向行列

同じ材料表面の同じ小領域について、接触中の仕事重み w と、材料に付いた座標内の相対滑り方向 u を用い、Q=Σw uuᵀ/Σw とする。180°の往復は同一軸。無仕事なら未定義。小さい固有値は方向の広がりの診断で、配向そのものを測った値ではない。違う粒・違う場所の履歴を合算すると誤る。例えば粒Aは0°だけ、粒Bは90°だけなら各粒は一軸でも、全体を合算したQは等方になる。

今回の比較は0°と90°を同じ距離ずつ擦り、法線荷重・摩擦係数を一定と仮定。全距離1,000mmで、方向変更間隔を1／2／5／10／100mmにしてもQの小固有値はすべて0.5。摩擦が変化すれば仕事重みも変わり、距離だけではQを決められない。

## 2. 集約値が同じでも消えない自由度

方向変更直後の仮の活動度を1、同一軸での累積滑り距離sで exp(−s/ℓ) に減衰する診断模型を置く。90°変更ごとに完全リセットする。これは著者独自の反例で、原著の式・分子機構・当該材料の測定曲線ではない。ℓは0.1／1／10mmの仮定で、原著の5mmから同定していない。

各区間で積分すると A=ℓ[1−exp(−L/ℓ)]。等長区間を繰り返した全距離当たりの活動度は

~~~text
r = L / ℓ
H = (1 − exp(−r)) / r
0 < H < 1
~~~

r=0.1でH=0.951626、r=10でH=0.0999955。比9.51669はこの仮の活動度の比だけで、摩耗倍率でも改善率でもない。同じQからHを一意に復元できないことを示す。Hを摩耗へ結ぶ係数、非零の定常摩耗、温度・荷重・角度・再接触・経時回復は未同定。一般の角度や連続曲線、転がり、異なる区間順への拡張はしていない。

比較開始も変更直後とした周期状態。純粋な未配向・初期面の摩耗を0とする式ではない。H=0.1の逆算r≈9.99955も診断用で、採用基準ではない。

## 3. 整地と滑走を分ける

接触を離して粒を回しても、次回接触方向と表面配向のずれは残り得る。したがって「無荷重回転だから次の滑走も無摩耗」は導けない。整地中の摩耗と、その後の滑走中の摩耗を別々に回収・計測する。回収率や粒姿勢の分散を寿命へ換算しない。

## 4. 試験時間の算術

1mm往復の各片道を1区間とし、仮v=0.05m/s、加減速a=10m/s²。速度台形が成立する必要条件d≥v²/aを満たすと、区間時間はd/v+v/a=0.025秒、定速の距離比は75%。測定には実際の速度履歴が必要で、全区間が定速ではない。

同じ1mを擦る各組で1,000区間。各区間の除荷・停止・再負荷を仮2秒へ揃えると、走行25秒＋停止2,000秒。18組・着脱各20分で16.125時間。仮の時間単価3,000／10,000／30,000円では48,375／161,250／483,750円。設備能力・見積り未取得。校正、加熱待ち、試料製造、観察、治具、税、再試験を含まない。

10m/sの実滑走速度を同じ1mm・同じ加速度で再現できないことも照合した。1m試験は装置と摩擦履歴の初期診断であり、耐摩耗寿命を判定する距離として保証しない。
