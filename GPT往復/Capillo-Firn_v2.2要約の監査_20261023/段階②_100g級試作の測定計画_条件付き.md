# 段階②：100g級試作の測定計画と棄却判定案

2026-10-23。対象はCapillo-Firn候補。**配合を捏造しないため、製造レシピの確定版ではない。** 受領した改訂要約はv2.2、追加全文はv2.1である。ここでは両者に共通して必要な測定仕様を定める。設備・試料・協力先は未確保。実物0件。

## A. 試作へ渡す前に固定する入力

| 必須記録 | 固定する内容 |
|---|---|
| 版・原料 | 一つの配合ID、全成分名・CAS・相・グレード・ロット、乾燥固形分gと実秤量g |
| 水 | 分散原料の持込水、自由添加水、工程で除去する水、最終含水率の定義 |
| 芯と外皮 | 各成分の配分、二層成形又は後被覆の順序、粒径・層厚・開孔の測定方法 |
| 製造条件 | 原料の調製法、pH、温度、時間、圧力、送り量、切断、熟成。未決定欄を推測で埋めない |
| 収支 | 製品、装置残留、回収不能分、分析用採取、添加・排出水を区別 |
| 測定環境 | 試料実温度、湿度、時刻、含水率、圧縮・除荷・待機履歴 |
| 比較・判定 | 原案のどの仮説を検証するか、目標範囲、測定不確かさ、逸脱時の判定 |

100gは最終湿潤製品の設計基準とし、購入原料を単純に合計100gとしない。例えば旧版のCNF乾燥4.5gを、仮に固形分2％の分散液で供給すると、原料は225g、その持込水だけで220.5gとなる。目標水52gに対して168.5gの除去等が必要になる。2％は例示であり採用グレードの仕様ではない。脱水・乾燥を使うなら、その後の孔構造・再分散性と費用も確認する。

未知の化学処理条件をこの文書から補完して製造しない。製造担当・試験所が材料仕様、取扱条件、装置適合性を確認して作業指示を固定する。

## B. 100g級で最初に行う順序

1. **別々に調製した試作を識別する。** 最初は独立3バッチを提案する。3回測定した同じ粒群を3バッチと数えない。この反復数は初期のばらつき把握用であり、成功確率や220日寿命の証明ではない。
2. **製造直後の全量収支と形態を記録する。** 実収量、含水率、凝集塊、独立粒、破砕粉、粒径分布、芯・外皮の位置を確認。形のよい粒だけを抽出して全収率としない。
3. **湿潤粒の包絡体積を測る。** 質量と独立した体積測定を用いる。画像・CT等は分解能、境界の定義、湿潤状態の保持、既知形状による確認を含め、試験所と選ぶ。全ての細孔や水相を分離できる装置が既にあるとは仮定しない。
4. **床体積を別に測る。** 既知の容器へ一定手順で充填し、圧縮前、規定圧縮中、除荷直後、待機後の高さ・質量を記録。粒密度も押し固める過程で変化し得るので、同じ履歴の試料を比較する。
5. **30℃と50℃の履歴を比較する。** 空気設定温度だけでなく試料の実温度を測る。密閉して水分をほぼ保つ条件と、湿度を記録して水分が変わる条件を分ける。旧案の50℃×8hは初期スクリーニングとして扱い、220日へ外挿しない。
6. **圧縮・破断・30分回復の試料を分ける。** 密度・形態の観察結果を先に判断し、必要量を追加製造して機械試験へ進む。壊した供試体を無申告で初期状態へ戻したことにしない。
7. **新粒と再生粒を比較する。** 再生後の芯・外皮、粒径、微粉、含水率、密度を同じ方法で観察する。形を作り直した質量と、性能が回復した質量を別に集計する。

水浸置換は吸水・溶出・膨潤・脱気、乾燥法は収縮により測定対象を変える可能性がある。測定法による影響を確認するまでは、乾燥骨格密度を湿潤包絡密度として使わない。気体割合13.47％、水も含む孔隙割合、粒子間空隙を別々に報告する。[密度の定義](https://micromeritics.com/density/)

## C. c・φ・δfには追加の測定設計が必要

### 床の見掛けせん断特性

原案と比較する例として垂直応力25・50・80kPaを用い、温度、含水率、速度、排水条件を固定した新しい供試体を割り当てる。せん断抵抗の最大値、残留値、変位、鉛直変位、接触面積の変化を記録する。

その条件で直線近似が妥当な場合に限り、τ=c_app+σ_n tanφ_appを当てはめる。未測定の間隙水圧を無視して真の有効応力物性と呼ばず、屈曲・速度依存・再現性不足も結果として残す。原案の42kPa・36°を固定して残りの値を逆算しない。

ASTM D3080/D3080Mの公開説明は圧密排水条件の試験であり、速度を上げるだけで非排水試験や高速スキー試験になるわけではない。供試体寸法と粒径の適合も試験所が確認する。本書は同規格の全文を取得した実施手順ではない。[公開範囲](https://store.astm.org/d3080_d3080m-23.html)

### 微小接点の破断と解放

δf≤10µmを調べるには、どの接点のどの位置間の変位かを先に定義する。装置のクロスヘッド変位、粒群全体のせん断変位、個別ネックの開口・滑りは別の量である。

局所変位を読む方法と装置変形の補正を用意する。10µmを判定したいなら、その十分下の測定不確かさが必要であり、例として1µm以下を計測系の検討目標にする。これは材料の合格値ではない。測れない場合は「未評価」とし、MCC長さからδfを代用しない。

荷重―変位曲線を取得し、残留摩擦、装置変形、破壊面積を考慮する。三角形近似が合わなければ0.5×Sf×δfの式を採用しない。機構が分離できない仕事は見掛けの仕事として報告し、天然雪の破壊エネルギーと断定しない。

### 試料量の例

60×60×20mmの箱は72cm³。密度487なら35.064g/個で、3応力分は105.192g。3独立バッチ×3履歴×3応力なら27個、約946.728gとなる。その他の測定・予備・加工損失は別である。この寸法は量の説明用で、規格適合・代表性が確認された試験箱の指定ではない。

したがって100g級製法試作と、c・φ・δfまで測る試験セットを別に見積もる。配合規模を変えた場合も製造条件と構造が同じか確認する。

## D. 事前に固定する判定

| 観測結果 | 判定と次の行動 |
|---|---|
| 配合ID、原料固形分、持込水、工程条件が未確定 | 製造指示書未成立。入力を固定する |
| 体積・含水・形態の測定法が試料を変え、影響を補正できない | 測定方法を再設計。材料が成功／失敗したとはしない |
| 独立粒や芯・外皮が形成されず、塊・ペーストになる | 当該製法で構造を実現したという主張を棄却。変更は別版として残す |
| ρp・ρbが目標に一致しない | 測定不確かさと事前の許容幅でモデル仮定を判定。別々の物性を後から動かして埋め合わせない |
| 資料が掲げた400〜550kg/m³の床密度帯を外れる | 当該履歴での密度目標未達。ただしこの帯だけで雪感を判定しない |
| τとσ_nの直線近似が成り立たない | 単一c・φモデルを棄却し、測定曲線・履歴依存を残す |
| δfが測定できない、又は局所変位と床変位を分離できない | δf仮説は未評価。達成扱いしない |
| 設定した30分後に必要性能が戻らない | その製法・履歴での60分営業復帰仮説を棄却。待機時間を隠して延ばさない |
| 再生で外皮が消える、又は同じ性能を回復しない | 造粒量を有効再生量から除く。性能合格収率を更新する |
| 初期密度・小試料強度が合格 | 次段階の摩擦、摩耗、排水、冬、曝露へ進める。人体滑走の承認ではない |

ρp=1,180.40等の細かい数値に対する工学的許容幅は原案にない。無根拠に±5％等を付けず、必要性能との対応と測定不確かさを踏まえ、試験前に定める。モデルの特定値が外れたことと、別条件でも目的を満たせないことは同じではない。
