# モデルと適用範囲

単位はコード内でSI。Rは局所の同一球接点の半径、mは開放粒全体の仮質量。Rから粒全体の質量を算出していない。物理試験0件。

## 1. 水橋

v=V/R³、接触角θ=0。sは二面の隙間。IAPWS水温式は、τ=1−(T℃+273.15)/647.096、γ=0.2358τ^1.256(1−0.625τ) N/m。純水・飽和界面の値を選別の基準とする。

s_c=R(v^(1/3)+0.1v^(2/3))。

2007近似：
F(s)=F0/(1+aS+bS²)、F0=2πRγ、S=s/(R√v)、a=1.05、b=2.5。

q=√(4b−a²)=√8.8975 とし、式を積分すると、
W=F0 R√v (2/q)[atan((2bS_c+a)/q)−atan(a/q)]。
下限を省略せず、独立Simpson積分4096区間と3体積で照合する。

2007 PDF式5には表示上の下限項がなく、式4の定積分と一致しない。2018 PDF式3には下限項があるが、印刷定数8.8795は4×2.5−1.05²とは一致しない。ここでは双方の印刷式を無条件にコピーせず、力式から算出した。この照合は原著の全実験を再検証するものではない。

2024近似（接触角0に限定）：
x=s/s_c、
a_s=−0.3319 v^0.4974+0.6717 v^0.1995、
b_s=13.84 v^−0.3909−12.11 v^−0.3945。
F0,2024=2πRγ(1−0.3823v^0.2586)。
F2024=F0,2024(1+a_s x)/(1+a_s b_s x+b_s x²)。
WをSimpson法2048区間で計算し1024区間と照合。両模型ともs_cで力を0へ落とす。
原著のv範囲10⁻⁶〜10⁻¹内の10⁻⁶、10⁻⁴、10⁻²を比較。図は間の対数点も計算。
新近似の数値計算と旧近似の閉形式が一致する必要はない。双方とも平衡・軸対称・単独二球橋。接触角履歴、粗さ、複数水橋の合体、粘性、非球形、動的水移動は未実装。

## 2. 振動の二つの診断

正弦駆動のΓ=Aω²/g、壁速度Aω、ω=2πf。
仮の相対速度v_rel=αAω。α=0,0.1,0.5,1は未知の伝達の比較値で、測定した分布でも成功確率でもなく、実機でα≤1となる保証もない。

同質量粒対の相対運動エネルギーはm v_rel²/4。n橋の仕事との比は(m v_rel²/4)/(nW)。
別に名目の慣性力比mΓg/(nF0)を出す。両者を同一の運動方程式の解や装置合否にはしていない。
重力向き、接触拘束、荷重経路、衝突速度、共振、摩擦と粘性が未実装。二つの比が1以上でも凝集解離成功ではない。

## 3. 柔軟根元

片持ち矩形根元 k=Ewt³/(4L³)、先端力F=nF0。
δ=F/k、表面最大ひずみε=6FL/(Ewt²)=3tδ/(2L²)。
仮ひずみ予算ε0=.005ならF_budget=ε0Ewt²/(6L)。
E=0.2/1GPaもε0も仮定。δ/L>0.1の行は小変形の適用外と明示する。
残留ひずみ、クリープ、疲労、割れ・摩耗、局部接触はこの式で合否判定できない。

## 4. 60分・損失・熱

面積A、処理面積割合f、深さdで、取り込み体積V=Afd。処理枠2280秒よりQ=V/2280、質量流量=120Q。
15秒滞留の表はQ×15という理想バッファ容量で、測定した処理時間や3槽装置の総容量ではない。
現位置処理ならQ全量の輸送は不要となり得るが、深さ別の作用確認が必要。

常に床質量Mを補う場合の年補充量=M N r。元の粒だけの残存率=(1−r)^N。両者を混同しない。
N=200、年間補充目標2%ならr≤0.0001。回収された使用不能片もrに含める。環境放出目標ではない。
仮原料単価500円/kg、加工・税・回収・処分等を含まない。

残水体積割合wで水重量=Adw×1000。潜熱を50℃付近の丸め仮値2.38MJ/kgとして比較し、熱量/2280を熱出力に換算。電気消費・自然乾燥時間・ヒーター実効率は算出していない。
