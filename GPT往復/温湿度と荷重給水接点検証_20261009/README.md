# 第44巡 再現資料

[報告書](../GPT回答_多方向探索第44巡_乾燥と濡れをまたぐ滑走接点と荷重給水_20261009.md)。物理試験0件、実物成功確率null。

- inputs.json：固定の診断入力。未測定値を材料実績としない。
- calculate.py：NIST蒸気圧、IAPWS表面張力、乾いた疎水性孔の拡散、侵入圧と理想液体流量、全体水量、荷重割合、薄層費用。
- humidity.csv：36温湿度条件。外気と接点の相対湿度を分離。
- pores.csv：36孔条件。保持圧が続く側と、開口後に保持圧が消える側を両方保存。入口圧以下では給水しない。静的な水容量条件を物理合格判定にしない。
- pore_sensitivity.csv：孔半径・貯水量・濡れの13条件。入力に置いた基準に加えコードに列挙した感度。確率分布ではない。
- macro_water.csv：27条件。給水される有効深さと全床の水量を混同しない。
- load_share.csv：9条件。接触面積と支持荷重の区別。
- coating_cost.csv：6条件。機能相の材料分のみ。実価格や製造総費用ではない。
- results.json／checks.json：集計と25件の式・単位・保存則等の照合。
- sources.json：一次資料等6件、閲覧範囲と著者PDFのSHA256。文献全文・図を再配布していない。
- exploration-ledger.json：設計変更・反例・次の識別条件。
- PNGとSVG：同じ2図を別形式で保存。こちらで作図した仮定比較。
- environment.json：実行環境。
- publication-manifest.json：保存対象のバイト数とSHA256（自己参照を除く）。

Python、Matplotlib3.11.2を使用。図以外の計算は標準ライブラリ。リポジトリ直下 .deps があればそれを参照し、なければ現在の環境を使う。

~~~powershell
python -m pip install matplotlib==3.11.2
python "GPT往復/温湿度と荷重給水接点検証_20261009/calculate.py"
~~~

25件は固定入力の回帰照合を含む。入力を変えたら期待値・図のラベルも確認する。CSVの供給時間は理想化した水量÷流量であり、水膜が形成される時間や低摩擦になる時間の測定値ではない。液圧・接触角・孔形状・気液境界が未知のため、出力を発注寸法に用いない。

GitHub mainへ通常コミットし、固定コミットから読み戻したバイト数・SHA256と照合後、作業複製とGit履歴を削除する。rootの接続案内と利用設定を保護する。
