# 第87巡：高さ・接点・滑りの対応を識別する未実施仕様

設備・協力先は未確保。照会・発注・物理試験は未実施。これは既存の[第82巡の実証入口](../初回実証の設備照合と試験費用_20261009/protocol.md)と[第86巡の寸法仕様](../枝寸法と量産性の同時設計_20261009/size_test_protocol.md)への追加条件で、別の完成試験設備を要求するものではない。

## 最小の識別順序

1. **枝単独**：候補材・実成形条件の50℃荷重／変位／保持／除荷を測る。ここでE=200MPaを設定値として押し込まない。実測k、時間依存、回復、損傷、許容範囲を取得。第86巡の短太い枝は三次元応力を含めて確認する。
2. **根元固定の小試片**：同じ材・枝で高さ分布を変え、面積、接触位置、支持数、p(d)を同時計測。最高点だけの押し潰しを、平均沈み込みで見逃さない。h=10／50／200µmは製造保証ではなく、比較条件。実現した分布を測り、U(0,h)に強制しない。
3. **間隙の比較**：乾燥支持面の高さ幅hを固定した比較で、対向する枝の水隙間gを20／50／100µmへ変える。固定治具の結果を自由粒へ移さない。支持外の一体突起案は、突起なしと対にして硬い迂回荷重経路と目詰まりを確認する。
4. **自由粒床**：乾燥→降雨相当→排水→再整地で、接触分布と滑り抵抗が戻るか確認。履歴試料と新しい対照試料を分け、試験順序の影響を記録。回収率、表面高さだけで復旧合格にしない。
5. **実スキー比較**：同一底面処理・速度・名目荷重を対応させた天然新雪圧雪との対比較。表面50℃の候補材について、動摩擦、発進、停止後再始動、エッジの切れと離れ、沈み込み、振動、摩耗粉を別々に測る。速度未到達域は空欄にする。

## 計測上の落とし穴

透明板越しの光学観測は接点の可視化には有効でも、実スキー底面と材質・粗さ・濡れ性が違う。その摩擦値を実スキーへ転用しない。透明板と実底面の荷重曲線を照合し、確認できる範囲に限って接点モデルを校正する。

感圧フィルムの厚さ・柔らかさが10〜50µm級の接触を変える場合は、観測器自体を模型に含める。面積を増やす測定器で「よく荷重が分散した」と判定しない。高さマップだけから力を算出した場合は推定値とし、実測力と区別する。

h=10µmの差を論じる装置には、それを識別できる校正・再現性が必要。装置の表示分解能だけで保証しない。CTを初手の必須調達にせず、光学高さ、枝荷重、可視接点で識別できる範囲を先に調べ、内部接続が曖昧な場合だけ追加する。

## 実施前に確定する事項

試料数・独立調製単位・効果量・再現性・測定誤差から計画を確定する。本巡は未実施の観測項目6件を[test_plan.json](test_plan.json)に保存するだけで、試片数や統計的検出力を獲得したとはしない。

雪の比較条件は「新雪」という名前だけでなく、密度・粒形・圧雪履歴・温度・含水・底面処理・速度域を記録。文献の硬い焼結雪やワックス付きの値を、無処理候補材の達成値に置換しない。

## 分岐の決め方

| 観測 | 次の改良 |
|---|---|
| p(d)は合うが接点数が少ない | 枝を一律に柔らかくする前に高さ分布と配向を修正 |
| 柔らかくすると濡れ閉鎖 | hとgを分離する形状へ。突起が効かなければ薄片重なり自体を外す |
| スペーサーで硬い接地・引っ掛かり | 連続した硬い支持を撤回し、揺動・分散支持または粒形を比較 |
| 法線挙動は良いが滑りが重い | 接触材・表面の低せん断機構を別検証。法線パラメータ調整でμを作らない |
| 再整地後に水橋・粉・泥で戻らない | 粒回収と機能再生を分け、洗浄・分級・交換量を含む運用へ再設計 |
| 同じ部材を深く掘っても成立条件が交わらない | 噴霧結晶化・結晶複合・可逆接続の別系列へ結果を返す |

冬の雪界面での排水・せん断固着、450mm機能深度、300mm掘削、R39保持、約60分復旧は別の実証要件として残す。
