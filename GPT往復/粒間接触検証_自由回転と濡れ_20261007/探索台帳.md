# 第13巡 探索台帳

| 枝 | 結果・判断 | 次の切り口 |
|---|---|---|
| R4を平面上で整列 | 粒同士の初回接触は接点位置と法線で力学条件が変わる | 完全整列の維持へ設備費を集中せず、配向に鈍感な形も比較 |
| C3の三方向開口 | 幅の方向差と材料量を下げる形状候補、無固定中央粒の釣合い例 | 曲げ、連続挿入・解放、50℃、成形と摩耗の検証 |
| S3閉円対照 | 幅は揃いやすいが材料量が増え、開口経路を持たない | 支持形の比較対照として保持。人工フィルンの完成候補とはしない |
| 支点3個 | 3個でも力とモーメントが釣り合わない配置がある | 接点増減、摩擦、回転、変形、追加接点を含む粒群へ |
| 内面高摩擦 | 成立例の接点が外面。内面だけ高摩擦へ変えると指定配置は釣り合わない | 相手材での摩擦差を測るか、接点が内側へ移る経路を設計 |
| 濡れと重力 | 仮の液橋は滑走荷重に小さくても自重より大きい | 排水と接点組替えを分離。液橋・破断距離・時間の実測 |
| 安価な復旧 | C3の材料量仮定は有利だが加工・寿命は不明 | 線径増加で節約が消える境界と、60分/45cm/300mm損傷の工程費を比較 |

進捗：新しい形状候補と粒間接触・釣合いの計算を保存し、内面だけの加工で支持が得られるという仮説を修正した。物理試験0件、実物成功確率null。目標雪感、冬、雨、安全、80m/s、費用を保持する。
