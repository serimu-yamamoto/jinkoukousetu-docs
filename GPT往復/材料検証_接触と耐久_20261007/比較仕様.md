# 材料比較仕様（未実施・未発注）

2026-10-07。数値は合格物性ではなく、相違を切り分ける比較条件。材料購入・実験実施・外部照会は行っていない。実施前に必要な装置能力・安全・試料量を詰める。

## 試料群

| 群 | 候補 | 切り分けること |
|---|---|---|
| A0 | グレードを固定した成形用PE | 現行の密度960という仮定と実物を区別 |
| A1 | HMWPE | 分子量・製造履歴による変化 |
| A2 | HMWPE/UHMWPE 80/20重量比 | 無ナノ添加の混合、分散と高粘度の不利 |
| B0 | 摺動用充填剤なしのPOM基準 | 安定剤などの組成確認を伴う材料対照 |
| B1/B2 | POM/HDPE、HDPE6.3/31.3wt% | 海島構造・摩耗・摩擦・クリープ・密度 |
| C | A/Bのうち適合した骨格へ限定表面層 | 被覆前後・摩耗後・膜欠損後を別に記録 |
| S | 指定した新雪圧雪の実試料 | 板・エッジ・力の波形で最終目的との距離を見る |

HMWPEとUHMWPEは分子量・分布・安定剤・成形履歴まで記録する。既存論文の原料と違う場合は再現試料と呼ばない。室温、50℃、乾湿の物性を架空の一グレードへ合成しない。

## 段階を飛ばさない比較

1. 実スキーのUHMWPEソール片を相手にした平板試験。無ワックス・指定ワックスを分ける。停止・再始動、低速、5/10/20m/sを装置能力に応じて分け、法線荷重・名目面積・実接触・試料温度・界面近傍温度を記録。鋼相手の文献値を代入しない。
2. 同一粒形状でA/B群を比較し、製造ばらつき、残留変形、個々の保持・解放力、摩耗部位を観察する。G3一経路が塞がったことを保持力へ換算しない。
3. 同じ全深度を持つ床で、沈み込み・横支持・エッジ解放・力の急変・整地後回復を比較。板の下で粒が回転／流動した量も測り、低抵抗が単なる床の流出によるものかを区別する。
4. 冬の雪との接続・界面排水、傾斜・雨・台風後の回収と再使用へ進む。平板試験だけでコースへ採用しない。

各段階で粒形・密度・荷重・温湿度・速度・表面粗さ・前履歴を保存する。雪試料の密度や温度も固定した一値で代表させず、目標とする新雪圧雪の範囲を事前に定義する。試験の選抜データと最終90％超の独立確認データを分ける。

## 50℃と劣化

- 50℃の4〜5時間荷重、除荷後60分内の回復、繰返し荷重を別記。荷重を掛けたままの支持部と、保持後に除荷される可動部は別の応力履歴とする。
- 長期の冬季積雪荷重・保管時変形を、短時間試験から保証しない。
- 乾燥、濡れ、飽和、乾燥途中を区別。初期50℃と滑走発熱後の温度は同じではない。
- 紫外線、異物、凍結融解、摩耗後も保持寸法・摩擦・破片を追跡。年補充2％を許容流出量にしない。
- 人体・環境の適合は、最終配合、劣化物、排水、粒・微粉の曝露経路を対象にし、原料分類や食品接触の呼称だけで認定しない。

## 採否の分岐

- A2で摩耗だけ改善し摩擦・成形費が悪化したら、超高分子量比率の最大化をやめ、A0/A1との比較へ戻す。
- B1/B2で重さが増えても、同じ50℃の曲げ・強度・寿命を満たす骨格変更で取り戻せるなら再評価。ただし端部・肌触り・全深度を削らない。
- Cで薄膜の費用、剥離、摩耗後の性能が成立しなければ一体配合へ戻す。
- どの材料でも雪の横支持と解放を再現できなければ、形状の絡み合い・限定ゲル接点・従来鉱物対照の別枝へ戻る。摩擦係数一つで合格を決めない。
