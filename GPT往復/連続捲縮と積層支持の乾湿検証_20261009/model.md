# 計算定義：湾曲支持・濡れた積層・加工収支

[calculate.py](calculate.py)は標準Pythonのみ。23照合・192計算行。物理試験0件、成功確率null。1 GPa、密度1300kg/m³は仮定で、特定の50℃材料の値ではない。

## 1. 湾曲をほどく単一モード模型

第69巡と同じセル幅500µm、半支持点幅a=100µm、変位x₁=48.15µmとx₂=86.60254µm、比較圧力5/100kPaを使う。雪の実測合格帯ではない。左右の各半部材の輪郭長L、参照長sに対する接線角θ=A cos(2πs/L)を仮定する。初期振幅A₀はa=L J₀(A₀)を満たす。J₀/J₁はベッセル関数で、級数と別の幾何積分を照合した。

伸びない模型では、現在の端点距離l=√(a²+x²)=L J₀(A)。半部材の曲げエネルギーU_b=EIπ²(A−A₀)²/L、端点引張力T=2EIπ²(A₀−A)/(L²J₁(A))、中央の力F=2Tx/l。2点に合わせる逆算でL=134.28696µm、EI=2.64115×10⁻¹² N m²となる。

これは選んだ形状族のエネルギー模型で、完全なエラスティカ解やFEAではない。形状族を制限したエネルギーの比較から、力の安全側上限・下限は主張しない。

## 2. 軸伸びを加えると同じ部材の力が下がる

伸びεを一様とする追加近似で、l=(1+ε)L J₀(A)。半部材エネルギーを

U=EIπ²(A−A₀)²/L + EA L ε²/2

と置き、指定したlでAを数値最小化する。ε=l/[LJ₀(A)]−1。端点力T=EAε/J₀(A)、F=2Tx/l。最小化後の左右合計エネルギーの微分とFを独立差分で照合した。軸方向ひずみの分布、せん断、粘弾性、接合と粒回転は未解決。

幅400µm、E=1GPaと仮定した矩形部材なら厚さt=(12EI/Ew)^(1/3)=4.295µm。伸びを入れた低/高荷重点は4.952/74.546kPa。軸伸び約0.81%でも、ほぼ伸び切る域では支持力に大きく影響する。

表面ひずみの診断値はε+tπ|A−A₀|/L。これは参照長で書いた線形梁のひずみ尺度で、有限伸びによる断面・曲率変化を省いた近似。8.28%という値を許容ひずみとしない。破断伸びと繰返し可能なひずみは別。

## 3. 独立した薄層に分ける改良と代償

幅を保ってn枚の自由な層へ分け、各厚さをt/n^(1/3)にすれば総EIは同じ。総EAと材料量はn^(2/3)倍になる。n=8で厚さ2.148µm、支持90.37kPa、表面ひずみ尺度4.18%。n=64で1.074µm、97.18kPa、2.07%。どれも材料の合格ではない。

各層がすき間なしに全面せん断結合して一枚になった極限ではEI比はn²。8層で64倍、64層で4096倍。これは濡れたら必ずその倍率になるという予測ではなく、自由すべりを前提とする設計の対極。実際の接触面積・付着・層間せん断は未測定。

雨の診断では純水50℃の表面張力γ=0.2358τ^1.256(1−0.625τ)、τ=1−323.15/647.096（IAPWS）を使用。平行な完全ぬれの液橋なら圧力尺度p=2γ cosθ/g。g=5µm、θ=0なら27.18kPa。

平らな両端単純支持梁へ一様pを載せた小変形比較はδ=5pL⁴/(32Et³)。8層の各薄片でδ/g≈27.9。これを139µmの実変形予測として使わない。湾曲、軸張力、メニスカスの変化を解いておらず、小変形範囲も越える。液橋に対する開口保持を無視できないという検査項目へ使う。撥水加工や疎水性だけで接触角・乾燥後の付着を既知にしない。

## 4. 連続工程の物量

2000m²×0.45m、包絡体充填率0.5、セル体積500×500×577.35µm³よりN=3.11769×10¹²。帯材だけで1/8/64層は1.870/7.481/29.922t（仮密度1300kg/m³）。枠、接点、滑走座、排水・保持構造は含まない。第69巡と材料係数・機構が違うため、重量比を完成材の性能改善率にしない。

各層を別に500µm角の面付けで加工する場合、面積=N×500µm×500µm×n/η。η=0.8、100日×16hの計画では、1m幅ウェブ速度は1/8/64層で10.15/81.19/649.52m/min相当。複数ライン・幅拡大で分配できるが、必要な総加工量は残る。仮加工単価10円/m²なら974万円/7794万円/6.24億円。材料や設備等は別。

完成粒は約54.1万個/s相当、半部材別なら1層でも約108.3万個/s。これは個別に動く刃やロボットの毎秒動作数ではない。幅方向を同時処理する一体連続成形・周期的な分割なら、並列化できる。実加工・打抜き端・粉じん・歩留まりは未実証。

S1の110dtex糸を4200m/minで巻く条件は2.772kg/h/その糸系統。34本を含む糸の値で、再び34倍してはいけない。高い線速を、複雑な粒の出荷速度や一体成形の能力に転用しない。2億円は整地設備・限定土木の暫定枠で、この材料費・工場費とは分離。
