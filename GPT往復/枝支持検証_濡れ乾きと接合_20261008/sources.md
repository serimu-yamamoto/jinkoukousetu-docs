## 原理を移す判断

| 検討 | 計算／出典から変わった次の行動 |
|---|---|
| 枝が存在すれば雪状粒になる | 粒内の支点間隔、支点剛性、粒間解放を別に定義する |
| 長い自由枝をそのまま使用 | 粒内複数接合と、短枝を最初に生成する工程を比較する |
| 濡れても乾けば形状回復 | 乾燥途中と乾燥後の束残りを追い、整地で戻るか区別する |
| 全面増径・被覆 | 自由長を短くする構造を比較。ただし接合費と保水の増加を含める |
| 接着した点を固定支点扱い | 回転ばねと並進ばねを追加。自由粒の骨格全体の変形も未解決として残す |
| 代表融点から50℃性能判定 | 同一銘柄の時間依存剛性と接合部変位が次の必要入力 |
| 含水率の数字だけで雨後復旧 | 飽和度・水重量・粒の形とソール抵抗を別々に記録する |
| 加工価格と再生価格に残予算を使う | 同じ残枠の二重使用を禁止し、代替計算として表示する |

固定マット・シート・メッシュへの代替は採用しない。新規性・特許性、人体安全・環境適合、全層保持、50℃雪感、90％超の実物成功率は本巡で証明していない。企業への連絡・発注・試料作製・物理試験は未実施。
