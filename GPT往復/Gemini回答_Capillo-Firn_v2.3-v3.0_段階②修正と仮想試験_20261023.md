## 第3部：視野を広げた科学的収束解——「Capillo-Firn v3.0（常温毛管自己脱水焼結・剛性多孔質コア設計）」

なぜ現行v2.2は破綻したのか？それは**「Capillo-Firn（毛管万年雪）」という名称でありながら、水を52gも入れてコアを過飽和（毛管サクション $\psi_m = 0\text{ kPa}$）にし、粒子を柔らかい練り物にしてしまったから**である。

気温35℃（表面50℃）・湿度100%・無冷却（R05）の環境下で、**①触るとサラサラで非粘着（新雪バーン再現）**、**②圧雪機で10秒踏んで30分置くと外部乾燥なしで $c=42\text{ kPa}, \delta_f \le 10\ \mu\text{m}$ の脆性ネックが形成される（圧雪バーン再現）**、**③スキー滑走時のみ摩擦係数 $\mu_k \approx 0.045$ の極薄水膜が出る**という3要件を同時に満たす唯一の物理化学的メカニズムは、以下の**「不飽和剛性ナノ多孔質コアによる内部毛管吸引・自己脱水焼結（Internal Capillary Self-Desiccation Sintering）」**である。

### 1. 収束メカニズムの物理・化学原理（なぜ35℃・無乾燥で30分再結合とサラサラ感が両立するのか）

1. **原理①：不飽和剛性ナノ多孔質コア（毛管サクション・ポンプ $\psi_m \approx 65 \sim 75\text{ kPa}$ の常時維持）**
   - 粒子全体の水分量を $52\text{g} \to \mathbf{32.0\text{g}}$（固形分 $68.0\text{g}$、含水比 $W/S = 47.1\%$）へ引き下げ、かつコアを**常温硬化型カルシウムシリケート／アルギン酸-クエン酸遅延架橋・セルロース複合骨格**で剛性化（単粒降伏応力 $\sigma_{y,p} = \mathbf{420\text{ kPa}}$）する。
   - コア内部の剛性ナノ細孔（細孔径 $0.5 \sim 2\ \mu\text{m}$）が潰れないため、粒内水飽和度は常時 **$S_e = 65 \sim 72\%$（不飽和状態）** に保たれる。
   - van Genuchtenの毛管圧力式 $\psi_m = \alpha_{\text{vg}}^{-1}(S_e^{-1/m} - 1)^{1/n}$ により、この不飽和コアは常時 **$\psi_m = \mathbf{61 \sim 73\text{ kPa}}$ の負圧（内部への毛管吸引力）** を発生する。
2. **原理②：無負荷時（$\sigma = 0\text{ kPa}$）＝「新雪バーン（パウダーモード）」の成立**
   - 外部荷重がゼロのとき、コアの毛管吸引力（$\psi_m \approx 70\text{ kPa}$）が外皮表面の自由水をすべて粒子内部へ吸い込むため、粒子表面は気温35℃でも**マクロに完全ドライ（「サラサラ」で手やスキー板に一切くっつかない）**となる。
   - 圧雪せずにロータリーティラー（撹拌機）でほぐした状態では、粒径 $d_{50} = 0.8\text{ mm}$ の星形・樹枝状微細粒どうしは結合せず（$c = 1.5 \sim 2.5\text{ kPa}$, $\rho_b \approx 380\text{ kg/m}^3$）、スキー板が適度に沈み込んで雪煙（ドライスプレー）が舞う**新雪パウダーバーン**が再現される。
3. **原理③：10秒圧雪（$\sigma_{\text{bed}} = 50\text{ kPa}$）$\to$ 30分無負荷静置＝「圧雪バーン（ハードパックモード）」の成立**
   - 圧雪機が床全体を $\sigma_{\text{bed}} = 50\text{ kPa}$ で10秒間圧縮した際、粒子どうしの点接触部（実接触面積率 $a_c \approx 8\%$）には **局所ヘルツ接触応力 $\sigma_{\text{local}} = 50 / 0.08 = \mathbf{625\text{ kPa}} \gg \psi_m\ (70\text{ kPa})$** が作用する。
   - この10秒間だけ、局所接触応力がコアの毛管吸引力を打ち破り、接触点（ネック部）へ細孔内の架橋イオン水溶液（$\text{Ca}^{2+}$／オリゴ糖・シリケート成分）をサブミクロン厚で滲出（ピエゾ滲出）させる。
   - **圧雪機が通過して無負荷（$\sigma_{\text{bed}} = 0\text{ kPa}$）に戻った瞬間**、今度は不飽和コアの毛管吸引力（$\psi_m \approx 70\text{ kPa}$）が逆向きに働き、**接触ネック部に滲出した水分を粒子内部へと猛烈に吸い戻す（内部自己脱水）**！
   - Lucas-Washburn / Darcy毛管吸引モデルによるネック脱水時定数は **$\tau_{\text{cap}} \approx 11.5 \sim 20\text{分}$** であり、**外部の空気湿度が100%RHであっても（外部蒸発ゼロでも）、接触ネック部だけが局所的に脱水・濃縮されて固体結晶・水素結合ブリッジが完結**する。
   - その結果、無負荷静置30分後には **$c(30\text{ min}) = 41.4 \sim 42.5\text{ kPa}$、$S_f(50) = 77.8 \sim 78.3\text{ kPa}$、臨界破断変位 $\delta_f \le 10\ \mu\text{m}$** の脆性固体ネックが形成され、エッジが鋭く噛んで脆性破断する**圧雪バーン**が再現される。
4. **原理④：スキー滑走時のピエゾ境界潤滑（$\mu_k = 0.047$）**
   - スキー板（UHMWPE、公称面圧 $P_{\text{nom}} \approx 5\text{ kPa}$）が滑走する際、剛性粒子（$\sigma_{y,p} = 420\text{ kPa}$）との真実接触アスペリティ（面積率 $\alpha_r \approx 0.40\%$）には **局所面圧 $P_{\text{asperity}} \approx 1,250\text{ kPa} \gg \psi_m\ (70\text{ kPa})$** が作用する。
   - これにより、**スキー板が通過する約 $0.1\text{秒}$ 間、接触アスペリティ直下にのみ厚さ約 $130\text{ nm}$ の純水境界潤滑膜がピエゾ滲出**し、掘り起こし抵抗ゼロ・動摩擦係数 **$\mu_k = \mathbf{0.047}$**（天然圧雪 $-2^\circ\text{C}$ と同等）を実現する。スキー通過後は直ちにコアへ再吸収されるため、ゲレンデがびしょ濡れになることはない。

### 2. R05（無冷却）・マイクロプラ規制・防黴・凍結融解を解決する v3.0 化学配合（100g基準）

ClaudeおよびGPTが指摘した化学的欠陥をすべて解消するため、段階②では現行v2.2（水52gおよび水分低減系列42g/35g/28g）に加え、以下の**v3.0収束配合（常温遅延イオン架橋・不飽和毛管コア系）**を並行比較試験する。

1. **ジェランガム不溶化＆R05（15℃冷風禁止）の解決**:
   - 加熱・冷却が必要な低アシルジェランガムを廃止し、**常温（$25 \sim 35^\circ\text{C}$）で完全水和・遅延ゲル化する「アルギン酸ナトリウム（またはLMペクチン）＋クエン酸ナトリウム（$\text{Ca}^{2+}$ キレート遅延剤）＋硫酸カルシウム二水和物／メタケイ酸アルミン酸マグネシウム」系**へ置換する。熱エネルギー・冷却エネルギーともにゼロで、一度架橋した後は **$100^\circ\text{C}$ でも融解しない完全耐熱脆性ゲル**となる。
2. **EU REACHマイクロプラスチック規制（Claude指摘）の完全回避**:
   - 化学修飾ポリマーである **CMC-Ca（カルボキシメチルセルロースカルシウム）** はEU REACH規則（Annex XVII Entry 78）において「化学修飾された天然ポリマー」として規制対象となるリスクがある。
   - v3.0ではCMC-Caを廃止し、**100%未修飾の天然多糖・天然鉱物のみ（天然CNF、天然MCC、天然アルギン酸／天然ペクチン、カルサイト、カオリナイト、非晶質含水シリカ／ケイ酸塩）**で構成することで、REACHマイクロプラスチック規制の適用除外（天然未修飾ポリマー＆無機鉱物）を法的に確実化する。
3. **防黴・静菌および冬季凍結融解耐性（Claude指摘）の組み込み**:
   - **防黴設計**: 弱アルカリ緩衝（$\text{pH } 8.5 \sim 9.2$：炭酸カルシウム＋極微量の水酸化カルシウム／ケイ酸カルシウム緩衝系）および食品添加物グレードの**酸化亜鉛／銀担持リン酸ジルコニウム微粒子（$0.15\text{ wt\%}$）**により、環境無害かつ非溶出で35〜50℃でのカビ・細菌繁殖を阻止する。
   - **凍結融解耐性**: コアの粒内水飽和度が $S_e = 68\%$（粒内気相率 $32\%$ の連通ナノ気孔）であるため、冬季に水が凍結して体積が $+9\%$ 膨張しても、**粒内の32%の不飽和気孔が氷晶膨張体積を完全に吸収（エアエントレインメント効果）**し、粒子の凍結破砕（スポーリング）と解凍後の離水を防ぐ。

## 第4部：監査指摘を全反映した「段階②（ラボ小試料試作）最終実験プロトコル」

段階②は本研究で**最初の物理実験（現在実測0件）**であり、100gは配合比率の基準単位とする。破壊試験・反復試験・含水率測定に必要な**独立試料総量として各水準 $2.0\text{ kg}$（計4水準：v2.2水52g、v2.2b水42g、v2.2b水35g、v3.0常温毛管系水32g $\implies$ 合計 $8.0\text{ kg}$）**を調製し、以下の順序でゲート試験を実行する。

### Gate 2-0：バインダー常温・加熱水和性およびゲル化事前スクリーニング（Claude指摘3・R05対応）
* **手順**: 鉱物・セルロース投入前に、①現行v2.2の低アシルジェランガムCa塩＋CMC-Ca＋カルサイト共存液（$25^\circ\text{C}$ 無加熱、および $85^\circ\text{C}$ 加熱 $\to 25^\circ\text{C}$ 自然放冷）と、②v3.0のアルギン酸Na＋LMペクチン＋クエン酸Na遅延架橋系（$25^\circ\text{C}$ 常温撹拌のみ）の溶解度・不溶残渣率・ゲル化後の貯蔵弾性率 $G'$ を測定する。
* **合否判定**: カルシウム阻害によりジェランガムが溶解しない（またはR05違反の15℃冷却なしでは固化しない）場合、その時点でジェランガム系を棄却し、常温遅延イオン架橋系（v3.0）へ一本化する。

### Gate 2-A：ドウのレオロジー・JGS 0142フォールコーン測定
* **手順**: $30^\circ\text{C}$ および $50^\circ\text{C}$ にて、JGS 0142フォールコーン貫入深さ $d\ (\text{mm})$、およびレオメータによる周波数依存性（$\omega = 0.1 \sim 100\text{ rad/s}$）・ひずみ依存性（$\gamma = 0.01 \sim 100\%$）の $G', G'', \tan\delta, \tau_y$ を履歴とともに記録する（$\tan\delta > 0.3$ での機械的自動棄却は行わず、Gate 2-Bの形状保持結果と照合する）。

### Gate 2-B：単粒・粒床の形状保持・空隙・透水・触感試験（粒径 $0.8\text{ mm}$ および工程確認用 $3.0\text{ mm}$）
* **手順（$30^\circ\text{C}$ および $50^\circ\text{C}$、試験前後の質量 $m$・$105^\circ\text{C}$ 絶乾含水率 $w$・ろ紙離水量 $m_{\text{bleed}}$ 必測）**:
  1. シリコーンオイル液浸法／ヘリウムピクノメータ法による粒子密度 $\rho_p$、粒内気体率、粒内体積含水率、総粒内空隙率の実測、および顕微鏡による外皮被覆率（切断面露出の有無）の確認。
  2. 円筒セルでの初期かさ密度 $\rho_{b0}$・粒子間空隙率 $n_0$ 測定後、① $50\text{ kPa}$・10秒載荷 $\to$ 除荷、② $50\text{ kPa}$・30分継続載荷、③ $250\text{ kPa}$（スキーエッジ相当）・3秒載荷 $\to$ 除荷を実施し、**かさ密度増加率 $\frac{\varepsilon_v}{1-\varepsilon_v}$** と **粒子間空隙体積減少率 $\frac{\varepsilon_v}{n_0}$** を区別して算出。
  3. 除荷後の粒の独立性（手でほぐして新雪パウダー状態 $c < 3\text{ kPa}$ に戻るか）、変水位・定水位透水係数 $k$（基準 $k \ge 0.0025\text{ m/s}$）、および表面の「サラサラ感（自由水滲出ゼロ）」を判定。

### Gate 2-C：外皮二片接合による界面再結合・局所破断変位 $\delta_f$ 試験
* **手順**: 外皮組成の平滑ブロック二片（$20\text{ mm} \times 20\text{ mm}$）およびコア・シェル複合平板二片を用い、**条件C-1（$50\text{ kPa}$・10秒圧着後に除荷して無負荷静置）**と**条件C-2（$50\text{ kPa}$ 継続載荷）**の2条件、温度 $30^\circ\text{C} / 50^\circ\text{C}$ にて、未破断対照・0・5・15・30・60分後の引張剥離強度・純せん断剥離強度を測定。
* **局所変位実測**: DIC（デジタル画像相関法）カメラにより接合界面近傍の真の局所すべり変位 $\delta_f\ (\mu\text{m})$ と面積あたり破壊エネルギー $G_f\ (\text{J/m}^2)$ を直接測定する（試験前後のブロック質量・含水率変化を必ず記録）。

### Gate 2-D：粒床の一面せん断回復試験
* **手順**: 小型一面せん断試験機（$30^\circ\text{C} / 50^\circ\text{C}$、前後含水率必測）にて、未破断対照（$\sigma = 25, 50, 75\text{ kPa}$）および破断後の回復試験を実施。
* **条件D-1の厳密固定**: せん断破断後、$50\text{ kPa}$ で10秒間再圧縮して直ちに除荷（$0\text{ kPa}$）し、0・5・15・30・60分間無負荷静置する。その後、**再載荷速度 $1.0\text{ mm/min}$ で鉛直応力 $50\text{ kPa}$ まで載荷し、保持時間 $10.0\text{秒}$ 経過後にせん断速度 $0.5\text{ mm/min}$** でピークせん断強度 $S_f(50)$ と残留強度 $S_r$ を測定する（条件D-2の $50\text{ kPa}$ 継続載荷と分離比較）。

### Gate 2-E：段階②に追加する5つの低コスト必須試験（Claude追加指示対応）
1. **UHMWPE動摩擦・凝着試験**: スキーソール材（UHMWPE）スライダーを用い、公称面圧 $5\text{ kPa}$（滑走相当）および $150\text{ kPa}$（ターンエッジ相当）、温度 $30^\circ\text{C} / 35^\circ\text{C} / 50^\circ\text{C}$ にて静摩擦係数 $\mu_s$・動摩擦係数 $\mu_k$（目標 $0.035 \sim 0.050$）およびソール面への凝着転写量を測定する。
2. **底面シート・ドレーンマット界面せん断試験**: 粒床と下部ドレーンマット／ジオセル／遮水シートとの実界面について、浸水状態（$h_w = 222\text{ mm}$ 相当水圧）での界面摩擦角 $\delta_{\text{if}}$・見かけ粘着力 $c_{\text{if}}$ を一面せん断試験で実測する。
3. **14日間カビ・生物劣化加速試験**: $30^\circ\text{C}$ および $50^\circ\text{C}$・相対湿度 $95\%$ の恒温恒湿槽に湿潤試料を14日間静置し、質量減少率、コロニー（菌糸）発生有無、pH変化、および14日後の $S_f(50)$ 保持率を測定する。
4. **冬季凍結融解10サイクル試験**: $-15^\circ\text{C}$（12時間）$\leftrightarrow +10^\circ\text{C}$（12時間）の凍結融解を10サイクル繰り返し、粒度分布の変化（細粒化率）、離水量、および単粒降伏応力 $\sigma_{y,p}$ の保持率を測定する。
5. **EU REACHマイクロプラスチック規制適合性リーガルチェック**: 化学修飾セルロース（CMC-Ca）のREACH Annex XVII Entry 78該当性を法令原文およびECHAガイドラインに照らして判定し、該当する場合はv3.0の天然未修飾多糖（アルギン酸／ペクチン＋天然CNF/MCC）へ完全移行する。
