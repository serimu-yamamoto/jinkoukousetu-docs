## 接触の定義

面積受渡しではL=1、幅を剛性密度へ吸収。上面の窓[u,u+1+γ]が、A=[0,1]、B=[1+γ,2+γ]に重なる部分だけを支持域とする。法線荷重位置xc=u+(1+γ)/2、r=x−xc。圧力はp=k_a max(δ+θr,0)。これは独立ばねのWinkler近似で、実材の同定値ではない。

回転自由では∫p dx=F、∫rp dx=0を満たす。q=θ/δを導入し、M(q)=∫r max(1+qr,0)dr=0を単調な二分法で解く。負圧領域は除外する。回転固定ではθ=0、必要な外部モーメントを報告する。下側粒の全体運動は拘束している。

全接触時の独立な2×2解法：
A=∫1、M1=∫r、M2=∫r²、
δ=F M2/[k_a b(A M2−M1²)]、
θ=−F M1/[k_a b(A M2−M1²)]。
γ≤1/3の端ではδ/δ0=1+3γ²。γ>1/3では三角圧力の部分接触になり、端の有効接触長/L=3(1−γ)/2、δ/δ0=8/[9(1−γ)]。

自由回転・一定法線荷重の保存的な最小ポテンシャルはΠ=−Fδ/2。Q=dΠ/du=−F δ'/2。これは摩擦力ではない。γ≤1/3なら端のQ/F=6γ²(1+3γ+3γ²)δ0/Lを独立照合する。

δ0/Lをεとすると実角度は、結果のthetaにεを掛けた小回転近似。例えばγ=.75で最大係数14.222。ε=.02なら約.284radとなり、小回転近似を安易に実形状へ使えない。有限回転による窓の投影変化、変形体の横膨張・せん断連成は含まない。

## 曲面案

cam_state()の垂直ばね接点は、指定された2高さhA/hBと圧縮だけの接触を使い、a=max(hA−y,0)、b=max(hB−y,0)、a+b=ηを解く。横の可逆仕事Q=a hA'+b hB'をポテンシャルの数値微分へ照合した。回転拘束・剛性固定という限定で、自由粒のモーメント釣合いを証明しない。

## 数値検証と記録

- 主計算：8曲面条件×201点、10面積条件×201点。9,747チェックの多くは同じ釣合いを各点で調べる検査。
- 独立解法：全接触の2×2解析解15配置、部分接触端の三角分布、独立中点積分100／400／1600分割。
- 境界：B接触開始をu=10⁻²,10⁻⁴,10⁻⁶,10⁻⁸で調べ、端解から予測する入口圧力を照合。主結果のpeak_pressureは201点での標本最大で、厳密な最大値ではない。
- initial_check_diagnostic.json、second_check_diagnostic.json、validation_revision.json：積分検査の修正履歴。物理模型の調整による合格化ではない。
- inputs.json、results.json、validation.json、boundary_limits.json：全入力・結果。
- manifest.json：公開対象のSHA256とバイト数（自身を除く）。

入口の有限圧力・微小面積を示す模型は、実際の角部応力特異性や衝撃を解像しない。接触開始の丸め・粘弾性・摩擦を追加しない限り摩耗や滑走感を評価できない。隙間率を排水能力と呼ばない。
