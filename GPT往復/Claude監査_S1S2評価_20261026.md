# Claude監査（短報）：Gemini「S1脂質・S2 PCL 水質・生分解・噴霧検証」（2026-10-26）
Geminiの全文（Canvas）は未入手で、依頼者が貼った要約だけで判定した。ThOD（ステアリン酸2.924、PCL 2.103 g-O2/g）と、BOD5の換算（1,846〜3,076mg/L）は一致する。
1. **S2（PCL）の融解膜による潤滑は不可、に同意**：溶融粘度が10²〜10⁴Pa·sあり、貼り付く。S2は、スリップ剤を加えた固体潤滑に変える必要があり、優位性が下がる。**主案はS1（脂質の霧雪）に一本化する**。
2. **流出量の前提が根拠なし**：「年60%が摩耗し、80%を回収、10%が水路へ」は旧Capillo-Firnの仮定であり、脂質の雪の値ではない。S1は、回収した粉と浮いた脂を**溶かし直して、そのまま再び噴く**ことができる（再造粒の工程が要らない）。摩耗率は、硬さからArchard式で感度計算し直すこと。流出は、閉じた排水系と浮上分離（S1の比重は0.94で、水に浮く）で設計値として決めること。基準は、一般排水基準の動植物油脂類30mg/LとSS、BODを使う。
3. **難燃フィラー42〜50%と密度の矛盾**：フィラーを45%（密度2.5）入れると、粒の密度は1.31g/cm³になり、充填率0.58で床密度は758kg/m³と、帯を超える。粒の中に約30%の気泡（独立気泡）がないと、400〜550に入らない。燃えにくさ、密度、硬さを同時に満たす配合を示すこと。
4. **50℃で焼結しすぎる危険**：融点の選び方（ステアリン酸69℃、ベヘニルアルコール71℃）、白さ（反射率）、無機スペーサーの組合せで、30〜50℃の焼結速度の幅を設計すること。数値は未測定。
