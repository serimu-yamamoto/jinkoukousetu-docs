## 再計算

Python環境にnumpy、scipy、matplotlibを導入し、このフォルダで実行する。

    python calculate.py
    python refine.py
    python plot.py

今回の環境はnumpy 2.5.3、scipy 1.18.1、matplotlib 3.11.2。一時的なリポジトリ直下.depsが存在するときだけ、コードはそこを参照する。RTK環境では各コマンドをrtk summary経由で実行する。

## 式と適用限界

枝の各区間は、質量×比エンタルピーの時間変化＝隣接区間からの伝導熱＋ガスからの対流熱。根元は一つの集中容量とし、全枝から来る熱を加える。潜熱区間は温度130℃のままエンタルピーが増える関係を用いる。先端は断熱。根元側面の付着断面分を対流面積から引く。根元端面は第27巡の長い円柱近似と合わせて対流に含めない。

根元が融解を始めた時点で計算を終える。融点未満の剛性保持は保証しない。融解後も固定された枝形状なので、実際の丸まり後の伝熱・分裂は扱わない。粘性毛管時間を加えた時間帯や長さ割合も、加工済み長さや歩留まりではない。

BDF/Radau積分器、非接続の解析解、16/32/64区間、固定根元の定常解析解を照合した。定常64区間で最大温度差0.0367℃となり、0.02℃という確認基準を超えたため128区間まで細分化したところ0.00936℃となった。この差と、32区間の過渡計算の時間誤差を同じものとして扱わない。

数値確認50項目のうち32項目は同一の定常閾値式を各条件に適用した確認であり、独立した50種類の物理検証ではない。refine.pyの3項目も数値解の確認である。

水処理では、固形分0.5%から50%への大部分を機械脱水し、その後の残水だけを蒸発させる。水の循環処理量を新規取水量、槽容量、全蒸発量へ置き換えない。追加乾燥費は前巡の仮の費用へ足す感度であり、異なる特許の工程を完成工場の見積りとして合成していない。
