# 50℃対応の雪状結晶素材と圧雪再現の再設計

作成日：2026年10月5日 JST　作成：Codex　宛先：Claude／依頼者

本書は、Claudeの正本v36、VT第1〜8弾とその計算コードを検証し、気温30℃以上・表面約50℃で新雪を圧雪した滑り心地を再現し、冬も天然雪の下地として使うための研究報告である。監査基点は資料倉庫のコミット `06c70ed`、調査中に追加されたVT5・VT6は `b8458e2`、VT7は `0bdff45`、VT8は `71b8210` までを対象とした。この1ファイルに結論、設計、計算、出典、Claudeへの依頼をまとめた。正本v36の差し替えではなく、次の正本を作るための独立検証である。

**研究の主軸を、重い鉱物粒の被覆だけに限定せず、「融解させずに使う結晶骨格・曲がる短枝・組み直せる粒間接点・薄い潤滑表面」を分けて設計する人工粒へ広げる。** 第一の研究案は結晶化PVAと再生セルロースを用いる多孔粒、独立した比較案は半結晶性樹脂の多孔粒である。HBG-5と追加案HBG-6は比較対照として残す。雪に似せる対象は六角形の外観だけでなく、粒の結合が荷重に応じて外れ、粒が移動し、再び締まる構造である。

今回得られた具体的な成果は次のとおり。

- 従来資料で候補を狭めていた引用と推論を訂正した。特に疎水性PEとの潤滑、弾性率から雪の硬さへの換算、2次元ばね模型からの混合率制限、含水3％からの質感推定を分離した。
- 元のVT3を実行して再現し、蒸発の未測定仮定だけで最高温度が31.6→38.4→44.2℃と変わることを独立コードで示した。刻み幅を半分にした差は約0.004℃だった。数値収束と物理的な正しさを区別できた。
- 材料・粒形・接点・表面を独立に変更する設計案と、50℃で先に確認する条件を具体化した。結晶化PVAについては高温水中の形状保持を扱う一次研究も確認した。
- 軽量化による材料単価の許容幅、冬の蓄熱低減、80m/sの保持負担を同じ計算条件で比較した。優位性と代償を数値で追えるようにした。
- VT6の石灰水案では、結合強度式の余分な係数と引張強さ→cの置換を特定した。析出量0.1％を作る石灰水は、完全利用を仮定しても表層5mmの空隙容量の約2.03倍になる。炭酸化を接点形成へ生かす条件を、水・CO₂・残留アルカリの収支として具体化した。
- 追加依頼の豪雨・台風後の復旧について、回収・山側への運搬・再配合・接点回復を分けた。仮定した2,000m²の床の10％が移動すると、運搬だけでも約4.56時間となる例を計算し、「簡単なメンテナンス」に収める移動量・運搬能力の設計条件を得た（第8.3節）。

**達成区分：文献確認・コード監査・条件付き計算・新しい設計仮説まで。新素材の製造、実滑走、人体安全、冬の追加融雪の実証は今回実施していない。以下の配合や寸法は試作探索の提案値であり、達成した物性ではない。**

## 1 目的と判定対象

引き継ぐ条件は、屋外・現地非冷凍、約30°斜面、日中9〜17時、常時べしゃべしゃにしないこと、全作動深さで同じ受入性能、局所300mmの削れへの対応、冬の季節撤去を要しないこと、自然地面に比べて追加融雪を生じさせないこと、人体・用具・環境への適合、維持更新込みの採算である。ネット、シート、敷設ブラシ、ジオセル、剛性パッド、油・塩類・フッ素・シリコーンによる潤滑を採用しない。

**依頼者の追加指定（本調査中、2026年10月5日）：冬は素材の表面を天然雪が覆う。素材と雪の間に水や油分が溜まり、雪が滑落する状態を作らず、両者がしっかり固着接続することを重視する。** 冬の判定を、露出した人工粒の滑りやすさではなく、雪と下地の接続、界面排水、融解・再凍結後の保持に置く。追加融雪についての既存条件を、この指定によって無断で緩めない。

さらに、**雨・台風で山麓へ移動した材料をピステンで山側へ戻し、均して再び使用できるか**を検証対象に追加した。目的は見かけの平坦化にとどまらず、排水、配合、接点、滑り心地の回復である。成果はGitHubに保管してClaudeと共有する。依頼者の明示指定により、保存照合後にローカル研究ファイルとGit履歴を削除し、接続先の案内だけを残す運用とする。

今回のユーザー指定により、**表面を散水で約30℃に下げたときだけ滑る材料を、50℃対応の代わりにしない。** 50℃の材料温度で、摩擦・エッジ支持・クリープ・水移り・摩耗を組み合わせて確認する。55〜60℃は余裕と異常時の探索条件として提案するが、現段階で保証温度とはしない。滑走中の微小接点は平均表面温度より高温になり得る。

「雪のような結晶構造」は次の三段階に分ける。

| 段階 | 何を再現するか | 確認方法 |
|---|---|---|
| 分子・結晶領域 | 規則的な配列による骨格の安定性 | X線回折、DSC、湿潤時の構造変化 |
| 一つの粒 | 短枝、孔、丸み、曲げ変形、壊れにくさ | 顕微鏡・CT、単粒荷重、摩耗後形状 |
| 粒の集合体 | 接点の形成・解放・再配列、空隙、局所せん断 | 貫入曲線、エッジ横反力、除荷、振動、整地回復 |

六方向に成形しても分子が氷の結晶になるわけではない。半結晶性ポリマーが高温で固体を保っても、圧雪の滑り心地は別途作る必要がある。大気圧の氷そのものを50℃で維持する方式には依存せず、氷の機能を担う固体骨格を作る。

目標の雪は「新雪を圧雪したバーン」とし、春の湿雪、夏の氷河、硬い競技バーンを混ぜた広い物性範囲のどこかに入るだけでは合格にしない。基準雪について気温・雪温・密度・粒形・整備履歴を記録し、同じ用具・荷重・速度で比較する。

## 2 Claudeの結果に対する検証

### 2.1 引用を訂正すると再開できる研究方向

正本v36第11章は arXiv:2404.05234 を「疎水面ではハイドロゲル潤滑が効かない報告」として挙げていた。しかし、その論文の導入で疎水面に効かなかったのは従来の脂質添加系である。論文自体はPMPC-co-PNIPAM共重合体を導入し、**PEを含む相手面で摩擦を低下させた**研究である。したがって「PE相手だから水和潤滑の枝全体を閉じる」は撤回する。[Linらの本文](https://arxiv.org/pdf/2404.05234)

これは未改質PVAや本粒床の有効性を証明しない。同論文の含水・温度・荷重・運動条件から、乾燥空気中50℃、実UHMWPE、2〜20m/s、土砂混入へは外挿できない。PMNの組成に含まれる温度応答性部分も50℃で再評価する。今回の候補は、固定化した親水性高分子の薄い表面層という設計方向であり、論文の配合をそのまま採用するものではない。

Linら2019はPVAの結晶領域を制御して疲労亀裂への抵抗を変え、局所的な結晶化と全体の柔らかさを分ける設計を示した。Huaら2021も凍結成形と塩析で階層構造を持つ強いPVAゲルを報告している。**従来の凍結融解ゲルの弾性率だけで、結晶化PVA全体を候補外にはできない。** ただし引張強さを圧縮弾性率に置換せず、塩析系は洗浄後の残留塩と物性保持が独立課題となる。[Linら2019](https://arxiv.org/pdf/1812.06403)、[Huaら2021](https://www.nature.com/articles/s41586-021-03212-z)

Karyappaら2024には、物理架橋したPVA構造の高温水中試験がある。本文の温度説明と補足Fig. S13の境界表現に差があるため、60〜70℃の一律保証には用いない。両者から取り出せる限定的な示唆は、**50℃付近の形状維持を目指すPVA構造を、一般論で除外しなくてよい**という点である。2時間の形状保持は、長期クリープや摩擦性能の証明ではない。補足Fig. S9にはNaイオン除去後に崩れる別の配合もあり、「洗えばどの配合でも強さが残る」とは扱わない。[論文情報](https://pubmed.ncbi.nlm.nih.gov/38506347/)、[一次補足資料](https://www.rsc.org/suppdata/d3/mh/d3mh01714a/d3mh01714a1.pdf)

### 2.2 計算の意味を訂正する

| 対象 | 検証結果 | 研究への反映 |
|---|---|---|
| 「HBG-5だけが成立する」 | 比較した限られた案と仮定の中の結果。材料空間全体の証明ではない | 高結晶・多孔・短枝型を再開する |
| 雪の硬さHVと弾性率E | Eは小変形剛性、HVは押しのけた体積に対する反力。単一Eから一意に換算できない | 粒再配列・接点解放を含む荷重変位曲線へ戻す |
| VT1報告のHV 0.5〜3.6 | `vt1.py`にはHV換算部分がなく、この数値の生成過程は同梱コードで再現できない | 導出、角度、境界条件、別コードの提示をClaudeに求める |
| Sfからc＝10〜100kPa | 受働土圧との対応づけは未校正。Sfは特定器具のせん断開始指標で、Mohr–Coulombのcと同じではない | 仮の探索範囲に戻し、設計確定値にしない |
| 混合率20％以下 | `vt2a.py`は固定した三角格子の線形ばね模型。接触の生成消滅、粒回転、滑り、破断を解いていない | 本物の3次元粒床の普遍的な上限とはしない |
| μ≦0.10なら滑り心地十分 | VT2は主に30°直滑降の加速度差を評価。ターン、低速、平坦部、左右差、グラブの同等性は導けない | 数値は参考。雪対照との全抵抗・横反力・変動で判定 |
| 掘り起こしμは無視できる | VT2の小さい弾性沈み込みから計算した特定状態。エッジで局所破壊する状態を含まない | 降伏後の排土・粒移動を別モデル化 |
| 含水3％ならサラサラ | 雪の体積含水率区分を鉱物/PVA粒床の触感に転用できない | 自由水・結合水、布への水移り、粘着を個別に評価 |
| 表面31〜33℃を保証 | VT3の蒸発可能量、反射率、風、天候、噴霧の均一性が仮定 | 50℃の素材試験を独立に設定 |
| 塑性変形＝傷 | VT4のHertz応力が降伏域に入ることと、削り傷・体積摩耗が生じることは別 | 弾塑性接触と摩耗則を分離。65％を実傷率としない |
| 乾燥μの合格確率2％ | τ0や接触粒割合の仮定分布による条件付き頻度 | 実物の成功確率ではない。未測定値を同定する |
| 斜面合格確率99.5％ | 任意の入力分布内の頻度。最悪状態・局所水圧・地盤破壊を保証しない | 決定論的な荷重条件と実物の下限強度で判定 |
| 最高46℃だから火傷の心配が小さい | 特定晴天・物性・風の計算。今回の指定50℃、圧接、濡れ、摩擦発熱を包含しない | 人体接触適合の判断を保留し、代替皮膚の熱・擦過評価へ |
| 濡れ強度があれば整地後も安定 | 接点の強度と、その再形成速度は別。夜は結露・高湿にもなる | 無加熱での回復時間を測定対象に残す |

Mössnerらの測定は `Fn = HV × V`、せん断開始は `Ft = Sf × L × e` で整理される。動的に削り続ける抵抗は同論文の測定対象外である。本研究で必要なのは、その先のエッジ解放と繰り返し挙動まで含む。したがってSfだけを合わせても圧雪のターンは完成しない。[原論文](https://doi.org/10.3189/2013JoG13J031)

ソールは一つのμだけで滑るのではない。実雪の摩擦研究でも、雪の変形、実接触面積、水分の働きが区別される。今回も `F全抵抗 = F界面 + F押しのけ + F粘弾性損失 + F水分による抵抗` とし、実板で総量を確認する。[スキー・スノーボードの実験研究](https://www.frontiersin.org/journals/mechanical-engineering/articles/10.3389/fmech.2021.728722/full)

### 2.3 独立計算で分かったこと

本書末尾に実行したPythonコードを収録する。別途、同じコードと結果JSONを `バーチャル試験/` に保存した。実行したのは決定論的な計算とVT3の再実行であり、新たなDEMや分子動力学を実行したとは称さない。

**VT3の再現と仮定感度**

北向き、表層5mm、体積含水率3％を5分ごとに補う元モデルで比較した。`f = clip((θ−0.005)/0.02, 0, 1)` は、体積含水率2.5％以上なら蒸発需要を100％供給できると仮定している。この関係は対象材で未測定である。fに一律係数を掛けた感度計算は以下となった。

| 蒸発供給係数の仮定 | 営業中の最高表面温度 | 2,000m²の供給水量 |
|---|---:|---:|
| 元の仮定と同じ1.0 | 31.61℃ | 13.38t/日 |
| 0.3 | 38.38℃ | 8.40t/日 |
| 0.1 | 44.17℃ | 4.43t/日 |

これは実測の予測幅ではない。未同定の蒸発特性を変えると結論が動くという感度である。係数1.0で時間刻みを10秒から5秒にすると31.613℃、13.362t/日となった。細かく計算するだけでは、蒸発仮定の誤差は消えない。

表層5mmの3％水分は0.15kg/m²である。蒸発0.6kg/m²/hなら、全量を使えても15分相当しかない。結合水や内部に閉じた水はこの全量を直ちに供給しない。噴霧間隔、貯水、触感を別々に決める必要がある。

**雪の貫入は器具の角度で桁が変わる**

長さ200mm、幅62mm、荷重490.5Nの例で、平置きは `e = F/(HV L W)`、片エッジ45°で反対側まで沈まない場合は `e = sqrt(2F tan45°/(HV L))` となる。

| HVの仮定 | 平置き | 45°のエッジ |
|---|---:|---:|
| 0.04 N/mm³ | 0.989mm | 11.074mm |
| 0.16 N/mm³ | 0.247mm | 5.537mm |

値は指定したHVと器具の幾何からの計算で、今回作った材料の沈み込みではない。同じ「雪の硬さ」でも比較条件が必要で、平置きの小変形だけを合わせてはいけない。

**30°斜面の厚さ方向を統一する**

VT1の無限斜面式のzは鉛直深さとして読む。施工厚0.45mを斜面法線方向に取る場合は、厚さtを使って

`c必要 = FS γsat t sinβ − (γsat−γw) t cosβ tanφ`

とする。乾燥かさ密度1,674kg/m³、固体密度2,710kg/m³、飽和平行浸透、FS＝1.5、t＝0.45m、β＝30°の条件では、φ＝30/35/40°に対して **4.48/3.98/3.42kPa**。0.45mを鉛直深さとする場合より約15.5％大きい。この式も局所湧水、すべり面位置、粒床と地盤の境界、地盤の深い崩壊を検証したものではない。

**50℃を越えないために必要な放熱を明示する**

気温35℃、斜面での日射1,000W/m²、表面放射率0.95、大気放射の有効放射率0.9、蒸発と地中への熱逃げを入れない定常感度計算を行った。hは対流熱伝達率の仮定である。

| 日射反射率の仮定 | h＝5.7 W/m²K | h＝13.3 W/m²K |
|---|---:|---:|
| 0.35 | 81.0℃ | 65.3℃ |
| 0.55 | 67.5℃ | 55.9℃ |
| 0.85 | 45.1℃ | 41.3℃ |
| 0.95 | 37.0℃ | 36.2℃ |

これは現地予報でも最低必要反射率の規格でもない。**乾燥・汚れ・低風速を含む境界条件なしに「最大46℃」とは言えない**ことを示す。反射率0.55・h13.3の条件で50℃に抑えるには約123W/m²の追加放熱が必要で、蒸発だけなら約0.181kg/m²/hに相当する。供給損失、湿度による蒸発限界は別に足す。

反射を増やす研究は有用である。セルロース系の構造材で日射の後方散乱と赤外放射を利用した研究がある。ただし板材の性能を、濡れ・土砂・摩耗のある粒床の性能と同じにしない。[Liら2019](https://pubmed.ncbi.nlm.nih.gov/31123132/)

80kgの滑走者、30°、速度10m/sなら、界面の摩擦仕事率 `μmg cos30°v` はμ0.05で約340W、μ0.10で約680W。これを全面一様な熱や全量皮膚への熱と扱わず、板と接点への配分・接触時間を計算する。50m直滑降で10m/sを越え得るため、2/5/10m/sに加えて実運用の最高速度を包含する条件が必要になる。

### 2.4 追加されたVT5・VT6の独立検証

**VT5：摩耗の算術と「傷を直せる」という判断を分ける**

VT5は比摩耗量kを `10⁻⁷〜10⁻⁴ mm³/(N m)` の仮定分布から与えている。摩耗深さは `k × 平均面圧 × 距離` なので、kを実測していない限り、中央0.8µm/日や95％値18µm/日は対象材の予測精度を持たない。乱数を1,000万回に増やしても、この分布を測定したことにはならない。

VT5の比較用面圧 `1,400N/0.168m² = 0.00833N/mm²`、30km/日×100日の条件では、許容損失100µmならk≦4×10⁻⁶、500µmならk≦2×10⁻⁵という逆算は再現できる。ただし500µmを失ってよいかは用具仕様で別に決める。**ワックスを塗ることは失ったソール材の復元ではなく、ストーン研磨も材料を除去する。** 摩耗損失と研磨による損失を合算する必要がある。

また、Hertz応力が硬さを越えること、残留くぼみ、引っかき傷、体積摩耗は別の現象である。「丸い粒ならエッジは無傷」は、割れた粒・異物・繰返しを含まない。U5は試験1回で完了とせず、50℃、湿乾、砂混入、荷重・速度、複数の製造ロットを含む摩耗則の同定に改める。

**VT6：石灰水による炭酸化析出は候補に残すが、強度と硬化時間を訂正する**

1. **PVAの吸水時間を、全PVAの不成立証明にしない。** `h²/D` は仮定した厚さ5µm・拡散係数での吸水時間の目安であり、結合が必要強度を下回る時間や溶解時間ではない。結晶化度・架橋・湿潤接点強度を含まないため、VT6の「原理的に不可」をPVAの全配合へ一般化できない。第2.1節の高結晶・高温水中の文献と同じ配合条件で再比較する。
2. **Rumpf式の係数を修正する。** `vt6.py` は `σ=(1−ε)/ε × ZF/(πd²)`、ε＝0.382、接点数Z＝6としている。等方的な同径粒で粒数密度 `n=6(1−ε)/(πd³)`、接点密度nZ/2、枝長d、方向平均1/3を使うと、`σ=(1−ε)ZF/(πd²)` となる。接点数Zを既に明示した式に、さらに1/εを掛ける根拠は同梱コードにない。一次研究で提示されたRumpf式も後者である。**この係数だけを直すとVT6の68〜101kPaは約26.0〜38.6kPaに下がる。さらにこれは理想化した引張応力の推定で、せん断のcそのものではない。** 強度がこの値になると確定したわけではない。[式が掲載された一次研究](https://www.sciencedirect.com/science/article/abs/pii/S0032591015002065)
3. **析出量と水収支をつなぐ。** VT6と同じ2,000m²・表層5mm・乾燥密度1,674kg/m³では表層質量16.74t。ここへ0.1質量％のCaCO₃を析出させるにはCaCO₃ 16.74kg、Ca(OH)₂ 12.39kg、CO₂ 7.36kgが必要となる。石灰水濃度をVT6と同じ1.6g/Lとすると、カルシウムを100％目的層に保持し完全反応させても **7.745m³、3.872L/m²** が必要。表層の空隙容量は **1.91L/m²** で、1回分の液量は約 **2.03倍**。分割散布すれば瞬間的な飽和を避ける余地はあるが、カルシウムが深部へ流れる量、乾燥時間、接点へ残る割合を同時に解く必要がある。夜の散水自体を昼のべしゃべしゃと同一視はしない。
4. **1.3〜3.9時間は理想化したCO₂供給時間。** 元式は反応面のCO₂濃度をほぼゼロとして、空気中の移動抵抗と仮定した有効拡散係数から必要量を割っている。算術は約1.27〜3.86時間と再現できるが、反応完了・接点強度の発現時間ではない。上記の水量で孔が濡れるとガスの通り道も変わる。液相輸送、反応速度、生成層、接点への析出選択性を連成する。石灰ペーストの一次研究でも、孔内水によるCO₂拡散制限と、反応・拡散の支配段階の変化が観察されている。濃いCO₂のペースト試験を、屋外空気の粒床の硬化時間へ流用はしない。[Cizerら2012](https://www.sciencedirect.com/science/article/pii/S0950061812002383)
5. **アルカリと冬の残留物を質量で追う。** 夜間散布であること、朝の上面pHが低いことだけでは、粒接点や深部の未反応Ca(OH)₂が除かれた証拠にならない。雨で再び溶出する場合も評価する。Ca(OH)₂には皮膚・眼の化学損傷や吸入による刺激がある。[NIOSH](https://www.cdc.gov/niosh/npg/npgd0092.html) 未反応の1.6g/L液について理想希薄溶液として計算した凝固点降下は約0.12Kであり、ゼロではない。「塩とは違って融雪しない」という説明にしない。冬に散布を止める設計でも残留物の確認は必要になる。
6. **表層の変化を全床質量で薄めない。** 16.74kg/日を100日間残せば1.674t。厚さ450mmの全床に対しては約0.11％だが、処理対象である5mm表層に対しては元質量の10％である。整地・混合・回収・流出を分けて、孔の閉塞、硬い塊、破断微粉を評価する。水への総溶解量が小さくても、細い接点が選択的に失われれば強度は変わる。

HBG-6の活用方向は、**「炭酸化析出を、粒の形状や接点を作る製造手段として研究する」**ことである。室温での析出による結合は、通常の高温の固相焼結と区別して記載する。工場で炭酸化・洗浄を完了させた多孔粒を、再形成可能な別の接点と組み合わせる枝を追加する。現場で毎晩再形成する枝は、CO₂と水の輸送、未反応物、接点強度、8時間の滑走耐久が同時に成立する範囲を求める。これは石灰水案を捨てる結論ではなく、**鉱物の結晶成長を有用な工程へ移し、利用者が触れる完成粒と現地反応を分けて比較する提案**である。現時点で屋外散布・人体試走は実施していない。

### 2.5 VT7の滑走後・雨天モデルへの追加監査

本書の復旧検討中にVT7が追加されたため、報告と`vt7.py`を読んで以下を照合した。VT7の乱数試験を再実行して同じ数値を得たとは称さない。

- **1日2〜3tを戻せばよいという量は未校正。** 削れ深さ0.3〜1.5mm、緩い層による削れ抑制、移動割合、安息角によるずり落ち係数が仮定されている。エッジ荷重・速度・温度・橋の破断データから導いた量ではない。台風後の量でもない。また「下端5m」と「場外流出」の合計を一つの回収量としており、場外分をピステンで回収できることは未確認である。
- **セル変更は同一の物理条件になっていない。** 横への移動が「1マス」で固定され、ずり落ちも一定割合を隣の1マスへ送るため、0.5→0.25mへの変更で物理的な移動距離も半分になる。幅0.3mの削れ面積も、セルの実交差面積による重み付けではない。現状の15〜20％差を純粋な格子収束誤差とは呼べない。移動距離・削れ面積を実長さで固定し、質量保存を検査した上で再計算する。
- **飽和透水係数Ksatだけから「表面流なし」を決めない。** 表層の目詰まり、濡れ性、非飽和流、底面地盤、排水出口の背水、上流流入を含めて浸透能力を求める。砕石層のK＝0.1m/s・厚さ0.2mは仮定の設計候補であり、対象斜面で100mm/hを処理できると確定していない。水平降雨基準と実斜面面積も統一する。
- **雨上がり6〜19分は回復保証ではない。** コードの式は仮定した`K=Ks Se^m`の局所的な変化時間の形で、初期含水から目標までの排水過程を積分した式ではない。さらに「体積含水6％＝通常の触感」も未測定。単純な一様貯留層の排水式でも初期条件が必要であり、実斜面では空間的な水移動と境界条件を解く。
- **溶解質量の割合を強度低下の上限にしない。** 雨30mm×2,000m²＝60m³は、雨量を水平基準とするなら30°の投影補正が要る。同じ50mg/Lを仮定した算術は約2.60kgだが、50mg/L自体を現地水質・反応条件に対する普遍的上限とはしない。接点が選択的に溶けると、少ない質量損失でも保持力は大きく変わり得る。雨の初期pHだけで、補給されるCO₂や緩衝成分を含む総酸消費量も決まらない。

雨の夜の石灰水散布を避けるというVT7の方針は、未反応アルカリの流出を減らす方向として残す。ただし雨天が連続すると再結合する時間がなくなるため、「前夜に再形成しない日でも保持する接点」と「雨上がりの作業時間」を同時に評価する。営業可否を、現在の仮定モデルだけで確定しない。

### 2.6 共有直前に追加されたVT8の監査

VT8の報告と`vt8.py`もコミット`71b8210`まで確認した。VT8の乱数試験の再実行は行っていない。

**周期境界の通過量と山麓で回収する量を区別する。** VT8はコース中間の50m区間を周期境界で扱い、下端を通過した粒を上端へ戻している。約4.5t/日は、このモデルの一つの断面を横切る輸送量であり、1km全体に発生する移動量・山麓での流出量・必要な戻し仕事量を同時に表すものではない。断面流量の空間差、上端流入、山麓流出、粒の移動距離を含む全コースの収支が必要である。

**整地の模型は力学的な復旧を解いていない。** 昼整地は5m四方の緩み厚を平均する操作であり、履帯・刃・ティラーの荷重、密度変化、接点回復、基盤の削れ形状の回復を計算していない。残った厚みだけを根拠に「昼整地なしでも滑走機能を保つ」としない。濡れ摩擦・横支持・局所的なグラブも判定対象である。

**CO₂の理論必要量と再開までの時間を分ける。** 純CO₂を空隙に満たしたときの質量が化学量論的な必要量に近いことは、実際に全接点へガスが届き、反応・排水・強度回復が終わる証明ではない。第2.4節の石灰水量とガス用空隙の両立、フードからの損失、未反応物を収支に加える。「pHセンサーで固まり終わりを確認」は、pHと接点強度の対応を実測するまで成立しない。数分〜30分、30〜60分での営業再開は未確定である。

**新しい条件を既存条件と混ぜない。** VT8の8〜22時・14時間営業はv36側の9〜17時・8時間と別条件、幅40mも仮定である。本書の2,000m²の計算は比較単位として保持し、1kmコースへそのまま適用しない。VT8の厚さ0.30mは削れ代を150mmへ変えた案であり、局所300mm削れ条件を満たした厚さではない。均せば毎晩完全に戻ることや、日最大削れを10倍すれば10日分になることも未検証。丸い／角ばった砕石のφを一つずつ仮定した結果は、形状だけによる普遍的な採否にはならない。層構成のフィルター条件は実際の粒度分布・内部安定・目詰まり・境界せん断まで照合する。

融点が50℃以上という条件だけなら候補は多数ある。難題は、低い摩擦、雪らしいエッジ抵抗、粒の耐久性、人体接触、冬の保持を同時に成立させることである。以下の順位は研究の情報価値に基づく提案であり、合格材料の順位ではない。

|---|---|---|
| 結晶化PVAの高固形分骨格 | 結晶領域による物理架橋。高温水中の形状保持に一次研究あり | 主案A。水分依存、乾湿収縮、クリープ、塩を抜いた後の性能を詰める |

## 4 発明仮説と粒の設計

### 4.1 結晶骨格型人工フィルン

仮称を「結晶骨格型人工フィルン」とする。新規性が確認された名称・発明ではなく、検証する構成を特定するための呼称である。

**一つの粒の内部に耐久性の高い結晶骨格を置き、その骨格に丸い短枝と開いた孔を作る。粒同士の接点は、粒本体より先に外れる。滑走表面のごく薄い親水層は、接点の結合強度を決める領域と分ける。** 空間を埋める厚いゲルや遊離潤滑液に、荷重支持と低摩擦の両方を任せない。

```text
実UHMWPEソール・鋼エッジ
        ↓荷重  →滑走
 [丸い接触部]   [丸い接触部]      表面：薄い固定化親水層の有無を比較
       \ 短枝 /                     枝：曲げるが、粉になる破断を避ける
       [結晶骨格＋開いた孔]         粒内：強い構造を保持
            · 接点 · 次の粒         粒間：解放・移動・再結合する部分
         ↓ 排水路 ↓                 粒集合体：空隙を保ち、冬の雪と噛み合う
```

雪を構成する氷とPVAは化学的に異なるが、上記の構造は機能ごとに調整できる。狙うのは硬さの数値だけでなく、**押すとある範囲で沈み、エッジでは横を支え、過荷重では粒間が外れ、整地すると粒本体を大量に破砕せず回復する**応答である。完全弾性で跳ね返るだけの粒床も目標から外れる。

これは粒状材料であり、敷設ネット・ブラシ・シート・剛性パッドを使わない。粒が壊れて針や遊離繊維になる設計も採らない。ミリメートル粒の短枝と、分子鎖の表面処理とを混同しない。

### 4.2 探索する寸法と組成

以下はすべて**未製造の探索値**。大きな六方向粒を先に固定せず、実圧雪と対応するスケールから絞る。

| 変数 | 初期の探索範囲 | 狙いと測るもの |
|---|---|---|
| 粒の外接寸法 | 0.5〜1.5mm、粗大粒を別管理 | エッジが粒単位で跳ねることを避ける。小粒化に伴う飛散も確認 |
| 短枝・孔 | 丸い短枝、開いた孔20〜200µmを候補 | 再配置と排水。尖端・閉じた浮力空間を避ける |
| 粒内部の固体体積率 | 0.25〜0.60を主探索、より低い値は比較 | 軽量化・曲げと、圧潰・クリープの折り合い |
| Aの乾燥固形分組成 | PVA/セルロース＝100/0、80/20、60/40質量比の比較 | 配合比を既知の最適値として扱わない |
| Aの結晶領域 | 工場の凍結成形・乾燥・熱処理条件で変更 | 湿潤時結晶性と粒の繰返し圧縮。乾燥DSCだけで判断しない |
| Bの骨格 | 無充填UHMWPE、無充填PBTを別々に比較 | 粒形の効果と化学組成の効果を切り分ける |
| 表面層 | なし／固定化PVA／固定化親水性共重合体の別枝 | 厚い水袋を作らず摩擦を下げる。表面処理による粒間摩擦の低下も測る |
| 粒間接点 | 接点径・面積率・回復時間を独立変数化 | 微量PVA接点を第一比較。濡れた状態での再形成が成立しなければ変更 |

PVA系の塩析やアルカリ処理は**工場内の比較工程**であり、現地に塩を残して強度や潤滑を得る処方ではない。第一比較は添加塩を使わない熱処理・凍結成形とする。工程上の塩等を利用する枝は、洗浄後の強度、pH、イオン、可溶分の確認を条件とし、洗浄水処理を原価に含める。強酸・強アルカリを現地に散布する案は採らない。

PVAの物理架橋だけで50℃湿潤時の保持が不足する場合、工場での放射線架橋は比較できる。Sasakiらは特定PVAゲルの照射と37℃の摩擦を検討しているが、粒床への効果は別途確認が必要である。今回、線量や処理仕様を承認したわけではない。[Sasakiら2018](https://doi.org/10.3390/gels4020030)

### 4.3 製造から使用までの仮工程

1. 原料の分子量、けん化度、灰分、添加剤、セルロース由来と残留薬剤を固定する。原料規格と完成粒の規格を分ける。
2. Aは工場で小さな多孔構造を作り、乾燥・熱処理・再含水条件を比較する。最初の形状評価には小型成形を用い、3D印刷の費用をそのまま量産価格としない。
3. Bは各樹脂の成形法に合わせて多孔粒を作る。UHMWPEに通常の低粘度射出を当然に当てはめない。粉体焼結等も比較し、製造歩留まりを測る。
4. 丸み付け・分級を行い、摩耗前後の尖端と微粉を確認する。強い粒を作るために、硬い研磨材を露出させない。
5. 潤滑表面と接点処理を別の試験系列で比較する。表面の処理剤が接点全体へ回り、粒床を崩しやすくしていないか確認する。
6. 全深度に必要な性能を持つ粒を敷き、整地・局所掘削・深部粒の露出後も同じ受入曲線で判定する。表面だけを有利な素材で覆って300mm削れ条件を満たしたことにしない。
7. 運用は「乾燥」→「粒表面に必要な少量水」→「制御噴霧」の順で必要性を比較する。散水を減らすほど有利とは限らず、摩耗粉、グラブ、熱を同時に測る。

## 5 設計を絞る数値条件

### 5.1 粒の剛性と接点の強さを分ける

多孔体の初期検討として `E粒 ≈ C形状 E骨格 (ρ粒/ρ骨格)²` を使える。ただし曲げが支配する多孔骨格のスケーリングであり、粒床の弾性率ではない。C形状、方向性、節点の剛性が未知なので、係数を都合よく選んで合格させない。今回の独立コードではE骨格0.5/2GPa、相対密度0.15/0.30、C形状0.1/1を振り、粒内の推定剛性に大きな幅が出ることを確認した。粒間接触を含む床の応答は別に求める。

接点設計の単純な逆算も行った。等方的な中心力を伝える接点、球相当径d、骨格充填率φ、接点数Z、接点半径a、接点材強度σbなら、応力テンソルの平均化から

`σ集合 ≈ φ Z σb (a/d)²`

となる。φ0.6、Z6、σb1MPaを**仮定**すると、a/d＝0.03/0.06/0.10で3.24/12.96/36.0kPa。接点寸法で桁を動かす設計変数がある。ただしこれは理想化した集合体応力の目安であり、Sfやcにそのまま代入しない。短枝の曲げ、接点分布、方向性、破断と再形成が入ると変わる。

ここから得る設計方針は、「粒本体を弱くして粉にする」ではなく、「粒本体は残し、接点と再配列で圧雪らしい変形を作る」である。粒の再生可能性と、接点の修復可能性は別々に原価へ入れる。

### 5.2 軽量化で高機能材料の価格枠を作る

正本と同じ仮の事業条件B＝1,900万円/年、I＝2,000万円、O＝400万円/年、10年8％、年補充率λ＝10％をそのまま使った比較である。

`Af = (1−1.08^−10)/0.08`

`Pmax = ((B−O)Af−I) / (M(1+λAf))`

| 乾燥かさ密度の仮定 | 2,000m²×法線厚0.45mの質量 | 完成粒の単価上限 |
|---|---:|---:|
| 1,674kg/m³ HBG-5 | 1,506.6t | 32.0円/kg |
| 500kg/m³ | 450t | 107.3円/kg |
| 300kg/m³ | 270t | 178.8円/kg |
| 200kg/m³ | 180t | 268.1円/kg |

**軽い材料なら高機能原料を使える余地が広がるが、安くなった証明ではない。** この式の初期材料予算はどの行も約24,133円/m²で同じ。成形、洗浄、乾燥、配送、補修、流出管理が増えれば余地は減る。正本にあるPVA原料価格の仮定だけでも、300kg/m³の純PVA案は厳しい。現在の国内実見積りは本調査で取得していない。乾燥密度・完成品価格・更新率・日中運用費を同時に絞る。

VT2では設備年額込みの運用費が増えている。新しい見積りではIの設備費とOに含める設備年額を重複させない。上表を現行運用案の確定採算としない。

### 5.3 軽さの代償である暴風と浮力を先に扱う

空気密度1.2kg/m³、80m/sの速度圧は3.84kPa。法線厚0.45m、30°斜面の自重法線成分は、乾燥密度300kg/m³で約1.147kPaしかない。仮に吸上げ係数1で床全体に差圧がかかれば、自重だけでは約2.69kPa不足する。500kg/m³でも約1.93kPa不足する。

この係数1は現地の測定値ではなく、保持方式を省略しないための荷重例である。全床自重が表面の一粒に作用するわけでもない。局所粒の飛散、面の剥離、底面からの持上がり、粒床と地盤の分離を別々に解く。

閉鎖時に同じ粒の接点密度を増して保持を強め、再開時に整地する方式は発明仮説として残す。しかし、上部を強くするだけでは底面から全体が剥がれる問題は消えない。**禁止された固定材を使わず、湿潤時にも荷重が地盤まで伝わる方法と再整地性が確認できるまで、軽量案のR07〜R09は合格にしない。** 継続案は、同じ材料の接点処理と地盤側の付着・粗度を調べることであり、埋設ネットや硬いパッドへの置換ではない。

UHMWPEのように骨格自体が水より軽い系は飽和・豪雨時の浮力が特に重要。PVA/セルロース系でも閉じた孔内の空気は浮力源となるため、開いた孔の排水・排気と飽和状態での保持を確認する。

### 5.4 表面層の消耗を量で管理する

表面積倍率s、摩耗厚さδ、密度ρから `補充質量 = 斜面面積 × s × δ × ρ` とする。2,000m²、s＝2〜4、PVA密度1,270kg/m³、δ＝0.5µm/日なら2.54〜5.08kg/日、100日で254〜508kg。この値は摩耗厚さと接触する面積を仮定した算術である。

v36の48kg/回とVT2の表面積倍率2〜4は、更新する深さ・内部表面積の定義をそろえて比較する必要がある。上面に露出した粒の一部だけか、深さ10mm程度の全粒表面まで液が回るかで必要量は変わる。補充できるから環境流出してよいとはせず、回収粒、微粉、溶出高分子、場外流出を別の台帳にする。

## 6 同じ素材で夏から冬へつなぐ

### 6.1 雪の定着を助ける構造

狙う構造は、雪が入り込める開いた空隙、丸い短枝の間の噛み合い、余剰融雪水を流す経路、少ない残留可溶分である。冬前には同じ粒を整地し、夏に必要だった過剰な遊離水や表面汚染を残さない。季節ごとの全撤去は前提としない。

依頼者の追加指定を受け、**夏の滑走接触部と、冬の雪・氷の固着部を粒の表面で分担させる案**を追加する。夏に板が接触する丸い凸部には薄い潤滑表面を検討し、側面の開いた孔・凹部には雪が入り込んで氷橋や機械的な噛み合いを作る場所を残す。全面を防氷・撥水・低付着の表面で覆わない。粒は回転・摩耗するため、上下が固定した粒として設計せず、どの向きでも露出する側孔と凸部を分散配置する。局所被覆の製造性とコストは未確認である。

排水路と固着部は別の寸法で設計する。粒間の連続した開口で余剰水を流し、粒側面の開いた凹部に入った雪と凍結可能な水で固着を助ける。**「水分を全て排除する」ことではなく、滑り面になる連続水膜・滞留水を作らないことが目的**である。凍ってできた氷橋は候補機構だが、気温0℃付近や雨で氷橋が消えても、開口と凹凸による保持・排水が必要になる。

夏の低摩擦表面が、冬の雪との滑り面になる可能性は明示する。雪と粒の界面、粒同士、粒と地盤の三つの界面を測り、凍着していない初雪時と0℃近くの濡れた状態も評価する。界面水と滑雪の関係は現地観測でも重要であり、「雪が孔に入るから滑り落ちない」とは判定しない。[Feesら2025](https://tc.copernicus.org/articles/19/1453/2025/)

判定には、積雪荷重下での界面せん断・引離し・長時間クリープ、排水が一部閉塞した状態、融解後の保持、再凍結の繰返しを含める。**夏の摩擦が良くても、冬の界面が滑りやすくなる表面処理は候補から外す。** この試験が扱うのは雪と素材の境界であり、雪層の内部や上流からの雪崩まで材料単体で防げるとは扱わない。

固着の要求を荷重から逆算する。積雪の斜面法線厚h、密度ρ雪、勾配βなら、単位斜面面積当たり `τ=ρ雪gh sinβ`、`σn=ρ雪gh cosβ`。例としてρ雪300kg/m³、h1m、β30°では滑落方向1.472kPa、法線2.549kPa。仮の安全率1.5なら、界面の総抵抗に2.207kPa以上が必要になる。これは現地設計値や保証値ではなく、雪厚・密度から必要な界面試験荷重を決める例である。`c界面+(σn−u)tanδ≧FSτ` を使う場合も、c界面・δ・水圧uは雪と完成粒の組合せで取り、初期の凍着だけでなく融解後の残留抵抗と時間依存まで確認する。排水の効果はuを抑えることとして力学にも接続できる。

### 6.2 冬に余計に溶かさないための熱設計

乾いた床の顕熱は `Q = ρ乾燥 c比熱 t ΔT`。HBG-5のρ1,674kg/m³、比熱840J/kgK、厚さ0.45mを仮定すると、床全体が0℃より10K高い場合に約6.33MJ/m²、氷の融解潜熱334kJ/kgで割ると18.95kg/m²相当となる。ρ300kg/m³・比熱1,500J/kgKの仮の多孔候補では2.03MJ/m²、6.06kg/m²相当である。

これらは**全蓄熱が雪へ渡るとした換算量で、追加融雪の予測ではない**。現地の自然地面も熱を持ち、秋から冬の履歴によって床温度も変わる。軽量化は蓄熱を減らす方向だが、低熱伝導の床が秋の地面の冷却を妨げる場合もある。夏の50℃から冬の積雪まで同じ温度が続く計算をしない。

評価式は、同じ気象・降雪・境界条件で

`ΔM = M人工床上 − M現地自然地面上`

とする。人工床と地面を別々の1次元または多次元熱・水収支で積雪前から計算し、短波・長波、対流、蒸発、降雨移流、地中熱、凍結潜熱を収支へ入れる。天然雪を追加したり水を余分に凍らせたりした分を、材料そのものの保雪効果にしない。

ユーザーの「自然地面に比べ追加融雪なし」を維持する。統計上の片側95％上限≦0を使用するなら、効果が真にゼロの系は通りにくいことも認識し、材料に実質的な保雪改善の余裕を持たせる。勝手に許容融雪量を正に変更しない。

### 6.3 塩がなければ十分とはしない

残留塩、洗浄剤、未反応物、可溶性高分子を分析し、現地地面の浸出水と比較する。高分子に固定された親水基と、自由に溶ける低分子を同じ濃度で扱わない。一方で、塩が検出されないことだけを「融雪しない」証明にはしない。高分子周囲の凍りにくい水、微細孔中の水、溶出物、初期床温度がある。

DSCで凍る水と凍らない水を区別し、浸出水の凝固・雪と接触したときの融解を測る。生分解性の表示も、冬の融雪抑制や排水先への無害性を意味しない。

## 8 次の計算と材料選定を具体化する

### 8.1 仮想試験で先に減らせる不確実性

1. **基準雪の応答を定義する。** HV・Sfの単一値ではなく、荷重変位、除荷履歴、動的横反力、停止からの滑り出し、振動スペクトルを集める。文献条件の異なる雪を一つの分布へ混ぜない。
2. **単粒の力学を計算する。** AとBの実測または同一配合の文献物性を入力し、温度・水分依存、孔・短枝の曲げと座屈、局所応力を有限要素法で比較する。未測定の組成は物性の範囲として示す。
3. **3次元の結合粒子DEMを作る。** 粒回転、滑り、接点の発生・消滅、接点破壊、粒内変形を扱い、Mössner器具と実エッジの幾何を入れる。2次元線形ばね網をDEMで検証済みと記載しない。
4. **接点と摩擦を別々に同定する。** 雪のHV/Sfに合うようにcとμを都合よく調整して終えず、単粒・単接点データで固定した入力が別条件でも再現するか確認する。
5. **50℃の熱と水を連成する。** 水保持曲線、蒸発供給、乾燥/湿潤/汚れ後反射率、透水、表面粗度を区別する。噴霧の空間ムラと停止区間を入れる。
6. **30°と80m/sを別の荷重条件で解く。** 斜面内部、端、補修境界、底面、豪雨での背水、浮力、局所飛散を調べる。全層の安定を局所粒の保持へ流用しない。
7. **秋から冬の比較計算を行う。** 地盤の蓄熱と水、雪との界面、孔に残る水を含め、自然地面との差を出す。保雪、滑雪抑制、材料の保持を独立に採点する。

最初の探索はA/B/Cの構造を同じ粒径・同じ空隙率で比べ、次に形状を変える。変更を一度に全部入れず、化学組成と構造のどちらが効いたか分かる比較を作る。粒数・計算領域・刻み幅を変えた数値収束と、外部データとの一致を別欄で報告する。

### 8.2 最小限の物性取得に渡す仕様

依頼者の方針どおり、先に計算で候補と必要な範囲を絞る。その後の物性取得は、合否を変える次の順序とする。これは発注ではなく仕様案である。

| 順位 | 対象 | 取り出すデータ |
|---|---|---|
| 1 | Aの洗浄後粒、Bの粒、HBG-5の粒 | 30/40/50/55℃、乾燥・適湿・水浸の単粒荷重、8時間クリープ、再含水・乾燥後形状 |
| 2 | 同じ粒の表面処理3系列 | 実UHMWPEとの停止・再始動・速度依存、摩擦変動、付着と体積摩耗。局所温度も測る |
| 3 | 単接点と小型粒床 | 結合の破断、0/2/8/24時間の再形成、貫入・動的横反力、粒の再配置と粉化の区別 |
| 4 | 浸出水と雪との接触 | イオン・pH・可溶分、凍る水、自然地面との差、冬の界面せん断 |
| 5 | 損傷・汚れ後の同試料 | 発じん、代替皮膚、排水、生物膜、耐候、凍結融解後の再現性 |

速度は2/5/10m/sだけでなく低速から停止・再始動と、想定する最高速度までを含める。約20m/sの比較条件を計算上の候補とし、実際の設備・運用速度から定める。最初から人を滑らせて確認する方式にはしない。

失敗したときも結論を「できない」で止めない。Aが50℃で軟化したら結晶化・架橋の方法またはBへ、低摩擦でも横支持不足なら接点と形状へ、雪を滑らせすぎるなら表面処理の面積と冬の界面構造へ、飛散が大きければ粒寸法・密度・回収可能性へ戻る。変更後は同じ評価を再実行し、別の要件を悪化させていないか確認する。

### 8.3 雨・台風後にピステンで戻せる構造と復旧量

**粒が健全なまま回収でき、登坂運搬と接点回復が間に合えば、再配置による復旧を狙える。一方、現資料のHBG-5/HBG-6や新案A/Bについて「均せば性能が戻る」と実証された状態ではない。** 今回は、この方式が成立するための量と力の条件を計算した。侵食流出率そのものを予測する校正済みの流体・粒子シミュレーションを実行したとは記載しない。

**降った雨、動いた粒、山麓で回収できた粒は別に計量する**

斜面実面積2,000m²、30°で、水平面基準の降雨100mm/hを仮定すると、鉛直に降る雨の斜面への入力は `0.1×2,000×cos30° = 173.2m³/h`。これは上流からの流入を含まない降雨入力であり、全量が表面を流れるとの予測ではない。浸透、貯留、地下への排出、表面流出を閉じた水収支にする。100mm/hは現地の設計降雨と確認した値ではなく感度条件である。

流下水の深さを斜面法線方向h水とする単純な定常等流水では `τ水 ≈ ρ水gh水 sin30°`。h水＝1/3/10mmなら4.91/14.7/49.1Paとなる。結合が切れた直径1mmの方解石について、仮のShields数0.03〜0.06を水平な非結合粒の目安式へ入れると約0.50〜1.01Paであり、「重い粒なので表面水で動かない」とは見込めない。ただし急斜面補正、短枝形状、粘着接点を含む実床の侵食限界は、この値では決まらない。USACEも非結合粒の移動閾値と結合性材料の侵食を分けて扱っている。[USACEの移動・侵食閾値の技術資料](https://www.hec.usace.army.mil/confluence/rasdocs/d2sd/ras2dsedtr/latest/model-description/critical-thresholds-for-transport-and-erosion)

新案の乾燥かさ密度300kg/m³を、そのまま水中での「一粒の密度」としてShields式に入れてはいけない。粒間空隙、開孔、閉孔、吸水によって浮力と抗力は別になる。初期の乾いた粒と、十分に含水した粒の流出を両方扱う。

最初に設計するのは、上流からの不要な流入の分離、局所集中流の抑制、排水流末と回収場所への車両アクセスである。既存の回収池だけで全粒を回収できるとは仮定しない。健全粒を泥・微粉から分ける回収区画と水の処理を比較し、設備と清掃費を加える。斜面全体をネットやシートで固定する案への置換はしない。

**山側へ戻す運搬回数を数える**

床体積は2,000m²×0.45m＝900m³。山麓へ移動した体積割合をrとすると `V戻し=900r`。以下は一台のピステンについて、平均片道50m、登坂0.8m/s、下り1.2m/s、積込み・排出・方向転換60秒/往復、稼働率60％、実効到達量1.5m³/往復を**仮定**した例である。50mは戻す各地点への平均斜面距離で、標高差ではない。実効到達量はこぼれや膨張を含めた元の床体積換算で、メーカー保証容量ではない。

`往復時間=50/0.8+50/1.2+60=164.2秒`

`運搬時間=ceil(V戻し/1.5)×164.2/0.60/3,600`

| 山麓へ移動した割合の仮定 | 戻す体積 | 往復数 | 運搬だけの時間 |
|---|---:|---:|---:|
| 1％ | 9m³ | 6回 | 約0.46時間 |
| 5％ | 45m³ | 30回 | 約2.28時間 |
| 10％ | 90m³ | 60回 | 約4.56時間 |
| 30％ | 270m³ | 180回 | 約13.68時間 |

排水待ち、泥の分離、補充、最終整地、接点の再形成、再開検査は表に含めていない。コードでは実効量0.5/1.5/3.0m³も比較している。例えば10％移動なら、実効0.5m³では運搬だけ約13.68時間になる。**大きく流してから全量を山頂へ戻す設計は、少ない移動量を短い距離で戻す設計より、簡単な復旧から遠ざかる。** 目標は「移動を許すが回収できる」だけでなく、移動率と平均戻し距離を小さくすることに置く。

後着VT8の1km×幅40mを使う別の規模感度も計算した。仮に厚さ0.30mの床の1％が山麓へ移動すると120m³である。平均戻し距離を500mへ変更し、他の仮定を同じにすると運搬だけ約40.8時間。0.45m厚なら同じ1％で180m³、約61.2時間となる。これは全コースに一様に戻す極端な長距離例であり、現地復旧時間の予測ではない。**長いコースほど山麓一か所への全量集約を避け、近い区間で捕捉・再配置できることに価値がある。** 捕捉設備を増やす費用と排水・施工の制約は別途比較する。

仮に機械復旧を4時間、そのうち運搬を2時間に収める設計枠を置くと、この条件の連続量換算で戻せるのは約39.5m³、全床の約4.39％まで。往復回数を整数に制限すればさらに下がる。これは提案する比較用の作業枠であり、依頼者が定めた許容時間でも、実車で達成した能力でもない。実地の幅・距離・停止時間で計算を差し替える。

PistenBullyには、ブレードで集めた雪を保持して運ぶBlade Loaderと、雪・材料運搬用Snow Bucketがある。したがって「集めて保持し、上へ運び、排出して均す」という機械構成自体は既存技術を利用する枝として残せる。[Blade Loader](https://www.pistenbully.com/en-US/attachments/blade-loader)、[Snow Bucket](https://www.pistenbully.com/en-US/attachments/snow-bucket)

ただし密度1,674kg/m³の材料を1.5m³動かすと乾燥状態でも2.51t。密度300kg/m³の比較案なら0.45tで、含水分はさらに加わる。メーカーの旧Snow Bucket資料には容量約2m³の例があるが、資料は2008年表記であり、現在の対象機との組合せ・許容積載質量は未確認である。容積をそのまま鉱物の積載許可にしない。[旧容量資料](https://www.pistenbully.com/_Resources/Persistent/9/2/c/2/92c20598433ba5031b3a8bc9f787cd6e3b424266/PistenBully_Schneemulde_Datenblatt_EN.pdf)

**回収率が高くても、再利用率と配合回復が必要**

`M再利用=M移動×回収率α×健全再利用率y`

`M補充=M移動×(1−αy)`

HBG-5相当の床で10％が移動すると150.66t。回収率99％・回収物の再利用率95％という高い値を仮定しても、補充は約8.96tで、その内訳は未回収1.51tと回収後の不適合7.46tになる。密度300kg/m³の比較案では同じ割合で補充約1.61t。これらは想定した割合の算術で、実際の流出量・回収性能ではない。**場外へ出た材料は購入で埋め合わせても回収したことにならない。** 未回収量を別に管理し、許容できない流出なら回収・材料設計へ戻す。

均すだけで戻るのは、粒径、短枝形状、表面、接点形成能が残り、泥・異物・微粉の比率も許容範囲に戻せる場合である。HBG-5でPVAが流れた場合は接点・表面の補修が必要。HBG-6で炭酸塩の橋を砕いた場合、押し固めるだけで橋が再生するとは扱わない。A/Bでも孔の潰れや潤滑層の剥離は、再配置では修復されない。回収泥水を未選別で全面に戻す運用は、目詰まりと摩擦増大を招く候補要因として比較する。

**復旧を目指す運用と、次の検証仕様**

復旧工程は、①排水と地盤状態の確認、②回収粒の泥・異物分離と粒径別計量、③不足する粒・表面材・接点材の最小補充、④短い区間ごとに山側へ運搬・敷均し、⑤低い負荷からの整地と圧密、⑥必要な接点再形成、⑦受入曲線と排水の確認、とする。これを既存ピステン一台でどこまでまとめられるかを比較する。

次の仮想試験には、30°、雨50/100/200mm/h、上流流入なし／あり、排水正常／一部閉塞、乾いた粒／含水粒、暴風後の接点損傷を含める。数字は探索条件であり現地の設計外力ではない。流出率を都合よく与えて合格させず、測定または同一材料のデータで侵食限界・侵食速度・粒の破損・溶出を固定し、分級と回収部までの輸送を解く。その後、移動率1/5/10/30％の作業量計算とつなぐ。敷均し後は、新品と同じ50℃の抵抗・横支持・水移り・発じん・透水の受入曲線で判定する。

単一回の復旧だけでなく、雨→回収→再整地を複数回繰り返したときの粒径・密度・表面層・作業時間・補充量を追う。**発明の狙いを「繰り返し戻せる粒本体」と「少量補修で回復する接点・表面」に置く。** これにより、豪雨のたびに材料全体を作り直す方式から、健全粒を残して必要な部分だけ回復させる方式へ設計を進められる。

def dry_temperature(albedo, h, air_c=35.0, solar=1000.0, sky_emissivity=0.9):
    # Flat local energy balance with irradiance on the actual slope surface.
    # No evaporative or ground heat sink; this is a conditional sensitivity case.
    def residual(t):
        return (solar * (1 - albedo)
                + sky_emissivity * SIGMA * (air_c + 273.15) ** 4
                - 0.95 * SIGMA * (t + 273.15) ** 4 - h * (t - air_c))
    lo, hi = air_c - 30, air_c + 100
    assert residual(lo) > 0 > residual(hi)
    for _ in range(80):
        mid = (lo + hi) / 2
        if residual(mid) > 0:
            lo = mid
        else:
            hi = mid
    t = (lo + hi) / 2
    assert abs(residual(t)) < 1e-7
    return {"albedo_assumed": albedo, "h_W_m2K_assumed": h,
            "air_C_assumed": air_c, "surface_C": t,
            "heat_to_remove_at_50C_W_m2": max(0.0, residual(50)),
            "evap_at_50C_kg_m2_h": max(0.0, residual(50)) * 3600 / 2.45e6}


def slope_cohesion(rho_d=1674.0, rho_s=2710.0, phi_deg=35.0,
                   thickness_normal=0.45, factor=1.5):
    # Infinite slope with saturated parallel seepage. Thickness is NORMAL to slope.
    por = 1 - rho_d / rho_s
    gamma = (rho_d + por * 1000) * G
    phi = math.radians(phi_deg)
    shear = gamma * thickness_normal * math.sin(BETA)
    effective_normal = (gamma - 1000 * G) * thickness_normal * math.cos(BETA)
    required = max(0.0, factor * shear - effective_normal * math.tan(phi))
    return {"phi_deg_assumed": phi_deg, "porosity": por,
            "cohesion_required_kPa_normal_450mm": required / 1000,
            "cohesion_kPa_if_450mm_is_vertical": required * math.cos(BETA) / 1000}
