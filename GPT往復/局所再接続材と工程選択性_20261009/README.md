## 再実行

Python 3の標準ライブラリで python calculate.py を実行する。JSONと4 CSVを生成する。図はMatplotlibを利用し python draw.py。スクリプトは通常インストールまたは資料倉庫直下の一時的な .deps を利用できる。依存ライブラリ自体は公開しない。

## 仮定の位置付け

- 物理試験0件、成功確率null。数式照合は実物検証ではない。
- 接点モデルは第63巡の粒径・充填・配位数とRumpf型数量式を明示的に再記述。Claudeサーバーのwf3コードを実行したものではない。
- qは有効接点の割合、σは完成接点の強度の未知量。文献バルク強度を代入していない。σとqの関係・分布・連結性は未知。
- 粒は球換算。開放枝・回転・摩耗・混合・空間連結性・雪の切削・実摩擦は未計算。a/Dの0.1は任意の適用域注意線。逸脱行は計算表に残し、製造可能とはしない。
- 全面膜は薄膜近似。支持骨格の嵩密度は独立仮定。H64-M粒内部材の設計荷重は未計算。
- 修復状態hの指数式は反証用の仮式。原著へのフィッティング・材料速度予測・成功率ではない。5時間継続する不要接触がない場合、その速度比を要求しない。
- 発酵液量は累積換算であり、槽容量・製造日数ではない。価格・加工能力・材料寿命・比熱・密度は未確認の比較入力。
- 熱量は顕熱だけ。現場の水・蒸発・熱損失・450mm全深度の温度分布・機械能力・税等を含めない。
- 雨水濃度は仮の物質収支。実際の放出率、BOD/COD、安全性、排水規制とは別。
