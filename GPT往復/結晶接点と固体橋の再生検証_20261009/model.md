# 計算モデルと再現方法

    python calculate.py
    python draw.py
    python audit.py

calculate.py はPython 3標準ライブラリだけで再生成可能。draw.py のみ matplotlib を要する。一時的な .deps が存在する場合は利用するが、依存ライブラリの複製を成果には含めない。

## 1. 等方的な接点網の上限から逆算

粒包絡の体積Vp=πD³/6、粒数密度np=φ/Vp、共有接点密度nc=np z/2。中心力による応力テンソル σij=nc F D <ni nj> の等方平均 <nx²>=1/3を用いる。全接点が限界力Fに達する楽観側の法線応力尺度に、追加の荷重効率εを掛ける。

    σ*=ε nc D σb πa²/3
    M=nc V πa² l ρb=3ρb V σ* l/(ε D σb)

これは実床の一軸引張強度・剪断強度の解ではない。局所的な破壊、異方性、凝集のむら、ばらばらの粒、接続網の未形成は含まない。名目5 kPaは測定対象を決めるための設計値。σbは形状や内部空隙も含む有効接点強度で、鉱物単結晶の強度や成形塊の圧縮強度ではない。

接点数を変えると一接点の半径は変わるが、一定の応力を得る必要質量はこの式では同じになる。これは単純模型の性質であり、接点数が実強度に影響しないという結論にはしない。

比較の球形粒は、前巡の角形粒・梁構造と別物。数と体積を独立に計算した。半径が粒径の10％を超える場合はgeometry_warningを記録する。この目安は機械的な保証ではない。

## 2. 破壊の仕事

Gcは両面形成などを含んだ、投影亀裂面積当たりの破壊エネルギーと定義する。同じ二面をもう一度掛けない。

    w=nc Gc πa²=3σ*Gc/(ε D σb)
    δc=2Gc/σb （三角形の局所凝集則に置いた開離変位）

Gc、σbとも未測定。δcは一つの首の変位であり、エッジの解放距離ではない。摩擦・粒内変形・粒群流動は別に必要。

## 3. 供給、水、乾燥

有効率ηは供給固体換算量のうち、実際に有効な接点として組み込まれる割合。反応・輸送・位置の選択性などを含む。確率でも材料安全率でもない。

    Mfeed=f M/η
    Vsolution=Mfeed/(CMg MM_NQ)
    Wslurry=Mfeed (1-c)/c
    Wevap,max=q A t/Lv

cは質量分率で、体積分率ではない。溶液をほぼ水1 kg/Lとみなす近似であり、厳密な溶液密度・反応による結晶水収支・イオン平衡を解いていない。溶液経路には残水率を独立に与え、全量蒸発を必須としない。懸濁液経路の名目計算は排水による減量を見込まず全キャリア水を計上する。

40分・100 W/m²という入力から200 kgの蒸発相当量を得る。風・湿度・水の拡散・境膜・降雨・蒸発冷却・化学反応・首の形成時間を含まず、エネルギーだけの必要条件。採用した100 W/m²が現場で利用できることも未確認。

同密度・同強度・同ηの比較を別に記録し、密度変更の効果と供給方法の効果を分離する。

## 4. 均一塗布の反例

粒表面中の接点足跡の面積比 fA=z a²/D²。毛管流などによる再分配がなく、全面へ均一に厚みl/2を供給する基準模型では、接点へ入る割合をこの面積比と置く。実工程の最大値・下限値・測定値ではない。影・表面濡れ・接点隙間・流れにより実際の値は変わる。

    M/fA = N πD² (l/2) ρb

濡れがあるだけでη=25％を保証しないため、この基準との違いを画像と物量で測る。

## 5. 破片の在庫と費用

毎回fMの旧首が壊れ、Mfeed-fMの新しい接点外材料が生じる。活動中の首を元の量へ戻す条件では、破片の生成は合計g=Mfeed。回収前の破片在庫Bn+gの割合rを回収する。

    B(n+1)=(1-r)(Bn+g)
    cumulative_feed = cumulative_collected + remaining_debris

初回の本体・首の製造を除く再生の収支。回収した割合ξを再利用できる場合の純新規原料下限も記録するが、回収・再使用は未実証。廃棄・流出先のモデルではなく、環境排出量を計算していない。選別に健全な粒が一緒に失われる効果も未計上。

26件の照合はこの模型内の体積、共有接点、式の消去、供給比較、蒸発量、回収在庫、元素収支を検査する。材料適合、成功率90％、実運用を確認した件数ではない。
