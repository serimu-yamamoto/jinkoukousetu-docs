# 計算の定義と工程仮説 H95

[入力](inputs.json) → [標準ライブラリの計算](reproduce.py) → [結果](results.json)。Pythonで reproduce.py を実行する。--check は結果を書き換えず再現一致を検査する。金額は税別の感度仮定、見積書ではない。

## 1. 原表の分母監査

S1の終点変位を未処理v、架橋cとする。

- 未処理からの減少率 = (v-c)/v。
- 原表Differenceに一致する計算 = (v-c)/c。
- 終点変位÷20mmはその時点の全ひずみ。初期弾性変形を差し引いたクリープ増分や、除荷後の永久ひずみではない。
- 室温26.58％、50℃36.51％、60℃45.31％の減少。元表の36.2/57.5/82.8％を「未処理比減少率」にしない。
- 8MPaの圧縮試片を微細枝の曲げ、粒床、摩擦、4時間保持に換算しない。時間記載に不整合があり、時間則のフィッティングはしていない。

## 2. 工程順序と同一製品質量の収支

完成品M、切抜歩留まりy、架橋前端材の同一グレードへの再利用率r、原料単価p、照射委託単価q。

総切抜処理量G=M/y、端材S=G-M、再利用rS。
先に全シートを架橋する工程Aでは、同じ製品へ通常の溶融再利用ができない仮定で新品原料G、照射量G。
未架橋で切り抜き端材を分離し、その後良品だけ架橋する工程Bでは新品原料G-rS、照射量M。
Bの差額余地 = rSp + Sq。端材の他用途売却価値、再溶融・乾燥・選別費、搬送保持費、品質検査、歩留まり変化、初期・終期在庫は入っていない。

rは劣化なく永久に循環できるとの意味ではない。同一配合・結晶化履歴・枝寸法・異物・分子量を再検査して合格した割合という仮定。長期定常収支であり、初回には循環中の追加仕掛在庫が要る。Aでも微粉充填材等への回収価値があれば差額は縮まる。「架橋材は一切リサイクル不能」とは言っていない。

比較は同じ合格完成品が得られることを前提にする。工程順序が変わって枝の形や架橋度が不均一になる場合、この費用差だけではBを採用できない。

## 3. エネルギーと搬送

吸収エネルギー[kWh]=M[kg]×D[kGy]/3600。1Gy=1J/kg。
電力量の仮推定=吸収エネルギー/総合効率η。料金はさらに仮30円/kWhを掛ける。
加速器定格200kWに全量吸収を仮定した最短照射時間はエネルギー/200。これは物理下限で、保証処理速度ではない。

シート密度ρ、厚さt、幅w、速度v[m/min]、層数nでは、良品搬送量[kg/h]=ρtwv×60×n×y。
厚さ120µm・密度930kg/m³は比較の仮値で、S2のHDPE密度952kg/m³や試片厚さ0.6mmと混同しない。積層・高速化の線量均一性、枝の潰れ、搬送滑り、保持治具による遮蔽は未検証。

## 4. 構造と製造の具体案

1. 単一PEグレードをシート成形し、枝・丸みを持つ根元・開放した粒間空隙を一体で作る。既存の緻密薄枝案を対照とし、平板断片だけでは層状密着するため立体化を比較する。
2. 未架橋状態で切抜・端材分離。薄枝は再使用できる機械式キャリアで姿勢を保持する。接着剤・離型油を必要条件にしない。
3. 工場の受託設備で照射。必要線量は未決定。熱・酸素・線量・保管時間・後処理で結果が変わるので実加工記録を残す。
4. 取り外し・分級・洗浄残留の確認・包装。架橋後に切削する予備案も残すが、端材と切断損傷を費用に戻す。
5. 現場整地は粒配置の復旧。切れた共有結合や破断枝を60分で溶接し直す仕組みではない。摩耗片は分級除去・補給する。

異材接合の課題を、線量均一性・結晶状態・疲労・キャリア搬送の課題に置き換えた仮説。特許的新規性や量産可能性は判定していない。

## 5. 10年の補給感度

初期135tを一定に維持し、年1/5/10％を回収・交換する仮定。交換量はM×年交換率×10年。回収再利用の控除なし、割引なし、数量増減なし。原料500円/kg＋照射150円/kgだけで算出する。切抜・運送・回収・分析・処分費を追加して比較する。交換率は測定していないため耐用年数や流出率の予測ではない。
