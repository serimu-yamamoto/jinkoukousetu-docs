## 解釈で守る境界

- 300mmの出力は比較厚さ。削れ代300mmを施工厚300mmへ変更していない。主な数量説明は45cm。
- 120kg/m³は全枝を比べる仮密度。目標粒を製造・充填した実測ではない。
- 空気50℃の行は取出60℃。取出50℃の達成例へ混ぜない。
- 冷却時の潜熱を融解値に等置し、比熱等も仮定している。熱模型時間は核生成・固化・粒形状の完成時間ではない。
- スラリー80wt%は水量感度。送液・噴霧・反応速度が可能というラベルではない。
- 平衡溶解容量は降雨時の実際の溶解量ではない。凍結点の尺度は25℃濃度を仮入力しただけで冬季判定に使わない。
- design_limits.jsonの接点乾燥費は電力蒸発という仮の別シナリオ。反応熱、排水回収、自然乾燥、装置費・分級・運送・残渣処理は別に必要。
- 数値照合の件数は実験数・試行成功率ではない。

## 雨量の面積基準

主模型の rain_mm は「供給水量÷床面積」をmmで表した等価通水深として読む。気象観測の鉛直雨量から換算する場合、風・上流流入・遮蔽がなければ、等価通水深＝鉛直雨量×cos(斜度)。[補足コード](rain_basis.mjs)を Node.js で node rain_basis.mjs と実行すると[4傾斜の換算表](rain_basis.json)を再計算する。床面積2,000㎡、25℃の濃度尺度2.617kg/m³、鉛直雨量100mmという固定例の幾何計算であり、暴風雨の実流入量や溶解速度の予測ではない。
