# Claude監査：Gemini「v2.3/v3.0 段階②修正と仮想試験」（2026-10-23）

**総評**：第1部（指摘への修正）はおおむね良い。第2部の「v2.2は不合格」という結論は、私の監査と同じ。しかし第3部のv3.0は、撤回したはずの**数値寄せが再発**しており、物理の誤りと無害要件への違反を含む。段階②では、v3.0を「試す候補の一つ」として扱い、予測値はすべて仮説に戻すこと。

## 第1部（修正）
- 再生量の算術訂正、組成ドリフトの閉鎖表（再計算で一致）、R05による15℃冷風の撤回、JGS 0142への準拠、粒径0.8mmへの是正は妥当。
- **R39**：せん断キーの上端430mmは、余裕150mmで決めた450mmの線より20mm浅い。キーも450mmより下に置くこと。
- 組成の閉鎖は「成分の量」の一致にすぎない。繊維の短縮、架橋状態、微生物による劣化といった性質の変化（劣化ドリフト）は閉じていない。

## 第2部（v2.2の仮想試験）
- 結論（ゲル化しない、潰れる、再結合しない、摩擦が大きい）は妥当。ただし、σy＝37.7kPa、c＝3.2kPa、μ＞0.25 などは、模型の式と入力が示されていないため、検算できない。定性的な判断として扱う。

## 第3部（v3.0）の問題
1. **数値寄せの再発**：c(30分)＝41.4〜42.5kPa、S_f＝77.8〜78.3kPa、μ＝0.047、σy＝420kPa、ψm＝61〜73kPa、τ＝11.5〜20分。どれも目標に一致しているが、計算の入力が開示されていない。実測0件の段階で「再現される」と断定している。
2. **ネックが乾くという仕組みは、物理の向きが逆**：毛管では、最も狭い隙間が最後まで水を保つ。吸引力70kPaに釣り合う水の曲率半径は約2µm（2γ/ψ）であり、粒子どうしの接点（サブミクロンの隙間）には液橋が残る。コアの細孔が接点の隙間より小さくない限り、接点は乾かない。また、コアの細孔を0.5〜2µmとすると、70kPaではほぼ水で満たされ、飽和度68%の前提とも合わない。
   - ただし、不飽和土で知られている「吸引力による見かけの粘着力」は実在する仕組みなので、この方向で測る価値はある（雨では消える点に注意）。
3. **防カビ剤が無害の必須要件に反する恐れ**：酸化亜鉛は、EU CLPで水生環境有害性の急性1・慢性1（H400/H410）に分類されている（複数のSDSで確認。附属書VIの原文は未確認）。銀を担持した抗菌剤も、水生生物への毒性で規制の対象になる。床全体2,191.5tの0.15%は約3.3tにあたり、雨で河川へ流れる。
4. **規制の確実化は言い過ぎ**：アルギン酸のNa塩からCa塩への置換やペクチンが、マイクロプラスチック規制の「化学修飾」に当たらないかは、ECHAの指針での確認が必要（現段階では「確実」とは言えない）。
5. **冬の融雪基準**：クエン酸Naなど水に溶ける塩が雨や融雪で溶け出すと、凝固点降下が0.01K以下という基準を満たすかの確認が必要。
6. **再造粒と矛盾**：一度架橋したアルギン酸Caは、常温で練り直して再び結合することがない。回収した微粉を常温で再造粒する工程が成り立つかは未検討。
7. **凍結融解**：「32%の気孔が膨張を完全に吸収する」という主張は、気泡の間隔などの根拠がない。試験の項目として扱う。

## 段階②への勧告
- v2.2・水分低減系列・v3.0の並行比較という骨格は妥当。v3.0の予測値は目標値としてだけ記載する。
- 防カビ剤は、無害な方法に置き換えるか、まず無添加で14日試験を行って要否を判断する。
- ネックが形成される仕組みを直接見る試験（接点の水分分布と強度を時間ごとに測る）を、Gate 2-Cに加える。
