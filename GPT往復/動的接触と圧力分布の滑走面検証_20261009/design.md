# H71-Pの設計案と分岐

H71-Pは、接触面の平均圧力/最大圧力の比を大きくする先端と、低い界面せん断抵抗を持つ相を組み合わせる未試作案。圧力分布を実現した結果ではない。特許上の新規性も未確認。

~~~mermaid
flowchart TD
 A[通常のスキー用UHMWPEソール] --> B[丸い縁と摩耗余裕を持つ粒の接触面]
 B --> C[先端の裏側を複数位置で支える一体骨格]
 C --> D[低荷重の退避と高荷重の支持を分ける粒内部]
 D --> E[短く解放し再接続する粒間接点]
 C --> F[貫通排水と冬の雪が入る開放空間]
 E --> G[雨後の回収・選別・整地]
 G --> B
 B --> H[圧力分布と材料せん断抵抗を同時に測る]
 H --> I[過大な局所圧・振動・摩耗なら別材料または結晶経路へ]
~~~

| 部位 | 最初の比較寸法・構成（未最適化） | 必要な検証 |
|---|---|---|
| 開放粒 | 代表寸法約0.5mm、6方向に先端候補。実粒群で同時に6点が接触するとはしない | 回転・傾き・粒の押しのけ・300mm掘れ後 |
| 接触皮 | 径50/100/200µm、厚さ10µmを数量比較。摩耗後も同じ接触相を露出する構成 | 材料則τ0,b、面積、微粉、接合剥離 |
| 裏側支持 | 先端を中央一点だけで押さず、同一骨格から複数箇所で受ける。第70巡の一体成形と組合せ | 平坦化が縁の圧力集中・座屈・反転を生まないか。形状の自由度を増やす前に有限要素で片当たりを反証 |
| 開放路 | 先端の周囲から根元へ連続する空間。密閉空気室・濡れて接着する積層を前提にしない | 液橋による固着、泥の目詰まり、排水、凍結・融解 |
| 接続 | 第57/65/70巡の支持・解放機能と接続。滑走面そのものを固定マットへ結ばない | エッジの支えと解放、整地時だけの再接続、全深度の同機能 |

β=0.8を目指すことと達成済みであることを区別する。肉厚・材質・支持位置を決める前に、乾湿50℃での弾性/粘弾性と接触則が必要。薄く柔らかくすれば均されるとは限らない。

## 比較を続ける四経路

1. **H71-P：圧力分布と材料の同時設計。** 優先比較。低摩擦材を全体へ混ぜるだけでなく、実際の荷重面へ連続して出るかを第67巡の相配置と接続する。
2. **H71-D：接触が入れ替わる受動構造。** 荷重一定・局所圧上限・全エネルギー・雪らしい振動を満たす場合に残す。指定横振動の診断をそのまま実機方式にしない。
3. **H71-M：簡単な丸い先端＋別の接触材料。** β改善費が高い、傾きで効果が消える、摩耗で形が失われる場合は形状を単純化して材料へ戻る。
4. **H68-A等：暖気中の噴霧晶析と保持された結晶。** 屋外30℃以上・無荷重50℃で形成/維持する証拠が必要。工場内の捲縮・内部の結晶化を暖気中の雪状結晶形成と数えない。

雨後に位置だけ戻っても接触相が削れていれば復元していない。レール整地の60分は、機能を保った粒の配材・密度・接続回復に対する運用目標。大量の台風回収や材料再製造の保証時間に拡張しない。
