# 第71巡 計算模型と適用限界

## 1. 接触数と圧力

同じ半径・弾性率の球状先端が、一定の全法線荷重Wを等分するHertz接触を考える。N個からdN個へ減らすと、各荷重は1/d倍、接触半径はd^(-1/3)倍、各面積はd^(-2/3)倍、総面積はd^(1/3)倍、最大圧力はd^(-1/3)倍になる。dは接触率で、成功確率ではない。粒の変形、塑性、接触面同士の干渉は含めない。

界面の抵抗則を τ=τ0+b p と仮定すると、F=τ0 A+bW。したがって、

~~~text
μ(d) = b + [μ(1)-b] d^(1/3)
p_peak(d) = p_peak(1) d^(-1/3)
[μ(d)-b] p_peak(d) = [μ(1)-b] p_peak(1)
~~~

これは横振動・速度依存を含まない準静的な幾何比較。S1の全動力学を再現した式ではない。接点が時間的に交代する場合も、全荷重を一定に保つ等分担の各瞬間に限って適用できる。同期した全接点の跳躍はW一定を破り、支持・振動の別問題になる。純Coulomb則ならF=μcWで接点数だけを変えても低下しない。

## 2. 圧力分布の逆算

β=p_mean/p_peakと定義すると、総実接触面積A=W/(β p_peak)、μ=b+τ0/(β p_peak)。Hertzではβ=2/3。軸対称の目標圧力 p(r)=p_peak[1-(r/a)^m] は、積分からβ=m/(m+2)。m=8なら0.8、m=16なら8/9。一様圧力ではβ=1。p(r)は目標の圧力分布であり、同じ式の表面形状を成形すれば実現するという意味ではない。

同じp_peakを超えない接触では、一般にもW≤p_peak Aなので、μ≥b+τ0/p_peak。この模型でHertzから形状だけを理想的に変えても、面積比例成分の削減は最大1/3。平坦な剛体パンチを弾性半無限体へ押せば縁へ圧力が集中するため、平らに削るだけでは一様圧力にならない。有限厚さ・支持位置・傾き・粗さ・粘弾性を含む接触解析が次段階。

材料に必要な値は、総摩擦の目標μTと粒変形等の正味抵抗μotherを分けて、τ0≤(μT-b-μother)β p_peak。右辺≤0なら正のτ0に余地がない。接触則は実ソールで同定する必要があり、模型入力を材料の実測係数へ読み替えない。

## 3. 横運動のエネルギー

剛板速度V、先端x速度0、先端y=A sin(2πft)、法線荷重一定、速度に依存しないCoulomb摩擦を仮定する。q=2πfA/V、c=cos(2πft)とすると、周期平均は

~~~text
g(q)=mean[1/sqrt(1+q²c²)]
h(q)=mean[sqrt(1+q²c²)]
板の前進仕事率 / (μc W V) = g
全散逸率 / (μc W V) = h
横方向から必要な平均仕事率 / (μc W V) = h-g
~~~

h-g≥0。横方向の仕事を無視すると、前進抵抗の低下をエネルギーの節約と誤認する。これは外部から指定した正弦運動の診断であって、S1の受動的な自励運動を否定する証明ではない。受動構造を検証する場合はx方向運動・法線仕事・接離・弾性エネルギー・減衰をすべて閉じる必要がある。

一定速度・1回だけの追従では、先端が進める距離sと板長Lに対しs/Lが追従による距離削減比。s=100µm、L=1.5mなら1/15000。往復リセット、転動、接離を含む一般的な摩擦低減の上限ではない。

## 4. 原著の式の監査

S1のHTMLとPDF抽出テキストでは、式(17)の分母がr²、本文ではr²=x²+y²+z²、s²=x²+y²と定義されている。一方θ=atan2(y,x)の微分は (x vy-y vx)/s²。x=1,y=0,z=2,vx=0,vy=1の反例では、正しい幾何微分1に対し掲載式は0.2。有限差分で独立照合した。

これは公開記載の整合性に関する照会点。原著PDFの数式画像は今回ツールで取得できず、著者コードも未確認。印刷誤記か計算へ影響するかは不明であり、論文の結果全体が誤りとは断定しない。本巡は式(17)を計算に使用せず、原著の再現成功とも記載しない。

## 5. 数値と費用

周期積分は中点則の周期平均。8192/16384分割の収束、別計算の横方向仕事と前進仕事の和、逆算目標値を照合する。形状圧力積分は解析式と10万分割を比較する。これらは数値演算の照合で物理的妥当性の校正ではない。

全深度の仮粒数3.117691×10^12、6面/粒、円形接触皮、厚さ10µm、密度950kg/m³。面積×厚さ×密度で追加皮の質量を算定する。仮単価は材料500/2000円kg、成形10/100円m²（税抜の比較入力）。面積は機能面そのものの面積で、ウェブの余白・歩留まり・接合・工具・検査・支持部・廃棄費を含まない。六面の立体加工をこの単価で実施できる証拠はない。既存先端と一体化できる場合は置換分を別途引く。
