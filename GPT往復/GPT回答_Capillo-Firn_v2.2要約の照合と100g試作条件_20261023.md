## 2. 「数値寄せ」の確認できた事実と、未確認の作業履歴

確認できた問題は、未測定のc=42kPa、φ=36°、δf=10µm等の代入結果から、雪の感触や支持を保証する文章へ飛躍したことである。v2.1の第4章では目標・実測対象と明記しながら、第5章ではエッジが抜けない、雪煙の条件を満たすと断定していた。

一方、SfやGfを先に置いてどの順番でc・φ・δfを決めたかという内部作業の順序は、今回の自己申告だけでは独立に確認できない。過去に付したという具体的な主観成功確率の原文・版も未提示である。監査済みv2.1自体は実物0・確率未算定と記している。意図や未提示の過去記録まで確定したとは報告しない。

次の3種類を分ける。

1. **定義・収支**：質量を体積で割る密度、各相の体積の和。ただし入力と体積加成の条件を示す。
2. **物理モデルの条件付き計算**：Mohr–Coulomb、線形軟化、Darcy近似。モデルが材料に適用できるか自体を試験する。
3. **当該試料の観測値**：温度・含水率・履歴・速度・測定法・不確かさを伴う実測。現時点で該当なし。

Sf=78.33kPa、Gf≈0.39J/m²は再計算できるが、物理モデルを材料と無関係な「恒等式」として性能保証することはできない。目標値の明示は改善であり、成立証拠の追加とは区別する。

## 3. 密度計算は概ね整合。ただし13.47％の名称を直す

全配合が未提示のため、固形分真体積21.3025cm³は再導出せず、提供された仮入力として使用した。水密度1g/cm³、体積加成、100g中水52gを仮定する。

| 量 | 条件付き計算値 |
|---|---:|
| 固形分＋水の体積 | 73.3025cm³ |
| 気体を含めない湿潤基質の密度 | 1,364.210kg/m³ |
| 目標ρp=1,180.40から必要となる包絡体積 | 84.717045cm³ |
| 粒内気体体積 | 11.414545cm³ |
| 粒内の気体体積割合 | **13.473729％** |
| 全ての水を孔隙水と数える場合の粒内総空隙率 | **74.854529％** |
| 同じ仮定の水飽和度 | 82.000115％ |
| 目標ρb=487との比から必要となる粒子充填率 | 41.257201％ |
| 粒子間空隙率 | 58.742799％ |

**13.47％は気体の割合であり、水を含む総空隙率とは違う。** 水を連続した含水基質の構成成分として扱う定義なら、13.47％を「含水基質に対する粒内気泡率」と呼ぶことはできる。結合水と自由水の区分も未測定なので、74.85％を実測空隙率として報告してはいけない。

また、ρb/ρpから充填率を求めただけでは空隙を独立に検証していない。粒の包絡体積と、一定の圧雪履歴後の床体積を別々に測定する必要がある。真密度・骨格密度・包絡密度は異なる量で、開孔・閉孔の測定上の扱いも異なる。[測定機器メーカーによる定義](https://micromeritics.com/density/)

星型の凹部を包絡体積に含めるか、隣の枝が入り込める空間とするかも先に定義する。包絡体積の取り方が違えば「粒内」と「粒間」の配分も変わる。水浸で吸水・溶出・膨潤した体積や、乾燥で収縮した体積を、そのまま営業時の湿潤粒体積に置き換えない。

## 4. 750kg/hなら解消する場合と、まだ不足する場合

前回の床2,191.5t、微粉化60％、その80％を再生する基準なら、必要合格再生粒は1,051.92t/年。750kg/h×8h×220日=1,320t/年であり、**750kg/hが合格完成粒の出力なら必要稼働率は79.69％以上**である。

| 750kg/hの解釈と仮条件 | 合格品量 | 必要量との差 |
|---|---:|---:|
| 合格完成粒出力、稼働率85％ | 1,122t/年 | +70.08t |
| 投入量等、稼働率85％、総合合格収率95％ | 1,065.9t/年 | +13.98t |
| 投入量等、稼働率85％、総合合格収率80％ | 897.6t/年 | **−154.32t** |

入力又は未選別製品の750kg/hなら、稼働率85％で総合合格収率93.75％以上が必要。芯と外皮を作り直し、乾湿後も性能を満たす粒だけを合格品に数える。名目の押出速度を、そのまま有効再生能力にしない。

なお1,051.9tは、旧モデルでは「摩耗発生量」ではなく「回収する80％分」である。発生は1,314.9tだった。要約の表現が摩耗率そのものを60％→48％に変更する意味なら、回収量と補充費も変わる。測定なしで発生量を減らしたことにせず、発生・回収・合格再生・未回収を別行にする。

## 5. 10m暗渠と費用の修正は条件付き

原式h=IL/(k sin30°)では、k=0.0025m/s・間隔10mのとき、100mm/hで222.22mm、**150mm/hなら333.33mm**となる。222.2mm以下という説明には降雨条件の明示が必要である。

kが0.001m/sまで低下すると100mm/hでも555.56mmとなり、450mm床の定常排水能力が不足する。10m間隔を採れば常に安全という計算ではない。粒床・フィルター・排水ネット・管・出口の能力、閉塞と界面すべりは前回指摘どおり別に確認する。

CAPEXの増額は3,697.5万円、OPEXの増額は年500万円だが、750kg/h二層共押出、増えた暗渠、再被覆原料、動力、人員、清掃・停止・処分等が明細に反映されたか未確認。設備・土木・材料・税の予算範囲も未確定のままであり、総額だけで採算修正済みとは判定しない。

## 7. 実物試験へ進んでよいか
