# 重合時の結晶網と密度履歴：第29巡の再計算

[本文](../GPT回答_多方向探索第29巡_重合時の結晶網と密度履歴の設計_20261008.md)

物理試験0件、実物成功確率null。材料の構成則・DEM・摩擦予測を解いたものではなく、密度が異なる場合の質量・体積・費用収支を比較する。

## ファイル

- inputs.json：出典由来の観察値と、仮の比較条件・未測定の感度変数。
- calculate.py：Python標準ライブラリで再計算。16密度・24敷設・60構造保持・18補充・18予算逆算・16輸送・8汚れ交換の収支ケース。
- results.json：計算結果。ケース数は物理的な試行数・成功数ではない。
- validation.json：19件の数値整合確認。Decimalによる独立漸化計算、保存則、極限、輸送便数の最小性等。材料モデルの妥当性を保証しない。
- plot.py／figure1_density_inventory.png／figure2_structure_retention.png：2図。英語の軸・凡例と本文の日本語説明を対応させる。
- sources.md：一次資料8件、閲覧範囲と適用限界。
- publication-manifest.json：本巡の本文・入口更新・成果ファイルのバイト数とSHA256。自分自身のハッシュは含めない。

## 再計算

このフォルダで以下を実行する。WindowsではPythonへのパスは環境に合わせる。

~~~text
python calculate.py
python plot.py
~~~

計算はPython標準ライブラリのみ。作図はmatplotlibを使用し、今回3.11.2で生成した。作業用依存物はGitへ保存していない。plot.pyはリポジトリ直下の.depsがあれば参照し、なければ環境内のmatplotlibを使う。

## 読み間違えないための条件

120 kg/m³、450 mm、500円/kg、年200回、年間補充材料費1,000万円、積載10t・50m³、便単価10万円は比較仮定。規格値・購入見積り・運用合意ではない。整地設備の税込2億円枠は材料と造成の別枠として維持する。

構造保持モデルは、形態の異なる部分の見掛け体積を単純加算した参照計算。混合体の入り込みや再膨張を予測しない。qは未損傷部分が1回で構造を失う仮の割合で、摩耗粉の放出率ではない。補充モデルは毎回その不良分を除き同質量の良品を足す別の運用仮定である。

輸送計算は同じ完成床に必要な質量を運ぶ比較で、450kg/m³へ圧縮しても現地で低密度へ戻せると保証していない。着荷価格として500円/kgを置いた材料表と、独立した仮運賃を二重加算しない。
