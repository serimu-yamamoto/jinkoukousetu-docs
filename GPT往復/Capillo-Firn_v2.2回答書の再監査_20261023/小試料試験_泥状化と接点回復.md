# 小試料試験：泥状化と接点回復を別々に判定する
2026-10-23。実物0件。これは試験設計案であり、未指定の製造条件を補完したレシピではない。

[今回の監査](../GPT回答_Capillo-Firn_v2.2回答書の再監査と接点回復の試験設計_20261023.md)と[前回の測定計画](../Capillo-Firn_v2.2要約の監査_20261023/段階②_100g級試作の測定計画_条件付き.md)を併用する。100g全配合の未受領は解消したが、工程仕様の未確定は残る。

## 0. 製造開始前に埋める欄
成分ごとの乾燥質量と実秤量、原料の固形分・持込水、鉱物と各高分子の芯／外皮への配分、pH、Ca形態・量、混合順、温度・時間、脱水量、成形圧・流量比、切断と端面処理、最終粒径・含水率、熟成条件。
不明欄に、過去版の条件や文献の別配合を自動転記しない。CNF4.5g・MCC2.5g以外の配置は今回も未指定。完成品100gと仕込原料100gを区別する。

## 1. まず外皮の接合を調べる
外皮組成・作り方を固定した後、粒全体を大量に作る前に外皮候補の小片で検証する。芯用のCNFを混ぜた試料と取り違えない。

- 未破断の同寸法小片、切断して接触させた小片、接触だけで圧縮しない小片を比較する。切断面と、製造したままの外表面の接合も区別する。
- 30℃と50℃で含水状態を記録・維持し、一定の面積に50kPaを10秒載荷して除荷。その後0／5／15／30／60分の**別の試片**を破断測定する。待機中の圧力は明記し、無荷重と持続載荷の結果を混ぜない。
- 接合部の局所変位、力、破壊面積、残留抵抗、破壊位置を記録する。接合部より母材が先に壊れた場合は、接合強度の直接測定値としない。
- 自然乾燥で含水率が下がり強くなった結果を、湿潤状態でのイオン再架橋の証拠にしない。密閉又は湿度管理条件と開放条件を分ける。
- 小片の接合は床の78.33kPaを直接判定する試験ではない。接触面積・粒数・応力方向が違うため、粒床試験へ進む前の機構スクリーニングに使う。

判定：湿潤小片が接合しない場合は、当該外皮・製法・接触条件の再接合仮説が支持されない。乾燥でのみ接合する場合は、再開時間・内部保水との両立を別に扱う。接合しても長く伸びる場合は、自己修復と脆性破断を同時達成したとはしない。

## 2. 単粒と粒床の形状保持を調べる
同じ配合100g級を製法確認の単位とする。最初の試料で工程残留・採取量を測り、後続試験に必要な独立バッチ量を決める。100g一つで全試験を行えるとは仮定しない。

1. 成形直後の独立粒率、凝集塊、粒径、枝、殻・芯、切断端面、離水を記録。
2. 30／50℃の試料を既知の面積と荷重で圧縮・除荷し、粒の不可逆変形と合体を観察。床への50kPaを単粒接触部の50kPaに読み替えない。
3. 同じ手順で充填した床の質量・体積を、圧縮前・圧縮中・除荷後・待機後に測る。湿潤粒の包絡体積は別途測定する。
4. 圧縮・破断・再整地後の微粉率と排水挙動を測る。形のよい粒だけ選んで収率や密度を報告しない。

判定：独立粒が得られない、芯／外皮が形成されない、圧雪後に粒同士が連続ペーストへ合体する場合は、当該製法で要求構造を達成したという主張を棄却する。数値目標の許容幅と計測不確かさは測定前に定める。密度一致だけでは滑走性能は合格しない。

## 3. 粒床の30分回復と脆性を調べる
形状保持と小片接合の測定を踏まえて追加試料を作り、未破断床と、規定のせん断で壊して整地した床を比較する。

- 30／50℃、含水率と破断履歴を固定。0／5／15／30／60分後に垂直応力25／50／80kPaでピーク・残留せん断抵抗を取得する。試験は破壊的なので別供試体を割り当てる。
- Sf(50)の30分目標は78.33kPa。c・φは複数荷重の曲線がモデルに適合する場合だけ推定し、42kPa・36°を固定して計算を合わせない。排水条件・速度・間隙水圧の扱いを記録。
- 初期と回復後の破断変位・仕事も測る。強さだけ戻っても、延性化してエッジが抜けなくなる場合は目的未達。
- 局所10µmの破断を、試験機の全体変位から直接断定しない。計測系の変形を補正し、局所計測できない場合は未評価とする。
- 初期のばらつき把握には独立3バッチを提案する。反復数は統計的な成功確率や寿命保証を与えない。全条件を何個の供試体で評価するか、事前に試料量・試験時間へ展開する。

## 4. 観測から次の設計変更を選ぶ
| 観測 | 次に変更する対象 |
|---|---|
| 粒がつぶれるが小片は接合する | 芯の形状保持、殻厚、成形・熟成順序。水低減だけで決着させない |
| 粒は保つが小片が接合しない | 表面の官能基・Ca状態・露出・接触形成。コア増強は直接の対策にならない |
| 接合上限は高いが30分に間に合わない | 表面アクセス・接触条件・回復速度。60分待ちを30分合格にしない |
| 強度は戻るが粘り・長い破断変位が残る | 接点の大きさ・配置・破断機構。MCC長さだけを変位と同一視しない |
| 初期は成立し再生後に崩れる | 微粉の成分配置、外皮更新、合格収率、追加原料と処理費 |
| 複数の目的を同時に満たせない | 当該機構の限界を記録し、局所補修や別の接点機構を別版で比較 |

人による滑走はここに含めない。次段階は機械による摩擦・切削・摩耗、排水、溶出・粉塵・微生物、冬季界面を同じ配合IDで検証する。測定機器、試料、協力先はまだ確保されていない。
