# 幾何診断と費用計算の導出

本ファイルは人工粒の摩擦係数や成功率を予測しない。未知の材料係数を当てはめず、平均配合から微小接点への外挿に必要な条件を示す。一次資料と代表密度の扱いは sources.json を参照。

## 1. 重量比と体積比

UHMWPE重量割合を w、密度を ρu、PEEK密度をρpとする。気孔なし・体積加算を仮定すると、

~~~text
φ = (w/ρu) / [w/ρu + (1−w)/ρp]
ρmix = 1 / [w/ρu + (1−w)/ρp]
~~~

ρu=934、ρp=1300 kg/m³、w=0.02でφ=0.02762078783、ρmix=1289.890792kg/m³。後者の厳密出力は results.json に従う。S1の成形品の測定密度ではない。空隙・熱劣化・相の体積変化があれば置換する。

## 2. 円形接点が球状相に触れる確率

半径rの球の中心を三次元Poisson過程で配置し、球の合併集合を相とする。球の重なりを許すBoolean模型。強度nは単位体積あたりの中心数。球体積Vs=4πr³/3に対し、相体積率はφ=1−exp(−nVs)なのでn=−ln(1−φ)/Vs。

円形接点は平面内の半径aの円盤で、厚みゼロ。円盤に球が少しでも重なるための球中心の許容体積は、

~~~text
Vex = ∫[-r,r] π [a + sqrt(r²−z²)]² dz
    = 2πa²r + π²ar² + 4πr³/3
P_touch = 1 − exp(−n Vex)
~~~

球と円盤が接しているだけでは荷重も摩擦も定まらない。P_touchは「少なくとも一つ触れる」幾何統計で、実験成功率・接点の合格率・表面被覆率ではない。相が接点を押し上げる／凹む、偏析する、変形して広がる、移着する場合はこの模型外。

定常・均一なランダム断面では、円盤内の相面積割合の期待値はφ。P_touchがほぼ1でも、平均面積率は2.762％のままである。

同じφでrを下げる操作はnを増やす。原料粉の径をrへ代入して加工後の相分布を測定済みとしない。表面へ相が偏析する場合も別に測る。

## 3. 面積率のばらつき

円盤内の面積割合の分散は、相の二点共分散を円盤上で積分して求めた。

~~~text
sphere_overlap(d) = π(4r+d)(2r−d)²/12  (0≤d≤2r)
Cov(d) = exp{−n[2Vs−sphere_overlap(d)]} − exp(−2nVs)
disk_overlap(d) = 2a² acos(d/2a) − d sqrt(4a²−d²)/2
Var(area_fraction) = 2π/(πa²)² ∫[0,min(2a,2r)] Cov(d) disk_overlap(d) d dd
~~~

独立した数値積分は等間隔Simpson法を使用。10001点と20001点の収束を照合した。CSVの標準偏差はこの理想模型内の空間ばらつきであり、試験の標準誤差や測定ばらつきではない。正規分布を仮定して負の面積率を作る処理はしない。

## 4. 二種類の径と、巨視的な偏在

二種類の相は、総η=−ln(1−φ)を各球群のn_i Vs_iへ割り当てる。CSVのcoarse_shareはこの強度×体積の配分で、実材料の重なりなしの相体積分率と同義ではない。

~~~text
P_touch = 1 − exp(−Σ n_i Vex_i)
φ = 1 − exp(−Σ n_i Vs_i)
~~~

偏在の反例では、十分大きな領域のqだけに相を置き、領域内の相率をφ/qとした。領域境界を接点がまたぐ寄与を無視できる大きさと仮定。全体の相率はq(φ/q)=φ、全体の接触割合はq P_touch(φ/q)。よってqより大きくならない。これは実成形品の凝集率を推定したものではない。

95％の接触目標は幾何上の診断用。Vex/Vs=1+(3π/4)(a/r)+(3/2)(a/r)²を二次方程式として解く。2.612µmという相径境界は半径10µm・単分散・均一分布・代表密度に限る。

## 5. 面積だけによる摩擦混合の限界

荷重が面積に比例し、主相の摩擦μpが変わらず、副相μu=0という極端に有利な仮定を置いても、μmix=(1−φ)μp。減少の上限はφとなる。これは材料に関する法則ではなく、単純な面積混合仮説の帰結。この仮説を超える改善は、膜・荷重分担・主相自体の変化等を別に確かめる必要がある。実摩擦値をこの式で予測しない。

## 6. 加工費の境界

接触部体積V=2844.15/1270m³は第23巡の半径30µmの物量例を再利用した。M=Vρmix。全粒の形状・接合・追加重量を確定していない。

~~~text
CRF = i/[1−(1+i)^(-N)]
B0 = M C0 (CRF+r0)
Cmax = (B0−A)/(M[CRF+r0/g])
追加単価上限 = Cmax−C0
~~~

i=5％、N=10年、C0=6000円/kg、r0=年間交換20％。gは機能寿命倍率の仮定で、年間交換がr0/gへ下がるとの定常運用仮定を含む。Aは追加の年間品質管理費。初期投入量は同じで、機能寿命の改善が初期在庫を減らすとはしない。負の追加単価は、他の条件を維持するには原価削減が必要という意味。

価格は使用可能な接触材の加工込み・税抜仮単価。骨格への接合、粒化、回収、工場設備、全体造成、運転休業損失は除外。同じ部分費用の比較であり、事業採算ではない。歩留まりyに対し総投入M/y、使用不能M(1/y−1)。使用不能分の再生便益は置かない。

## 7. 再現

Python 3.12、NumPyとMatplotlibを使用。reproduce.pyを実行するとCSV、results.json、オリジナル2図を生成する。必要依存は requirements.txt に列記。実行環境でのRTK運用はリポジトリAGENTS.mdに従う。

23項目の照合は、独立断面積分、点接触極限、尺度不変、配合換算・密度、分散の上限と収束、分布の保存、費用・歩留まりの収支、未実施行の区別を含む。実際の形態や低摩擦の成立を検証した件数ではない。
