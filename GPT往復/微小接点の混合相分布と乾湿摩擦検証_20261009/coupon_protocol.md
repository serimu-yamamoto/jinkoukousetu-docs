# H67比較試料と未実施試験の仕様

状態：設計案のみ。製作・発注・購入・実験は実施していない。数値は選別用の暫定仕様で、製品保証値・人体安全閾値ではない。168行の計画表の観測値欄は空欄。

## 1. 比較試料

| ID | 試料 | 目的・製作条件 |
|---|---|---|
| M0 | 無充填UHMWPE | 同系材の対照。添加物・グレード・分子量・表面仕上げを記録 |
| M1 | 無充填polyetherimide（PEI） | 第23巡の異材対候補。polyethyleneimineと取り違えない。銘柄未確定 |
| M2 | 無充填PEEK | 混合・分散の効果の対照。M3〜M5と同じ母材ロットを基本とする |
| M3 | PEEK98／UHMWPE2重量％ | 基本加工の比較。原著と一致する銘柄・粒度を確認できない場合は再現試験を名乗らない |
| M4 | 同じ98／2、微細・均一相を目標 | 添加量を変えず最終相分布を変える。2µmは幾何診断の試作目標で、製作可能性と低摩擦は未確認 |
| M5 | 97／3、微細・均一相を目標 | 水潤滑抄録からの別濃度。乾湿を同一条件で比較 |
| M6 | 無充填POM-C | 加工・費用側の対照。充填剤・油・フッ素等を含まない仕様を確認 |

各候補は独立した製作3ロット。各試験へ新品の30×30×3mm平板を用意し、加工方向を刻印。厚さは治具側で全面支持し、段差・反りを測定する。摩擦面の仕上げを揃え、RaだけでなくSa、うねり、峰の曲率、加工方向を記録する。削り過ぎによって特定相が選択除去されていないか確認する。

PEEK系の工場加工には、温度・時間・圧力を記録できる高温プレス、必要に応じた制御混練、金型、換気、冷却、精密仕上げが必要。原著工程の温度条件だけを理由にPE相の成分・分子量が保存されたとはしない。粉砕・分散法の試作条件は、熱分析・レオロジー・原料SDS・装置仕様を確認してから設定する。未指定の相溶化剤を足して同じ処方として扱わない。

高温接触材と低温骨格の直接溶融接合は未成立。まず平板で接触相を選び、その後に量産可能な連続前駆材／一括形成と機械保持を比較する。兆単位の微小先端を個別に組付ける量産費は置かない。試験片の3mm厚や30mm幅は人工粒の寸法ではない。

## 2. 加工後の相分布を特定

表面・断面の化学マッピング（Raman/IR、必要に応じAFM等）でPE相とPEEK主相を区別する。光学分解能・画素寸法・識別誤差を先に記録し、目標相径より粗い観察で「2µm均一」とはしない。SEM形状像だけで同じ元素主体の樹脂相を確定しない。

表面と摩耗想定深さの少なくとも3層について、位置を決めた格子で観察する。各ロットの複数試験片・各片の中心と周辺を含める。D10/D50/D90、相率、凝集領域、相欠損領域の幅、空隙、表面偏析を記録する。相径だけで合格にせず、実測接点径の窓を走査した接点ごとの分布を保存する。窓の重なりを独立標本数へ数えない。

DSC・FTIR、必要なら分子量評価で加工前後を比較し、50℃での弾性・クリープ、引張／曲げ、界面の欠陥を測定する。微細化のための熱履歴で相が変化した場合は、粒径効果と化学変化を分離する。原料粉径を最終相径として登録しない。

## 3. 材料選別の第A・B段階

第AはM0〜M3の96組。第Bは材料形成と第Aを確認した上でM4〜M6を比較する条件付き72組。Aの平均だけでM1等の明瞭な不良状態を隠さず、Bへ進む理由を記載する。7材料の探索を全部実施したことにはしない。

同じ仕様のワックス未塗布UHMWPE実ソールから、平坦な直径8mm接触片を切り出して剛性の分かったホルダーへ固定する。表層厚さ、組成・グレード、研磨状態、元板とロットを記録。相手側も各試験で新品。元板ロットを材料群に偏らせない割付けとする。

- 温度：表面30℃と50℃。周囲30℃。接触近傍を計測し、空のステージ設定温度だけで合格としない。
- 公称圧：0.5MPa、8mm円で荷重約25.13N。これは選別用であり、微小接点の実圧や走行中の分布を代用しない。
- 滑り：0.5m/sで載荷滑り時間30分。移動距離900mを記録する。装置の往復反転を雪の動きとして解釈しない。
- 停止：載荷したまま5分保持し、再始動ピークと過渡を別保存。反転点・初回・停止直後を平均から削って良好に見せない。
- 記録：力・温度の時系列、摩擦の変動、両材の摩耗・粗さ、膜の成分、剥離片、摩耗粉の量と粒度。吸水補正の無載荷対照を別途置く。

各試験に30分滑り＋5分停止＋仮の段取り10分を配分すると、A72時間、B54時間。調湿、吸水対照、顕微鏡・化学分析、温度安定、機械校正、運搬、洗浄、破損再試験、作業員費は含まない。装置費・外注費は未見積り。

## 4. 水分状態は時間だけで決めない

| 状態 | 準備と記録 |
|---|---|
| 乾燥 | 30℃・記録した相対湿度で質量安定を確認。新品面から開始 |
| 薄い水膜 | 脱イオン水の初期量を面積当たり1µL/cm²（等価厚10µm）の比較条件として付与。液量、分布、50℃での蒸発を記録 |
| 排水後湿潤 | 30℃水へ24時間浸漬後、所定姿勢で10分排水を暫定手順とする。実際の残留水量と表面像を必須記録。時間だけで同じ濡れと判定しない |
| 再乾燥 | 同じ浸漬・排水後、30℃環境で質量変化を記録しながら乾燥。初期と同じ含水・形状へ戻ったかを測る。高温焼戻しを乾燥へ紛れ込ませない |

30分中に水膜が消える試験は乾湿遷移の履歴として扱う。一定水膜の結果とはしない。水を連続供給する別試験を行っても、屋外で常時散水を必要とする完成仕様には移さない。環境を維持できない場合は不成立／条件逸脱として記録する。

## 5. 次段階へ進む判断

暫定選別で比較するのは、各乾湿状態の初回・定常・再始動、双方の摩耗、膜の維持、化学状態。雪の実測基準と利用者が受容できる許容幅が未確定のため、この段階だけで絶対合格値を置かない。平均改善があっても雨後だけ急増する材料は、その欠点を次段階へ持ち越して明記する。

候補が残ったら、実接点径・圧力・速度・方向変化を揃えた微小接触試験、繰返し雨乾燥、UV、土砂、50℃クリープへ進む。小さい円盤がPE相に触れている画像と、その場所の摩擦を対応づける。接点の有無を摩擦測定の代用にしない。

粒化後は、厚い同一接触相の下に解放構造を設け、第65〜66巡の方向・再接続を実物で確認。新雪圧雪との比較、全深度の削れ、冬の雪の固着と排水、自然地面より追加融雪しないこと、台風回収後の機能回復を別評価する。未知の安全を人が滑って確認する段階へは進めず、まず無人の材料・荷重試験から得る。

## 6. 機構別の打切りと融合

- 微細化しても局所摩擦が改善しない：相径をさらに小さくする反復を止め、M1の異材対、接触面化学、単一材の形状へ戻る。
- 摩擦は低いがソールが削れて膜を供給している：相手消耗と回収量を評価し、工場処理・接触相内の供給へ分ける。利用者の板の摩耗を無料の潤滑材にしない。
- 乾燥で良く雨で不良：水和だけに依存させず乾湿両端の材料候補を比較。塩・油等で穴埋めしない。
- 接触相は良く骨格が硬過ぎる：滑走相を局所化し、方向別接続と短い解放を持つ別骨格と融合する。
- 加工・安全・機能寿命で費用境界を超える：予算超過を明示し、分子結晶・温暖析出側にも同じ局所接触の検査を適用する。
