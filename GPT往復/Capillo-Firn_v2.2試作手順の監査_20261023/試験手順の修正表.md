| 対象 | 実施前に直すこと | 残す測定・記録 |
|---|---|---|
| 配合ID | 初期粒、3mm工程確認粒、微細枝状粒、再生粒、水低減粒を別IDにする | 成分・乾湿基準・粒径・処理履歴 |
| 持込水 | CNF以外も含む全原料の持込水を計上。9.054％は他の持込水ゼロ時の境界 | 実秤量、固形分、排出水、最終含水率 |
| 水低減系列 | 固形分固定なら90／83／76gバッチ。100gへ換算する場合は全成分を再計算 | 芯／外皮への水配分、密度・摩擦・接合への影響 |
| 端面処理 | 「バッチ外微量」を廃止。粉の成分、量、付着と回収を定義 | 完成品・装置残留・粉流出を含む収支 |
| 水和・温度 | 採用グレードで加熱／冷却の応答を測る。50〜55℃を転移直上と決めつけない | 未分散物、温度掃引、流動、押出圧、原料順序 |
| pH | 6.8〜7.5は目標値。カルサイトだけで自動的に固定されるとしない | 試料温度でのpH、調整法と追加成分 |
| 芯／外皮 | 80:20質量とノズル寸法を別々に指定して終えない | 各流量、体積・気泡配分、切断面、実殻厚 |
| Gate A | tanδ>0.3、塑性限界相当のコーン貫入による自動棄却を撤回 | 周波数、ひずみ、温度、時間、形状・離水の実観察 |
| Gate B 密度 | 液浸・気体法による吸水、膨潤、溶出、脱気の影響を検証 | 湿潤包絡体積と床体積を独立に取得。不確かさを併記 |
| Gate B 圧縮 | 質量・粒体積が変わる場合を分け、密度増加と空隙崩壊を同一視しない | 載荷中／除荷後の体積・水分・形態 |
| Gate B 摩擦 | 凝着の観察に加え、温度・面圧・速度を固定した摩擦測定 | ソール材、無処理／処理状態、摩擦力、摩耗、温度 |
| Gate C 水分 | 飽和湿度＝含水率一定としない | 前後質量、試料水分、温度、結露、離水 |
| Gate C 合否 | 「数kPa以下」の任意棄却線を廃止。未接合対照・分解能・必要局所強度から判定 | 未破断、無接合、10秒圧着後除荷、持続載荷を比較 |
| Gate D 変位 | 試験箱変位と局所接点変位を分離。機械変形・残留摩擦を補正 | 接点の局所δ、床全体の仕事、破断面積。未分離なら見掛け値又は未評価 |
| Gate D 再載荷 | 30分待機後の再載荷時間・速度・せん断開始待機を固定 | 再締固めで増えた強度を自然回復と取り違えない |
| 再生 | 回収量、新品外皮、完成品、循環規格外、パージを別々に計上 | 湿潤／乾燥基準、組成、時間基準、合格収率 |
| 土木 | ジオセル上端を最大削れ＋余裕より下に置く | 全断面、弱い界面、アンカー伝達・止水、排水閉塞時 |
| 環境・冬 | 水分率だけで微生物性を判断せず、完成粒・摩耗粉・流出水を扱う | 予備曝露・凍結融解の履歴。短期試験を220日寿命へ読み替えない |
| 運用 | 60分閉鎖の条件を維持。夜間・交互レーンは別案として評価 | 整地、最終区画の回復、検査、幅・能力・費用 |
| 冷却 | ラボ15℃風と現地再生を区別しR05との適合を保留 | 場所、冷却負荷、設備と費用 |

100gは1配合の基準量。二温度、複数時刻、複数応力、独立反復を行う試料量は、供試体寸法と破壊試験数から別に積算する。試験所・設備・購入は未手配。
