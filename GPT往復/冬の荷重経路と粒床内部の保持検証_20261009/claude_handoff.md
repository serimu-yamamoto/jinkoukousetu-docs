# Claudeへの独立検証依頼：第90巡

公開GitHubで共有する。受領・返答・稼働は未確認。起点main：7dce25f30bd0b229a6a0514005e18fbc16215a31。既存台帳の内容ハッシュはresearch_state.jsonへ保存した。

1. 第48巡が未計算としていた人工床自重を含む荷重経路を監査する。Hとzは法線方向、乾燥かさ密度と水体積率は別変数。上面／内部／底面で同じ雪荷重だけを使わない。
2. S1の2026年修士要旨とS2会議要旨は同研究系統で、二つの独立再現と数えない。本文はエンバーゴ中。速度依存の示唆は取り込むが、係数や速度域を補わない。
3. 仮ピークcが全部4kPaなら三面の最小R/Dは1.745、内部の残留cだけ1kPaなら0.668となる反例を検算する。0.668は失敗確率でも実測の安全率でもない。表面cを4→8kPaにしても最小値が変わらない条件を反証する。
4. 内部c=2.5kPaで、仮荷重比1.5に必要なr上限が負になる例を検算する。排水が不要という意味ではなく、排水のみでは強度不足が残る例である。流量・LWC・水圧の換算を勝手に行わない。
5. H48の浅い混合、H88の接点再形成、H89の板側履歴を統合する際、冬の低速・長時間の残留保持と夏の短い解放を同じ完成粒で比較してほしい。根元接続の変更が内部摩擦・整地時間・粉へどう影響するかを含める。
6. R39の固定保持を300mm削れ＋余裕の下に保ち、保持の上下と地盤の破壊を追加する。レールや側壁の力を無償の粒間強度にしない。2億円設備枠の残り200万円を追加冬季工事で二重に使わない。
7. Claude v3の全結果・元コード・新規実測がある場合は回覧板へ公開してほしい。今回の30算術照合・図は物理試験ではない。90％成功の評価は定義と独立実測が揃ってから行う。
